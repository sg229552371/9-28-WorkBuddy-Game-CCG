## 三、并行切分（文件所有权隔离）

> 铁律 §5.45：每任务独占文件集；新增逻辑一律**文件末尾独立区块**；现有函数只插单行调用。
> 下面四个任务**文件零重叠**，可真正并行。

### 🅐 T1「空间分区」—— 独占 `js/core.js`
| 措施 | 做法 |
|---|---|
| B1 去重 O(k²) → O(k) | 对象存 `_qTick`，查询时比对帧序号（`SpatialHash` 内部维护 `tick`，每次 `clear()` 递增） |
| B2 自适应 cell | 新增 `autoCell(count)`：按实体数推荐 cell（<500→96，<1500→128，≥1500→192）；`World` 构造时调用 |

**交付**：`core.js` 尾部新区块 + 单行调用。**契约**：查询结果集与旧实现逐位等价（顺序可不同）。

### 🅑 T2「对象池」—— 独占 `js/pool.js`（新建）+ `js/game.js` 的 FX 段
| 措施 | 做法 |
|---|---|
| C3/C4 粒子·飘字真池 | `js/pool.js` 提供通用 `Pool`（预分配 + 空闲链表 + `alive` 标记）；`FX.parts/floats` 改池化；`updateFX` 改 swap-remove（无 `filter` 新数组） |
| C1 `aliveHeroes` | 模块级 scratch 数组复用（仿 `_tmpArr`），返回同一引用（调用方只读） |
| C2 `enemyTargets` | 同上，scratch 复用 |
| C7 `explode` Set | 模块级复用 |

**交付**：`js/pool.js`（新）+ `game.js` FX 段改造 + 末端区块。**契约**：粒子/飘字行为逐位等价（数量、寿命、速度）。

### 🅒 T3「长数组 swap-remove」—— 独占 `js/game.js` 的 `World.update` 段
| 措施 | 做法 |
|---|---|
| C6 monsters/bullets | `filter` → 末尾交换删除（原地，无新数组） |
| C5 `Bullet.hitSet` | 池化时 `clear()` 复用；未池化时延迟创建（首次命中才 new） |

**交付**：`game.js` `World.update` 段 + 末端区块。

> ⚠️ T2 与 T3 都碰 `game.js`——**必须串行**（或严格分区块让代理互不越界）。为安全起见把 T3 合并进 T2 的同一代理串行做。

### 🅓 T4「画质分档 + 自动降档」—— 独占 `js/main.js`
| 措施 | 做法 |
|---|---|
| D1 三档画质 | `G.settings.quality = 0|1|2`（低/中/高），`isLowQuality()` 兼容旧语义（quality===0） |
| D3 自动降档 | PerfGuard 从「仅告警」升级：连续 90 帧 p95 > 阈值 → 降一档（有冷却、不回升、可手动覆盖） |
| D4 默认档 | 按 `deviceMemory` / 分辨率 / UA 初判；设置页可切 |

**交付**：`main.js` 档位逻辑 + 设置页开关（`index.html` + `css/style.css` 小改）+ 末端区块。
**契约**：`quality` 未设置 → 行为与改动前一致（向后兼容）。
