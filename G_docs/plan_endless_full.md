## 三、并行波次切分（多线程并行）

### 3.1 硬约束（来自 `parallel-ai-game-dev` 规范）

- **H1 一个文件一个波次所有权**：同一文件不得被两个并行波次同时改。
- **H2 共享文件串行**：`js/config.js`、`index.html`、`css/style.css` 是**共享契约文件**，由 **Wave 0（主会话）串行冻结**，并行波次**只读不改**。
- **H3 新模块优先**：每个并行波次尽量**新建独立文件**（`js/endless-*.js` / `js/ui-abyss.js`），把冲突面压到最小。
- **H4 接线只追加**：对 `modes.js` / `main.js` / `game.js` 等既有文件的接线，一律走**文件末尾独立区块** + 主循环**单行调用**，禁止改中间逻辑。
- **H5 接口先冻再并行**：`Endless.*` / `CFG.endless.*` / `Meta.data.*` 的签名（§3.3）在 Wave 0 冻结；并行波次只能消费，不得改签名。
- **H6 验收门禁**：每波次收尾必须 `bash run_tests.sh` 全绿 + 新增本波次测试；合并前由守门员复核（测试项计数核对，防静默跳过假绿）。

### 3.3 冻结接口（H5，Wave 0 定稿）

```js
/* --- 层级（W1 产出，W4 消费） --- */
CFG.endless.tier = {
  max: 20,                          // 最大层级
  stepMul: 0.18,                    // 每层强度增量系数
  rewardMulPerTier: 0.10,           // 每层奖励倍率增量
  anchors: [[1,1.0],[10,2.2],[20,4.0]],  // 层级 → 难度系数（分段线性）
};
Endless.tier = 1;                   // 当前层级（运行时）
Endless.applyTier(n);               // 设置层级（进入前调用）
Endless.tierMul();                  // 当前难度系数（乘进 hpMul/atkMul）

/* --- 词缀（W2 产出） --- */
CFG.endless.affixes = { list: [ {id, name, desc, weight, mods:{...}} ] };
Endless.rollAffixes(n);             // 为当前层级随机 n 条词缀
Endless.activeAffixes();            // 当前生效词缀（HUD/结算读）

/* --- 记录（W6 产出，Meta 持久化） --- */
Meta.data.abyss = { bestWave:0, bestTier:0, fastestSec:0, firstExtract:false, firstFinalBoss:false };
```

### 3.4 验收标准（每波次）

- [ ] `bash run_tests.sh` 全绿 `bad=0`（测试项只增不减）
- [ ] 本波次新增测试文件已登记进 `run_tests.sh`
- [ ] 非深渊世界（主线/裂缝/工匠/主城）行为**逐位不变**（`isActive()` 早退）
- [ ] 无 DOM 依赖（核心逻辑可在 vm 沙箱无头跑）
- [ ] 接线走「末尾区块 + 单行调用」，不改既有中间逻辑
