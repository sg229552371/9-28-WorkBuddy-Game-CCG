## 零、背景与目标

**问题**：21.12~21.14 已证明「3000 敌 + 2000 弹」技术上可跑（lod 档 137fps），但**只是压测场景**——
`?stress=` 走的是空世界 `kind="stress"`，无地形、无掉落、无结算、无 UI 信息。

**目标**：把海量敌人变成**真正可玩的模式（无尽模式 / 深渊）**，并补齐配套体验。

## 二、无尽模式玩法规则（定稿）

### 2.1 入口
- 主城新增 **「深渊之门」**（位置：主城右上角，与既有 NPC 区分；金红色调）
- 走进判定圈 → 点击 → 读条 2.0s（复用统一道具系统 `channel` 范式）→ 进入深渊世界
- 首次进入弹一次规则说明（可跳过）

### 2.2 核心循环
- **波次制**（wave）：第 N 波 → 清空后 3s 间隔 → 第 N+1 波
- **同屏上限曲线**：`capFor(wave) = min(300, 40 + wave * 12)` —— 波 1≈52，波 10≈160，波 22+ 达 300
- **敌人强度**：血量/伤害随波次线性增长（`hpMul = 1 + (wave-1)*0.18`，`dmgMul = 1 + (wave-1)*0.06`）
  - ⚠️ 这是**首版占位曲线**，按用户「后期会调」的预期，一律进 `CFG.endless`，不做硬编码
- **奖励**：每波结算结晶 = `round(8 * wave^1.15)`，第 5/10/15… 波额外掉落宝箱
- **失败**：玩家死亡 → 立即结算（复用撤离结算面板），结算显示到达波次/击杀数/获得结晶
- **退出**：无主动撤离（首版），死亡即出

### 2.3 与既有系统复用
- 复用 `World`（新 kind `"endless"`）、`Monster`、`Bullet`、升级 4 选 1、背包、芯片
- 复用 `G.lastSettleReport` + `buildCrystalReport`（结晶产出明细）
- 复用 `CFG.altarJudgeMul` 判定圈范式
