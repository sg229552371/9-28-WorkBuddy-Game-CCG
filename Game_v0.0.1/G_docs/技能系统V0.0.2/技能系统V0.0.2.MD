技能出生到结束的顺序,严谨版应该是两个主体、两条时间轴:

A层一,施法者相位(每个英雄一条，闭环):
出手索敌决定起手→蓄力冷却tick字段已备尚未接线spawnEffectcooldownFor;冷却结束回到索敌,这是闭环，不是单程线.;
A层二,效果体生命周期(0到N个实例，每个各走一遍):
生成→存活运动命中0~N次→终止→回收;
bornStep守卫→phaseSweep→事件/非状态→到期/贯穿/越界→phaseRecycle;命中可派生新实例一递归回到「生成」.;

//---已实现
环绕 史诗	主弹变成围绕英雄转的实体，还切换了施放策略（无目标也能放）	convertNode → TP_ORBIT_CONTACT + CAST_ORBIT
追踪 稀有	主弹持续转向索敌	homingMode 1→2
分裂 史诗	命中后炸出小弹（2~8 发）	addNode onHit → 飞行弹
弹射 史诗	命中后飞向另一个敌人，逐跳递减	onHit 链式，最多 1~5 跳
链锁 史诗	命中后直接炸在下一个敌人身上（无弹道）	onHit → 瞬发范围，1~4 跳
爆破 史诗	主弹消失时爆出圆形范围（半径 110）	onExpire → TP_INSTANT_AREA
余焰 稀有	消失后地面留下持续火场（半径 120，4 秒，带虚线）	onExpire → TP_PERSISTENT_AREA
灼烧 稀有	敌人身上挂火焰（跟随目标，半径 48，3 秒）	onHit + attach:"target"
