### 0.2 生成原则（四条）

1. **同一口径延续**：21~99 关不是新规则，而是**第 9/10 关斜率与 11~20 关外推口径的继续延伸**——手法与 11~20 关完全同构（见 `js/config.js:342~354` 注释）。
2. **压力双通道**：`monsterLevel` **封顶 10**（怪物属性成长口径 ≤10），21 关以后的压力**全部由 `levelCurve` 的 `countMul`（数量）/ `hpMul`（血量）承载**。
3. **机制关不叠加**：毒圈 / 补给（`hazard` / `supply`）在 11 关以后一律 `null`，**机制关总数维持既有 5 关**，21~99 关**不新增机制关**。
4. **可回归**：全部字段由生成器纯函数产出（无随机、无时间依赖），同输入同输出；`CFG._validateLevelCurve()` 的硬校验**改为按 `CFG.levels.length` 自适应**（不再硬编码 20）。

## 2. 逐字段外推公式表（`CFG.levels[20..98]`）

> **实现真源 = `js/config.js` 生成器**。下表公式与 11~20 关数据**逐条对齐**（已用 11~20 关实测值反推校验）。
> 记号：`lv` = 关卡号（21~99）；`⌊x⌋` = 向下取整；`round` = 四舍五入。

| 字段 | 21~99 外推公式 | 与 11~20 关同源校验 | 备注 |
| ---- | ---- | ---- | ---- |
| `id` | `"LEVEL_" + 三位零填充(lv)` | 同 1~20 关 | 如 `LEVEL_021` |
| `name` | `"第 {lv} 关 · {章节主题词}"` | 同 1~20 关 | 主题词取 §1 表（待审） |
| `theme` | 按章节主题调色板取值 | 同 1~20 关 | 视觉用，不参与结算 |
| `mapW` / `mapH` | `min(3000, 2400 + (lv − 20) × 30)`，取 30 的整数倍 | 11~20：1980→2400（区间 [1920,3000]） | **约 L40 触上限 3000 后封顶**；保持 `mapW === mapH`（正方形，`smoke` 断言） |
| `monsterLevel` | **恒 10**（封顶） | 11~20 关即封顶 10 | 压力改由 `countMul`/`hpMul` 承载 |
| `eliteBase` | `10 + ⌊(lv − 11) / 2⌋`（续 +1/两关） | 11~20：10→15 | 与「两小步一档」口径一致（原型档） |
| `elitePool` | `ED0001 = max(5, 19 − (lv − 11))`；`ED0003 = min(75, 47 + round(1.5 × (lv − 11)))`；`ED0002 = 100 − ED0001 − ED0003` | 11~20：19/34/47 → 10/29/61 | 高阶精英占比单调抬升；`ED0001` 有下限 5 |
| `boss` | 见 §4（10 模板循环；章节终关与 99 关 = `BS0010`） | 11~20 为 `BS0001~BS0010` 第二轮 | 恒 10 只 Boss 模板 |
| `monsterCap` | **维持 300**（性能红线，不随关卡抬升） | 11~20：分档 120/160/220/300 | countMul 承载压力，同屏数不冒险抬升 |
| `circles` | 见下方「圆模板」小节 | 11~20：SC03 主力、SC02/SC01 搭配 | 圆总数 15→26 递增 |
| `progressGoal` | 见下方「进度目标」小节 | 11~20：220→440 | 步长每两关 +2 |
| `timeLimit` | `420 + (lv − 10) × 30`（+30/关） | 11~20：450→720 = 420 + (lv−10)×30 ✔ | 与 `js/config.js` 11~20 关逐字吻合 |
| `artisanAtKills` | `60 + (lv − 11) × 4`（+4/关） | 11~20：60→96 = 60 + (lv−11)×4 ✔ | 首次工匠雕像里程碑 |
| `altarTimeline` | 见下方「祭坛时间轴」小节 | 11~20：10→12 条 | 池沿用 1~20 关同款 |
| `hazard` / `supply` | **恒 `null`** | 11~20 关同 | 机制关总数维持 5 关 |

### 2.1 `progressGoal`（击杀进度目标）

- 11~20 关实测步长序列：`L10→11 = 20`，其后 `20, 22, 22, 24, 24, 26, 26, 28, 28`（**每两关 +2，起始步长 20**）。
- 外推：**L21 起继续每两关 +2**，即相邻关步长 `step(lv) = 20 + 2 × ⌊(lv − 11) / 2⌋`。
- 样例：`L21 ≈ 470 / L25 ≈ 570 / L30 ≈ 690 / L50 ≈ 1,180 / L99 ≈ 2,690`（原型档，待调）。

### 2.2 `circles`（刷怪圆）

- 11~20 关实测：**SC03 为主力**（约 **+1 / 两关**）、**SC02 / SC01 搭配**（各约 **+1 / 三关**），圆总数 **15 → 26** 递增。
- 外推：沿用同一圆池（`SC01 / SC02 / SC03`）与快慢节奏（`interval ≈ 7.0 / 6.0 / 5.5` 逐关轮换）；`SC04` **不挂 L21 以后**（被 `special_monster_test` 锁定仅挂 L8~L10，与 11~20 关口径一致）。
- 样例：`L21 = [{SC03×7~8},{SC02×5},{SC01×3~4}]` → `L99` 约 `SC03×20+`（原型档，待调）。

### 2.3 `altarTimeline`（祭坛时间轴）

- 11~20 关实测：条目数 **10 → 12**（约 **+1 / 4 关**）；时间点按 **~1.02× 递进**（首条约 12~14s，末条约 426→672s）。
- 外推：条目数 `= 10 + ⌊(lv − 11) / 4⌋`；时间点沿同一递进公式展开；池**沿用 1~20 关同款**——`ALTAR_001 / ALTAR_002 / ALTAR_003` 三选 + `ALTAR_004a~e`（邪神 5 变体）轮转；**宝箱（`ALTAR_003`）不在开局 10 秒内给**（与 1~20 关口径一致）。

## 3. `CFG.levelCurve.rows` 21~99 外推规则（同 `season_design_v1.md` §5.3 四条）

> `rows.length` 由 **20 → 99**，与 `CFG.levels.length` **一一对应**（`rows[i].lv === i + 1`）。

| 字段 | 21~99 外推规则 | 与 11~20 关校验 |
| ---- | ---- | ---- |
| `hpMul` | `1 + (lv − 1) × 0.12`（**严格对齐怪物等级成长口径**，`js/config.js:110` 注释） | L20 = `1 + 19×0.12 = 3.28` ✔ |
| `countMul` | 沿第 9/10 关斜率 **+0.15/关** 线性外推（`lv ≥ 11` 起），即 `2.25 + (lv − 10) × 0.15` | L20 = `2.25 + 10×0.15 = 3.75` ✔ |
| `hazard` | **默认 `null`**（机制关总数维持既有 5 关） | 11~20 关同 |
| `supply` | **默认 `null`**（同上） | 11~20 关同 |
| `chest` | **延续后期档 `CT4`**（高阶占比不回落） | 11~20 关同 |

> ⚠️ **校验上限提醒（待主会话/策划确认）**：现 `CFG._validateLevelCurve()` 对 `countMul` / `hpMul` 设了 **`> 10` 即报超界**；本外推在 **高关卡会越界**——
> `hpMul(L99) = 1 + 98×0.12 = 12.76`、`countMul(L99) = 2.25 + 89×0.15 = 15.60`。
> 结论：**20 行硬校验已按 `CFG.levels.length` 自适应（D037）**，但**倍率上限 10 的区间校验需同步放宽或改为「单调不减即可」**，否则高关卡会触发 `issues`。**此项以代码实现为准，本稿仅登记风险**。

## 4. Boss 映射规则

- **模板池** = `BS0001 ~ BS0010`（**恒 10 只**，与 1~20 关全表覆盖一致）。
- **循环规则**：`boss(lv) = "BS00" + 两位零填充(((lv − 1) mod 10) + 1)` —— 即 **每 10 关一轮**。
  - `L21 → BS0001`，`L22 → BS0002`，…… `L30 → BS0010`，`L31 → BS0001`，依此循环。
- **章节终关**：`lv ∈ {30, 40, 50, 60, 70, 80, 90}` 时，循环结果**天然**为 `BS0010`（因 `(lv−1) mod 10 = 9`）——**无需特判**。
- **全局终关 `L99`**：循环结果为 `BS0009`，**强制覆盖为 `BS0010`**（终局·邪神本体）。
- **特殊关（如 15 关 BS0005 / 20 关 BS0010）**：属 1~20 关手调段，不在本外推规则内。
