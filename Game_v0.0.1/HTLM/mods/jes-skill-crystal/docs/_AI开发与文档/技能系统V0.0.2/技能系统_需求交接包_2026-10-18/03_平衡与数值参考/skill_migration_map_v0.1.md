## 5. 存档迁移规则（v0.5 §13，**冻结**）

- 保存 `schemaVersion / configVersion / 每英雄技能与水晶实例 / 等级 / 奖励事务与随机状态`。
- **未知 ID、等级越界、旧冲突组合 → 保留原始备份 + 输出报告，禁止静默删除**。
- **旧九级资产不可直接截断成两级**（v0.5 §13 明文）。
- 首轮**不承诺**新增跨版本中途恢复；已有能力则保留或明确兼容。

**已有实现（`js/skill-save.js`）**：
- `report.unknownIds[]`（未知 ID → `action:"preserved"`）
- `report.levelOverflow[]`（等级越界 → `action:"preserved"`）
- `report.migrated[]`（`from → to`，含 `kind`）
