# 第8章　四类载体与位移状态〔2026-10-18 终审修正〕

> **一句话结论**：载体有四类——无载体（＝瞬时实例）、自身载体（位移状态＋跟随判定体）、独立载体、附着载体（有寿命无运动，见 8.5A，D-106）〔2026-10-18 终审修正〕；近战／远程只是玩家感知分类，不是载体表；瞬移是零时长位移，无判定体，落点爆炸另生成实例；严禁用超大速度冒充瞬移。〔D-01 已确认；建模细则 D-18 推荐默认〕

## 8.1 四类载体总表〔2026-10-18 终审修正〕

| 载体（`carrier`） | 本质 | 有存活期 | 有 vanish | 典型 | 章内位置 |
|---|---|---|---|---|---|
| `none` 无载体 | 寿命为 0 的瞬时实例 | 否（同 tick 完成） | 是（`instant_end`） | 瞬时扇形、瞬时圆形爆炸、瞬时射线 | 8.2 |
| `self` 自身载体 | 位移状态 + 跟随判定体 | 是（随位移状态） | 是（见 8.3 原因码映射） | 冲刺、跳跃、有路径命中的位移 | 8.3 |
| `independent` 独立载体 | 出手后独立运行的实例 | 是 | 是 | 飞弹、炮弹、地震波、地刺、火区、回旋体、环绕飞刃、持续射线 | 8.5 |
| `attached` 附着载体（D-106） | 附着在目标（`anchor_target_id`）上的有寿命效果体，无空间运动 | 是（寿命或终止条件） | 是（`expired`／`hit_end`／`dispelled`／`anchor_gone`） | 护盾、增益／减益、持续治疗、状态型派生体 | 8.5A〔2026-10-18 终审修正〕 |

决定载体的不是距离，而是**这段效果由谁承载、是否需要独立存活过程**。

## 8.2 无载体（＝瞬时实例）

出手时直接完成一次结算，实例寿命为 0，在同一 tick 内 hit 与 vanish（`instant_end`）。〔D-01 已确认〕

| 规则 | 内容 | 状态 |
|---|---|---|
| 8.2-1 | 无载体 = 瞬时实例，`carrier = none`、`lifetime_ticks = 0`；**不是"没有实例"** | 〔D-01 已确认〕 |
| 8.2-2 | 它有自己的 vanish，原因码固定 `instant_end` | 〔D-01 已确认〕 |
| 8.2-3 | 它没有运动；"瞬时射线"指一次性直线判定，不是会飞的东西 | 〔D-18 推荐默认〕 |
| 8.2-4 | 瞬移**不属于**此类（瞬移是位移，不是判定；见 8.4） | 〔D-18 推荐默认〕 |
| 8.2-5 | 无载体仅指瞬时实例；任何"有寿命但无空间运动"的实例一律用 `attached`（8.5A），不得写成 none + 寿命>0 | 〔D-106 推荐默认〕〔2026-10-18 终审修正〕 |

适用：瞬时扇形、瞬时圆形爆炸、瞬时直线判定、瞬时射线。

## 8.3 自身载体：位移状态 + 跟随判定体

自身载体由两个东西组成：

| 部分 | 性质 | 归属 |
|---|---|---|
| 位移状态 | 施法者被占用的运动状态；不是实例 | 属于施法者（4.7 的 D-06 约束其期间不能施放其他技能） |
| 跟随判定体 | 跟随施法者位置的效果体，`carrier = self`，是真正的实例 | 走第5章生命周期，产生 hit、发 vanish |

规则：

| 编号 | 规则 | 状态 |
|---|---|---|
| 8.3-1 | 位移状态开始 = 出手；同一 tick 创建跟随判定体 | 〔D-18 推荐默认〕 |
| 8.3-2 | 位移状态结束 → 判定体终止（一一对应），原因码按 8.3.1 映射 | 〔D-18 推荐默认〕 |
| 8.3-3 | 位移状态被打断 → 判定体以 `interrupted` 终止，发 vanish，默认不派生，不补 hit | 〔D-11 推荐默认〕 |
| 8.3-4 | 位移状态期间不能施放其他技能 | 〔D-06 已确认〕 |
| 8.3-5 | 路径上的目标是否受伤由判定体的 `hit_policy` 决定，默认每目标 1 次 | 〔D-18 推荐默认〕 |
| 8.3-6 | 判定体的生成与终止都不改变"位移状态是否继续"：由施法者运动决定，判定体只是附着 | 〔D-18 推荐默认〕 |

### 8.3.1 位移结束的原因码映射

`landed` 仅限抛射体落到目标点或地面；位移状态不使用 `landed`。固定时长定义的位移用 `expired`，按距离／终点定义的用 `range_end`，被打断用 `interrupted`。〔D-18 推荐默认；R5〕

| 位移怎么结束 | 判定体原因码 | 能否 vanish 派生 | 状态 |
|---|---|---|---|
| 位移按固定时长定义，时间到（含跳跃） | `expired` | 是（不额外跳伤） | 〔D-18 推荐默认；R5〕 |
| 位移按距离或终点定义，抵达终点或距离耗尽（含冲刺） | `range_end` | 默认否，显式声明才可 | 〔D-18 推荐默认；R5〕 |
| 被控制／击退／被拦截 | `interrupted` | 默认否 | 〔D-11 推荐默认〕 |
| 施法者阵亡、场景卸载 | `purge` | 否 | 〔D-01 已确认〕 |

## 8.4 冲刺、跳跃、瞬移的建模

| 项 | 冲刺 | 跳跃 | 瞬移 |
|---|---|---|---|
| 载体 | `self` | `self` | 无载体意义上的"零时长位移"，**无判定体** |
| 位移状态 | 有，时长或距离有限 | 有，时长有限 | **无**（零时长，出手当 tick 完成） |
| 跟随判定体 | 有，路径上可 hit | 有，是否路径命中由技能声明；默认仅落点有判定 | 无 |
| 路径是否产生命中 | 是 | 默认否（抛物线是表现，见第9章） | **否** |
| 越墙 | 不越墙 | 当前默认不越墙；越墙需独立规则，不能靠把曲线画高 | 由瞬移规则的落点合法性决定 |
| 被打断 | 判定体 `interrupted`，不补 hit | 判定体 `interrupted`，**不补落地伤害** | 无打断窗口（零时长） |
| 落点效果 | 抵达终点以 `range_end` 终止，默认不派生，显式声明才可 | 按固定时长定义时以 `expired` 终止，可派生落地冲击；不使用 `landed` | 落点爆炸是**同一次出手里另生成的**实例，不是"瞬移结束后派生" |
| 期间能否施放其他技能 | 否〔D-06〕 | 否〔D-06〕 | 不存在"期间"，可在同 tick 继续后续出手 |

补充规则：

1. **跳跃被打断时，不因动画结束就自动补落地伤害。**〔D-11 推荐默认〕
2. 瞬移的落点爆炸写成"出手时同时创建一个独立（或瞬时）实例"，不写成"瞬移 vanish 派生"，因为瞬移没有实例也没有 vanish。〔D-18 推荐默认〕
3. 瞬移的"起点残影"同理：另生成实例，不是瞬移本身的产物。〔D-18 推荐默认〕
4. 跳跃与冲刺的具体穿墙、碰撞阻挡规则属于判定细则，本章只规定"越墙不得靠改曲线实现"。〔D-18 推荐默认〕

## 8.5 独立载体

出手生成后，实例独立运行，不依赖施法者的位置与状态。

适用：飞弹、炮弹、地震波、地刺、持续火区、回旋投掷、环绕飞刃、持续射线。

规则：

1. 独立载体**不等于必须飞行**：环绕、静止火区都属于独立载体。〔D-18 推荐默认〕
2. 独立载体的 vanish 原因码取决于其终点：`hit_end`、`range_end`、`landed`、`expired`、`returned`、`interrupted`，不会是 `instant_end`（那是瞬时实例专用）。〔D-14c 推荐默认〕
3. 独立实例一旦生成，不受施法者之后被打断的影响（4.5-2）。〔D-10 推荐默认〕
4. 召唤物（独立闭环）与独立载体不是同一概念：召唤物拥有自己的施法者闭环，其细则见第22章。〔D-07 已确认〕

## 8.5A 附着载体（`attached`，第四类）〔2026-10-18 终审修正〕

附着在某个目标上、有寿命、无空间运动的效果体。护盾、增益／减益、持续治疗、状态型派生体归此类。

| 规则 | 内容 | 状态 |
|---|---|---|
| 8.5A-1 | `attached` = 附着在某个目标（`anchor_target_id`）上的效果体：**有寿命、有 owner、无空间运动、不进碰撞分桶** | 〔D-106 推荐默认〕 |
| 8.5A-2 | 必须有 `lifetime_ticks > 0` 或明确的终止条件（额度打光／条件满足）；寿命为 0 的瞬时判定不得用 attached | 〔D-106〕 |
| 8.5A-3 | **不参与候选接触收集**，除非模板显式声明 `periodic_tick`（周期跳）；届时按 `periodic_tick` 生成接触，不按空间重叠 | 〔D-106〕 |
| 8.5A-4 | 终止原因码：`expired`／`hit_end`／`dispelled`／`anchor_gone`（宿主消失或阵亡） | 〔D-106〕 |
| 8.5A-5 | 宿主阵亡时，attached 实例按 `<P>` 级预算随宿主一起清理（见 15 章 purge 优先级），不单独走周期回收 | 〔D-106〕 |
| 8.5A-6 | 典型用途：护盾、增益／减益、持续治疗、状态型派生体；**纯数值状态（不建实例）仍可不建效果体**，由模板选择（与 F-06 四判据衔接） | 〔D-106〕 |

## 8.6 近战和远程不是载体表

"近战／远程"是玩家感知和设计分类，不应成为两套底层生命周期。

| 玩家感知 | 可以是的载体 |
|---|---|
| 近战 | 无载体瞬时扇形；自身载体冲刺；独立载体剑气 |
| 远程 | 无载体瞬时射线；独立载体飞弹；独立载体地面区域 |

因此：设计卡里不设"近战／远程"字段决定生命周期，只设 `carrier`。〔D-18 推荐默认〕

## 8.7 禁止用超大速度冒充瞬移

| 做法 | 为什么错 | 正确做法 |
|---|---|---|
| 把冲刺速度调到极大，当作瞬移 | 仍然是位移状态：期间锁定其他技能（D-06）、会产生路径命中、可被打断，且受固定步长下穿越检测影响 | 瞬移 = 零时长位移，直接改坐标，无判定体 |
| 把瞬移写成"自身载体高速运动" | 破坏"瞬移无路径命中、无打断窗口"的语义 | 瞬移不进入位移状态 |
| 用极大速度的独立实例冒充瞬时射线 | 会跨越多 tick 检测，目标可能漏判 | 瞬时射线用瞬时实例，同 tick 一次性直线判定 |
| 反过来：把冲刺写成"小范围瞬移 + 路径伤害" | 路径伤害需要判定体，瞬移不产生 | 冲刺写位移状态 + 跟随判定体 |

〔D-18 推荐默认〕

## 8.8 常见误写 → 正确写法

| 常见误写 | 正确写法 |
|---|---|
| "近战用第一套生命周期，远程用第二套" | 只有 `carrier` 四类；近战远程只是分类〔2026-10-18 终审修正〕 |
| "护盾写成 carrier=none + 寿命 300" | 应为 carrier=attached（8.5A，D-106）〔2026-10-18 终审修正〕 |
| "瞬移结束后派生爆炸" | 落点爆炸在同一次出手里另生成实例〔D-18〕 |
| "冲刺的位移状态是一个实例" | 位移状态不是实例，只有跟随判定体是〔D-18〕 |
| "跳跃被打断，动画播完后补落地伤害" | 被打断即以 `interrupted` 终止，不补〔D-11〕 |
| "用超大速度让冲刺看起来像瞬移" | 瞬移是零时长位移，不进位移状态〔D-18〕 |
| "无载体没有 vanish" | 无载体＝瞬时实例，有 `vanish(instant_end)`〔D-01〕 |
| "冲刺期间可以同时放别的技能" | 位移状态期间不能施放其他技能〔D-06 已确认〕 |
