# 附录 A　术语表

**一句话结论：**全书术语以本表为准；同义词不得另造。带"取代"的词是 v0.1 旧词，仅供对照。

| 术语 | 定义 | 详见 |
|---|---|---|
| 施放 | 玩家/怪物发起一次技能，从索敌到本轮结束。一次施放 = 一轮，对应一个 `cast_id` | 第4章 |
| 施法者闭环 | 索敌 → 前摇 → 出手 → 冷却 →（回到索敌）。取代 v0.1 的"层一" | 第4章 |
| 出手 | 闭环里一个瞬间：创建效果体或进入位移状态。X = 一轮内出手总次数；旧 Y、Z 分配作废 | 第10章 |
| 效果体 | 一切技能产物的统一容器（瞬时/独立载体/自身载体）。取代 v0.1 的"层二" | 第5章 |
| 实例 | 效果体的一次运行时存在，有唯一 `instance_id` 与创建序号 `seq` | 第5章 |
| 瞬时实例 | 寿命为 0 的效果体，同 tick 内完成 hit 与 `vanish(instant_end)` | 5.5 |
| 载体 | `none`（无载体）/`self`（自身，位移状态+跟随判定体）/`independent`（独立）/`attached`（附着，8.5A）〔2026-10-18 终审修正〕 | 第8章 |
| 位移状态 | 施法者被占用的运动状态，期间不能施放其他技能（D-06） | 4.7、第8章 |
| hit | 事件。一次候选接触中至少一份未被闪避（含非伤害份，见 22.2/33A）时成立，只发一条〔2026-10-18 终审修正〕 | 第6、11章 |
| vanish | 事件。效果体自然终止时发出，带原因码 | 第6、7章 |
| 原因码 | `hit_end` `range_end` `landed` `expired` `returned` `interrupted` `instant_end` | 36.3 |
| purge（清场） | 清场/卸载/阵亡清理/预算丢弃。不发 vanish、不派生、不补 hit。不是原因码 | 第7章 |
| 伤害份 | 一条 hit 内独立判闪避、独立算减免的单位 | 第10、11章 |
| 候选接触 | 实例与目标由不重叠变重叠，或 `rehit_interval_ticks` 到点；每次只判一次逐份闪避；`per_target_limit` 按候选接触计 | 第14章 |
| 家族登记 | 分裂体与母体共享的"已发生候选接触"登记表，防二次命中；不同于防霰弹 | 第20、30章 |
| 防霰弹 | 同一次出手同时生成的独立实例对同一目标只有一个能接触 | 第14章 |
| 结算记录 | **非事件**只读记录：`hit_settled` `evaded_all` `damage_taken` `cast_started`，供被动触发层订阅 | 第6章 |
| `debug_record` | **非事件、非结算记录**，仅供测试与调试，任何层不得订阅触发逻辑；`kind`：`budget_drop` `proc_blocked` `gen_limit` | 6.7 |
| 被动触发层 | 读结算记录，只能生成效果体或挂修饰器，不能直接造成伤害 | 第21章 |
| 修饰器 | 水晶与遗物的统一机制，三档权限 | 第16–17章 |
| `mutate_number` | 改数值字段（仅暴露字段） | 第17章 |
| `add_behavior` | 加行为，只影响之后生成的实例 | 第17章 |
| `mutate_live_instance` | 改场上已存在的实例 | 第18章 |
| 快照 | 出手时施法者属性的冻结副本，默认用于该实例全寿命 | 第18章 |
| 派生 | 在 hit 或 vanish 上生成子效果体，`parent_ref` 指向父实例 | 第7章 |
| 派生代数 `generation` | 根为 0，只数派生 | 第7、20章 |
| `chain_depth` | 因果链深度，每次派生与每次被动触发各 +1，故 ≥ `generation` | 第20章 |
| 来源链标记 `origin` | `origin_skill` `origin_cast_id` `chain_depth` `proc_mask` | 第20章 |
| `internal_cooldown_ticks` | 触发配置的内置冷却，按持有者计 | 第21章 |
| 召唤物 | 拥有独立施法者闭环的效果体，受 `summon_cap` 约束，`bind_owner` 默认 true | 4.8、第22章 |
| 实例预算 | 同屏实例数的分级上限；超限按优先级 purge | 第15章 |
| 设计卡 | 一页写完一个技能的标准模板 | 第24章 |
| 层一 / 层二 | **v0.1 旧词，取代**：分别由"施法者闭环""效果体"替代 | 附录 E |
| 推荐默认 | AI 提出、本书暂用、未经用户确认的规则 | 第2章 |
| 已确认 | 用户明确拍板，仅 D-01…D-09、D-90…D-92（第二轮）与 D-104…D-105（第三轮） | 第2章 |
| 待用户确认 | 方向性、需用户表态，目前 F-23（控制递减）1 项〔2026-10-18 终审修正〕 | 第2章 |
