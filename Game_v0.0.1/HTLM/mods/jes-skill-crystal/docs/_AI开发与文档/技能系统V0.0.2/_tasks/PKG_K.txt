## 外部事实参考（2026-10-18 取得，可引用其**结构性原则**，不得声称核验了他方数值）
- GAME《ADR 0007: The DSL is a sandboxed AST interpreter》：自定义策略是 **JSON AST**，逐节点走**固定 handler 表**；四条保证 = 无动态求值（无 eval/exec/getattr）、白名单（节点类型/操作符/函数/字段路径各自 allow-list，前置检查）、**冻结预计算上下文**（字段访问是查冻结字典，AST 字符串永不寻址任意属性）、协作式 yield 可取消。https://fvergaracl.github.io/GAME/decisions/0007-dsl-sandbox.html
- 同上《The DSL Strategy Engine》管线四阶段：编辑 → JSON AST → validate_ast()（Shape／Whitelist／Limits 三类校验）→ 持久化；限制含 DSL_MAX_NODES、DSL_MAX_DEPTH；validator 给每个节点补稳定 id 用于 trace 与报错。https://fvergaracl.github.io/GAME/dsl-engine.html
- 纯 JSON 条件 DSL（@bct-app/game-dsl）：`validate`／`evaluate`／`diagnose` 三入口；零运行时依赖；**不修改数据、不访问外部服务、不管理生命周期**；短路分支标记 skipped。https://classic.yarnpkg.com/en/package/@bct-app/game-dsl
- Lua 配置 DSL 安全实践：构造函数必须**纯**（不读文件/环境变量/网络/当前时间，不改宿主全局态）；不暴露 os、io、package、debug、require、dofile、load；**解析必须 all-or-nothing**（部分应用难回滚）；资源预算（指令数/内存/超时）。https://ilukes.com/blog/2025/lua-configuration-dsl-en
- DSL 工程准则：先定 **EBNF 文法**；AST 节点**类型化**；**schema 校验放在解析边界**（不在 handler 内）；**执行引擎保持纯函数**（输入 AST+context，输出结果，无 I/O 无副作用）；**外部 DSL 不得图灵完备**（语言也要最小权限）；解析错误必须带位置（行/列）与期望 token。https://github.com/paulpas/agent-skill-router/blob/main/skills/coding/dsl-engineering/SKILL.md
- 公式替代常量（Contentplate）：数值可写成 `clamp(level*2, 0, 100)`，变量由运行时注入；引用可嵌套，**带环检测与深度限制**。https://scrayos.net/de/contentplate-turning-game-configuration-upside-down
