| 卷四 | `04-interface-tables.md` | 交界映射表 T1 / T2 / T3 | 跨文档接线 |
| 卷五 | `05-decisions-and-changes.md` | 决策总表与变更记录 | 追溯与裁决策 |
| 卷六 | `06-glossary.md` | 术语总表 | 统一口径 |
| 卷七 | `07-provenance.md` | 来源与证据 | 可信度与边界 |

**这不是运行时实现，也不是教程。** 文档静态一致性不等于引擎已实现。

## 怎么构建与校验

在 `G_docs/技能系统V0.0.2/技能系统书_v1/` 下执行：

```bash
python tools/build_book.py            # 生成合订本
python tools/build_book.py --check    # 校验合订与源逐字节一致
python tools/validate_book.py         # 全书校验（链接/锚点/清单/旧词/枚举）
```

`validate_book.py` 检查项：清单齐全与顺序、源文件存在、相对链接可达、片内锚点可达、合订逐字节一致、每卷有标题、禁用旧词（排除警示语境）、`instant` 不得作 `carrier` 枚举、`events` 只有 `hit`/`vanish`、AC 计数。

## 铁律（改这本书之前先看）

1. **只改分章源，不改合订本。** 合订本是生成物，手改会被下次 build 覆盖。
2. **改动分章后必须重跑 build + validate**，两者都过才算完成。
3. **已确认的 14 条决策（D-01…D-09、D-90…D-92、D-104、D-105）一字不动。**
4. **不扩充已冻结枚举**：`carriers` 只有 `none`/`self`/`independent`/`attached`；`events` 只有 `hit`/`vanish`。
5. **每次改动带 `〔YYYY-MM-DD 第N轮〕` 标注**，并在卷五登记。
6. **文档不覆盖已批准条款**；与代码冲突时记录差异，不自动改批准规则。
