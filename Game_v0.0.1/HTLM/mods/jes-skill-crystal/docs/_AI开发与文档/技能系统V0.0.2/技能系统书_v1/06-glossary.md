## 6.2 核心术语：模型、载体与生命周期

| 术语（中文） | 标识（英文/代码） | 定义（一句话，可判定） | 出处章节 | 易混项 |
|---|---|---|---|---|
| 效果体 | 说明词；实例字段表称 `instance` | 承载一段战斗行为的统一容器，生成、存活、命中、终止与回收均按同一生命周期解释。 | 基础 2.2；契约 5.1—5.3 | 不是某一个事件，也不要求每种效果体都能被击中 |
| 实例 | `instance`、`instance_id` | 效果体的一次运行时存在，生成时取得唯一 `instance_id` 与创建序号 `seq`。 | 基础 2.3；契约 5.4 | 积木、技能 CFG、施放次数 |
| 载体 | `carrier` | 按效果由谁承载及是否需要独立存活过程划分实例的四值类型。 | 基础 2.4；契约 8.1、36.4；C04-01 二 | 近战／远程不是载体类型 |
| 无载体 | `none` | 寿命为零、没有运动并以 `vanish(instant_end)` 结束的瞬时实例载体。 | 契约 8.2、5.5 | 无实例、瞬移、正寿命护盾 |
| 自身载体 | `self` | 由位移状态与跟随判定体组成、且只有跟随判定体拥有实例身份的载体。 | 契约 8.3；C04-01 三 | 位移状态本身不是实例 |
| 独立载体 | `independent` | 出手后独立运行、既可运动也可静止的实例载体。 | 契约 8.5 | 独立不等于必须飞行，也不等于召唤物 |
| 附着载体 | `attached` | 附着于 `anchor_target_id`、有寿命或明确终止条件、无空间运动且不进碰撞分桶的效果体载体。 | 契约 8.5A | 静止火区仍可为独立载体；纯数值状态不必建实例 |
| 瞬时实例 | `carrier=none`、`lifetime_ticks=0` | 无跨 tick 存活期的实例，出手创建者同 tick 完成适用接触与终止，派生创建者按 14.4 延至首个可接触 tick 判定。 | 基础 2.3；契约 5.5、14.4 | 瞬时不等于忽略派生延迟 |
| 生命周期 | `live → terminating → gone`；清理为 `live → gone` | 实例从生成到回收的过程，可有零到多次 hit，自然终止至多一条 vanish，purge 则直接回收。 | 契约 5.2—5.3、7.6 | 不是每一步只执行一次的线性链 |
| 存活状态 | `live` | 实例尚可按规则运动和产生 hit 的生命周期状态。 | 契约 5.3 | 存活不等于正在飞行 |
| 终止中状态 | `terminating` | 已确定自然终止原因、只处理 vanish 与派生而不再运动或产生新 hit 的状态。 | 契约 5.3、7.1 | 还未释放预算 |
| 已回收状态 | `gone` | 实例完成回收并释放预算后的状态。 | 契约 5.2—5.3 | 回收不是事件 |
| 寿命 | `lifetime_ticks` | 实例生成时确定的预定逻辑寿命，其中瞬时实例固定为零。 | 契约 5.4；Schema 3.1 | 不等于前摇、冷却或表现拖尾时长 |
| 终止原因码 | `vanish.reason` | 实例进入自然终止时确定且之后不再更改的冻结原因值，只能从七码表选择。 | 契约 7.1、36.3 | purge 是清理方式，不是第八码 |
| 施放 | `cast_id` | 玩家或怪物发起的一轮技能过程，从索敌到本轮结束对应一次施放身份。 | 基础 2.3 | 出手、hit、实例数 |
| 施法者闭环 | 说明词 | 索敌、前摇、出手、冷却构成的固定施放闭环。 | 基础 2.3；契约 4.2 | 不属于效果体的生命周期 |
| 出手 | `X`（一轮出手总次数） | 闭环中创建效果体或进入位移状态的瞬间，一次出手可生成零到多个实例。 | 基础 2.3；契约 5.2、10.1 | 齐发多个实例不自动增加出手次数 |
| 位移状态 | 说明词 | 施法者被占用且期间不能施放其他技能的运动状态，本身不分配实例编号。 | 基础 2.3；契约 8.3 | `self` 的跟随判定体 |
| 瞬移 | 说明词 | 出手当 tick 完成的零时长位移，没有路径判定体或位移存活期，落点效果须另建实例。 | 契约 8.4、8.7 | 高速冲刺、瞬时射线 |
| 召唤物 | `summon_cap`、`bind_owner` | 拥有独立施法者闭环并受召唤上限约束的效果体，默认随召唤者清场。 | 基础 2.3；契约 4.8、7.3、22.11 | 不是所有独立载体都具有施放能力 |

## 6.3 核心术语：积木与配置契约

| 术语（中文） | 标识（英文/代码） | 定义（一句话，可判定） | 出处章节 | 易混项 |
|---|---|---|---|---|
| 积木 | `brick`、`brick_id` | 有名字且有登记卡的能力预设，由一种载体的预设组合与默认参数构成。 | 基础 1.3、2.2；铁律四 | 不是运行时实例，也不是第五种载体 |
| 载体预设 | `carrier` 与 `default_cfg`（组合说明） | 积木用某一合法载体组织默认能力的配置组合，不另立载体枚举。 | 基础 1.3；铁律四 | 载体类型只是预设的组成部分 |
| 默认配置片段 | `default_cfg` | 积木可被同一 Schema 展开的能力默认片段，不得包含运行结果字段。 | 基础 3.3；Schema 1.2、2 | 默认值不是锁定权限 |
| 作者暴露参数 | `author_params` | 积木声明给作者填写的叶字段路径列表，必须能解析到 Schema 路径。 | 基础 1.3；Schema 2 | 作者可编辑不自动授权修饰器 |
| 修饰暴露参数 | `exposed_fields` | 允许修饰器按指定权限、范围及 live 标记修改的字段白名单，未列字段不可改。 | 契约 17.2；Schema 3.4 | 与 `author_params` 是不同开放边界 |
| 锁定参数 | `locked_params` | 以“字段→理由”登记的不可修改结构安全约束，覆盖命中锁字段即拒绝。 | 基础 3.3；Schema 1.2、2 | 不是界面暂时隐藏的高级项 |
| 积木修饰声明 | `relic_params` | 登记卡按字段声明“可改／可加／禁止”的边界，不直接等同运行时三权限。 | 基础 2.6；Schema 2 | “可改”不自动允许修改现存实例 |
| 技能配置 | `CFG`、`canonical_skill_cfg` | 编辑器写入、运行时读取的单技能定义契约，保存能力定义而不保存试运行实例状态。 | 基础 3.1、3.5；Schema 0、1.1 | 不是附录 B 契约摘要 |
| 配置结构规范 | `Schema` | 规定 CFG 字段结构、类型、必填项与枚举的数据契约，并配合语义校验约束合法组合。 | Schema 1、1.3 | YAML 能解析不等于配置合法 |
| 七顶层键 | `schema_version`、`skill_id`、`meta`、`bricks`、`params`、`presentation`、`runtime_hints` | 规范技能 CFG 必须同时具备且不得增减的七个根键。 | 基础 3.1；Schema 1.1 | `events` 是契约摘要键，不是第八个 CFG 键 |
| 结构版本 | `schema_version` | 声明文件结构与解释规则版本的字符串，当前固定为 `"0.1"`。 | 基础 3.1；Schema 1.1、6.1 | 文档版本、`meta.version` |
| 技能身份 | `skill_id` | 跨目录唯一且稳定的技能标识，采用 `<role>_<category>_<name>[_<variant>]`。 | 基础 3.2；Schema 1.1 | 中文名、`instance_id` |
| 元数据 | `meta` | 保存归属、显示信息、内容修订与设计说明的组织数据，不存实时战斗状态。 | 基础 3.1；Schema 1.1、`$defs.meta` | `origin` 是运行时来源链 |
| 积木列表 | `bricks` | 保存完整十二字段积木登记卡实例、用于展示和默认展开的数组。 | 基础 3.3；Schema 1.1、2 | 此处“卡实例”不是场上效果体实例 |
| 作者逻辑配置 | `params`（CFG 顶层） | 保存作者对默认值的逻辑配置、模板、份与触发关系，而不保存结算结果。 | 基础 3.1；Schema 1.1、3 | 实例也有 `params`，但两者不是同一可变对象 |
| 实例参数集 | `params`（instance 字段） | 实例生成时确定并按授权修改的实例级参数集合。 | 基础 3.5；契约 5.4、18.1 | 修改实例不得回写技能资产 |
| 表现配置 | `presentation`（CFG 顶层） | 包含 `fx/sfx/anim/trail/camera/damage_number/status_icon` 七段、不得反向改变逻辑的表现映射。 | 基础 1.5、3.1；Schema 4 | 卡内同名字段只是所需表现段引用集合 |
| 非功能提示 | `runtime_hints` | 提供已登记预算档位、分桶等非功能建议的配置段，不得绕过安全上限或承载必需战斗规则。 | 基础 3.1；Schema 5 | 不是隐藏技能定义或性能验收表 |
| 效果体模板 | `templates[]`、`template_id` | 用载体、索敌、寿命和份定义一个效果体配方的配置项，可在一个技能内组合多个。 | Schema 3.1—3.2 | 模板身份不是生成后的实例身份 |
| 内容版本 | `meta.version` | 标识技能内容修订的三段版本字符串，数值或组合变化递增此值。 | Schema 6.1、`$defs.meta` | 不靠修改此值改变 Schema 解释规则 |

**配置边界补注：**基础 3.3 曾将 `params.<brick_id>` 标为建议语法；Schema 1.2 已给出 `default_cfg → params → brick_overrides[]` 的规范化顺序。词表不把旧建议当成第二套正式寻址规则；锁定检查先于覆盖，数组整体替换，内部工序仍不可配置。

## 6.4 核心术语：份、事件、结算与记录

| 术语（中文） | 标识（英文/代码） | 定义（一句话，可判定） | 出处章节 | 易混项 |
|---|---|---|---|---|
| 份／结算份 | `part`、`parts[]` | 一次候选接触按份处理、在成立 hit 中承载伤害或非伤害效果的结算单位。 | 基础 2.2、2.5；契约 6.1、11、22.10 | 多份不是多条 hit |
| 份索引 | `part_index` | 识别 `parts[]` 中具体结算份的索引，而不是出手或实例编号。 | 基础 2.5；契约 36.4；Schema `$defs.part` | CFG 份定义与运行时份结果不可混写 |
| 伤害份 | `parts[]` 中的伤害类型 | 一条 hit 内独立判闪避、独立算减免的伤害结算单位。 | 基础 2.5；契约 10.5、11.1 | 无敌令伤害份视为闪避，不扩大到所有份 |
| 有益份 | `beneficial_parts`（摘要分类） | 治疗、护盾、增益类结算份，推荐默认不判闪避且不受无敌的伤害闪避规则影响。 | 契约 22.10、附录 B；D-58、D-90 | 此分类不是 `part.type` 的单个枚举值 |
| 有害非伤害份 | `harmful_non_damage_parts`（摘要分类） | 减益、控制、击退等非伤害份，按自身闪避规则与对应免疫标记处理而不因无敌一概取消。 | 契约 11.4、22.10、附录 B；D-104 | 不是伤害份，也不是必定生效 |
| 候选接触 | `candidate_contact`（摘要计次口径） | 实例与目标由不重叠变重叠或重复间隔到点的一次接触机会，每次只判一次逐份闪避。 | 契约 14.7、36.4 | 全闪避仍消耗候选接触额度 |
| 命中事件 | `hit` | 一次候选接触中至少一份未被闪避时成立且只发一条的事件，包含非伤害份。 | 基础 2.5；契约 6.1—6.2、36.2 | 最终伤害为零不等于无 hit |
| 自然终止事件 | `vanish` | 效果体自然终止时发出的带原因码事件，每实例至多一条。 | 基础 2.5；契约 6.3、36.2 | purge 不发此事件 |
| 清场／清理 | `purge` | 清场、卸载、阵亡清理或预算丢弃时不发 hit/vanish、不派生且不写结算记录的回收路径。 | 基础 2.5；契约 7.3、36.3 | 已发生结算不倒退，调试记录不属结算记录 |
| 技能事件 | `events` | 可驱动技能内部派生的冻结事件集合，成员只有 `hit` 与 `vanish`。 | 契约 6.1、7.2、36.2 | spawn、tick、暴击、击杀均不是新增事件 |
| 结算记录 | `settlement_records` | 记录已发生结果、供被动触发层只读消费的四类非事件对象。 | 基础 2.5；契约 6.4、36.5 | 与事件、调试记录分别计数 |
| 命中结算记录 | `hit_settled` | 一条 hit 成立并结算完毕后产生的记录，含合计、击杀标记及成立份的索引与类型。 | 契约 6.4、36.5 | 其 `parts[]` 无逐份金额或闪避字段 |
| 全闪避记录 | `evaded_all` | 一次接触全部份被闪避、没有 hit 时产生的记录。 | 契约 6.4 | 不是零伤害 hit，也不驱动 hit 派生 |
| 实际受伤记录 | `damage_taken` | 目标实际承受伤害后由受击侧写出的含 `target_id/total/origin` 的记录。 | 契约 6.4 | 不等同于所有成立 hit |
| 施放开始记录 | `cast_started` | 施放进入前摇时写出的记录，零前摇则在第一次出手前写入。 | 契约 6.4 | 不代表已生成实例 |
| 调试记录 | `debug_record` | 仅供测试、调试面板与性能分析读取且不得触发游戏逻辑的诊断对象。 | 契约 6.7、36.5、附录 B | 非事件、非结算记录；正式 UI 不读 |
| 最终份量值 | `final_amount` | 一份按运行时规则完成结算所得的量值，不是作者预填的答案。 | 基础 2.5；契约 36.4；Schema 3.2 | 与配置输入 `amount` 不同 |
| 减免至零标记 | `any_reduced_to_zero` | 标示成立 hit 中存在未闪避但被减免至零的份的结果标记。 | 契约 6.2、6.4.1 | 不是闪避，也不能把所有零值都叫免疫 |
| 击杀标记 | `killed` | 命中结算使目标死亡时保留在 hit 与 hit_settled 中的结果标记。 | 契约 6.2、6.5、14.5 | 不新增“击杀事件” |
| 被动触发层 | `triggers`（CFG 配置入口） | 读取结算记录后只能生成效果体或挂修饰器、不能直接造成伤害的独立层。 | 基础 2.6；契约 6.4、21；Schema 3.3 | 技能自身派生不订阅结算记录 |
| 重复命中规则 | `hit_policy` | 用每目标候选接触限额、重复间隔与实例总成立命中上限限制接触的规则集合。 | 契约 14.7、36.4 | `per_target_limit` 按接触计，`max_hits` 只按成立 hit 计 |

## 6.5 核心术语：时间、排序、随机与快照

| 术语（中文） | 标识（英文/代码） | 定义（一句话，可判定） | 出处章节 | 易混项 |
|---|---|---|---|---|
| 逻辑步 | `tick` | 技能逻辑推进与时间量计数的唯一基准，与渲染帧解耦。 | 契约 14.1 | 一个渲染帧可执行零个、一个或多个 tick |
| 固定步长 | `timestep: fixed` | 每次逻辑推进采用固定步长而不按渲染耗时改变技能计时的运行方式。 | 契约 14.1、14.9、附录 B | 慢动作改变每真实秒推进步数，不改各实例 tick 数 |
| 创建序号 | `seq` | 生成时分配、全局单调递增且永不复用的实例排序序号。 | 契约 5.4、14.3 | 与唯一身份 `instance_id` 的用途不同 |
| 先进先出 | `FIFO` | 事件先产生先处理，处理时新增事件追加队尾而不插队或递归深入的队列规则。 | 契约 14.3 | 同 tick 候选接触仍先按 seq、再按稳定目标标识排序 |
| 种子 | 种子化可注入 `RNG` 的输入 | 固定随机判定序列来源、使相同输入可重复得到相同随机结果的注入值。 | 契约 14.6、14.9 | 不是表现随机流，也不代替相同初态条件 |
| 逻辑随机源 | `rng: injectable_seeded` | 所有逻辑随机判定取值的可注入种子接口，抽取顺序按实例、目标、份稳定排序。 | 契约 14.6、附录 B | 表现 RNG 独立，不得推进逻辑随机序列 |

## 6.8 易混术语辨析表

| 对照组 | 差在哪 | 用错会怎样 | 判别例与出处 |
|---|---|---|---|
| 效果体 vs 实例 | 效果体强调统一模型，实例强调一次实际存在及身份。 | 用模型名替代实例计数，会漏计寿命、预算和来源。 | 一种飞弹能力生成三个实例，各有编号；基础 2.3、契约 5.4。 |
| 积木 vs 载体 | 积木是带默认参数的能力预设，载体是其运行时承载类型。 | 把每块积木登记为载体会破坏四值枚举；把载体当完整能力会漏参数。 | 飞弹和静止火区都可用 independent；基础 1.3、契约 8.5。 |
| 份 vs hit | 份是一次接触内逐份结算单位；hit 是至少一份未闪避后仅发一条的事件。 | 按份复制命中规则，会重复派生、重复音效或重复计次。 | 三份中两份成立仍只有一条 hit；基础 2.5、契约 11.6。 |
| hit vs hit_settled | 前者是技能内部派生入口并含逐份结果，后者是结算完成记录、含合计和成立份类型。 | 把记录加入事件选项会越过最小事件集；两份载荷重复求和会重计结果。 | hit_settled.parts 不含 final_amount/evaded；契约 6.4、6.4.1。 |
| vanish vs purge | vanish 是自然终止事件，可按原因派生；purge 是不发事件或结算记录的清理路径。 | 清场补 vanish 会制造本不该发生的结束爆炸与连锁。 | 附着体驱散或宿主消失走 purge；契约 7.3、8.5A、36.3。 |
| 事件 vs 结算记录 | 事件只有 hit/vanish，结算记录只有四种，消费方与用途分离。 | 技能派生订阅结算记录或被动直接扣血会绕开既定接口。 | 技能内部用 hit/vanish，被动读四种记录；契约 6.4、36.2、36.5。 |
| 派生 vs 分裂 vs 弹射 | 派生是创建子实例的总机制；分裂是 hit 派生子体并终止母体的行为；弹射保留原实例改向。 | 把弹射当派生会错加代数、错扣创建预算；把分裂当同实例会漏父子和家族登记。 | 连锁则创建子实例并递减 chain_remaining；契约 7.2、30.2。 |
| generation vs chain_depth | 前者只数派生，后者还数被动触发生成。 | 用代数替代因果深度会漏掉被动互触发循环。 | 派生后再被动生成使 chain_depth 再加一；契约 20.4、36.4。 |
| 无载体 vs 无实例 vs 瞬移 | none 仍有实例及 instant_end；瞬移是无路径判定体的零时长位移。 | 省掉瞬时实例会丢预算与 vanish；把瞬移写高速冲刺会产生路径命中。 | 落点爆炸与瞬移同次出手另生成；契约 5.5、8.2、8.4。 |
| 候选接触 vs 成立命中 | 接触先占候选额度，至少一份未闪避才成立 hit。 | 用成立 hit 才启动重复间隔会让全闪避后逐 tick 重掷。 | per_target_limit 按接触，max_hits 按成立 hit；契约 14.7。 |
| snapshot vs 实例 params vs CFG params | 三者分别是出手属性副本、生成时实例参数、作者保存的逻辑配置。 | 修改模板回写旧实例或把 L3 塞入快照，会破坏冻结时点与复现。 | 目标防御命中时取，施法者属性用快照；基础 3.5、契约 18.1、18.9。 |
| author_params vs exposed_fields vs locked_params | 分别回答作者能填什么、修饰器能改什么、哪些结构必须锁定。 | 将作者可填当实时可改会越权；只隐藏控件则可被文本导入绕过。 | live 修改需明确白名单和授权；Schema 1.2、2、3.4。 |
| 家族登记 vs 防霰弹 | 家族登记管母体与分裂后代的接触历史；防霰弹管同出手同时生成的独立实例。 | 共用开关会改变父子命中次数或错误抑制其他出手。 | 家族登记包含全闪避的接触；契约 14.8、30.2。 |

| 预算类别 | `P0` / `P1` / `P2` / `P3` / `P4` | 契约 15.2；附录 B budget_priority_levels=5；Schema runtime_hints 以引用承载，不硬编码档位目录 |

### 6.10.2 七种自然终止原因与清理对照

| 原因码 | 含义 | 发 vanish | 默认允许 vanish 派生 | 出处 |
|---|---|---|---|---|
| `hit_end` | 命中次数／穿透额度用尽；分裂母体也用此码 | 是 | 是 | 契约 36.3 |
| `range_end` | 距离／路径耗尽、距离型位移抵达终点，或 on_target_lost: terminate | 是 | 否，需显式声明 | 契约 36.3 |
| `landed` | 抛射体落到目标点／地面，仅限抛射 | 是 | 是 | 契约 36.3 |
| `expired` | 持续时间到期或固定时长位移结束 | 是 | 是，但到期不额外跳伤 | 契约 36.3 |
| `returned` | 回旋体回到施法者 | 是 | 是 | 契约 36.3 |
| `interrupted` | 被打断或被拦截，含位移打断 | 是 | 否，需显式声明 | 契约 36.3 |
| `instant_end` | 瞬时实例结束 | 是 | 是 | 契约 36.3；派生时序见 14.4 |
| 对照：`purge`，非原因码 | 清场、卸载、阵亡清理、预算丢弃 | 否 | 否 | 契约 36.3；附录 B is_reason_code=false |
