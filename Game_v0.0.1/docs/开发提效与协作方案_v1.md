# 开发提效与协作方案 v1

> 2026-10-24 | 状态：推荐方案，制作人可逐条增删
> 背景：Godot 落地进入玩法迁移期（P2 起），需要定「多 AI 怎么分工、钱花在哪、活怎么查」
> 成本约束：**WorkBuddy = 个人付费（省着用），其他 AI（本地 Claude CLI / 冰川 GPT 等）= 公司付费（重活派出去）**

---

## 一、成本分层的核心思路（一句话版）

**WorkBuddy 当大脑，公司付费 AI 当手脚。**

| 角色 | 负担的工作 | 为什么 |
|---|---|---|
| **WorkBuddy（省）** | 架构决策、方案设计、口径裁定、逐项复核、跑门禁、写文档骨架、拍板整理 | 这些是「少量 token、高价值」的工作——决定做对比做快重要 |
| **本地 Claude CLI / 冰川 GPT（公司付费）** | 机械对译（js→GDScript）、批量迁移、测试补齐、文档排版、枚举校验脚本 | 这些是「大量 token、低决策密度」的工作——出错也能被门禁兜住 |
| **门禁（免费）** | run_tests.sh 106 套 + tests/run_godot_tests.sh | 所有 AI 的产出一律过门禁，谁写错谁返工，不占你的钱 |

省钱不减能力的三个习惯：
1. **大文件不进 WorkBuddy 上下文**：js/config.js 3132 行这类，派 CLI 读和改，WorkBuddy 只看 grep 摘要与门禁结果；
2. **复核看差异不看全文**：CLI 交付后 WorkBuddy 只 `git diff` 逐项核对验收点；
3. **对话里少贴代码多给路径**：需要时 WorkBuddy 自己局部读（offset/limit），不整读。

## 二、并行开发流程（沿用已验证的六步法）

真源：`HTLM/G_docs/dev_standard_and_playbook.md` §5（D042 归档前的 106 套门禁就是这套流程跑出来的）。

1. **文档冻结**：先在 decision_log 登记（D045+），任务卡里的口径不许现场发挥；
2. **共享文件冻结**：index.html / project.godot / run_tests.sh / boot 等共享文件归主集成人串行，其他 AI 禁碰；
3. **拆任务卡**：每卡 = 独占文件集 + 验收标准 + 真源引用（「对译 js/xxx.js 第 N 行起」），禁止「你看着办」；
4. **并行执行**：本地 Claude CLI 用 `claude -p` 后台跑；冰川 GPT 做独立模块（文件集不交叉）；
5. **串行集成**：逐卡合并，每合并一卡跑一次对应门禁；
6. **门禁收口**：双门禁全绿（HTML 106 套 + Godot GUT）才算交付。

**任务卡模板**（给 CLI 的 prompt 必须自包含）：
```
目标：<一句话>
独占文件：<路径列表，其他文件只读>
真源：<HTLM/js/xxx.js 第 N~M 行，口径以它为准>
验收：<具体断言，如"bash tests/run_godot_tests.sh 全绿；函数名 ASCII">
禁止：<如"不改动 autoload/；不改 HTLM/ 内任何文件">
```

## 四、文档规范（对齐 skill-editor-godot-V201 口径）

参考项目已验证有效的结构，本项目从今天起执行：

```
docs/
├── 迁移总纲_v1.md            # 已有：阶段计划与映射表
├── 玩法问题诊断与修复方案_v1.md  # 已有：寻路/穿障
├── 开发提效与协作方案_v1.md      # 本文档
├── mods_registry_godot_v1.md   # Godot 侧模块注册表（唯一真源）
└── 决策日志 → HTLM/G_docs/decision_log_v1.md（全仓库唯一，不重复建）
```

模块内文档（jes-skills 已示范，后续模块对齐）：
- `docs/_AI开发与文档/`：**三分区**——`00_开工必读`（新人/AI 5 分钟上手）、`01_写内容`（怎么加数据）、`02_改代码`（怎么改逻辑）、`03_查规则`（口径查证）；
- `docs/_人工文档流程/`：给人看的操作手册；
- `docs/_重要资料记录/`：外部参考、拍板依据的存档；
- `docs/垃圾桶/`：废弃内容不删，移入归档（保留演进史）。

写作纪律（AI 二次开发友好的核心）：
1. 每份文档开头写「真源在哪、权威层级是什么」；
2. 规则条目必须带代码落点（文件:行号），行号会漂移的写函数名；
3. 拍板即回写：决策日志一行 + 权威章节替换（旧表述加「已被取代」横幅）；
4. 文档过时不可怕，**无痕过时**才可怕——改历史必须留痕。
