# 《巴别回路》美术资源需求清单 v1

> 日期：2026-10-25 ｜ 对应真源：《SRPG组队肉鸽策划书_v1.md》§6/§7 + 《资深游戏开发程序员提示词_v1.md》第 4 步收尾
> 口径说明：**9:16 竖屏**（提示词 v1 用户口径，覆盖策划书横版 1920×1080 描述）；棋盘采用「上棋盘、下信息」布局。
> 风格锚点：粗描边卡通（描边 4px 等宽）+ 泥塑质感（噪声贴图 20% 叠加）+ 青色霓虹 #35E0D8 + 暖沙 #D8B98A。
> 色板（主色 ≤ 6）：暖沙/骨白底、朱砂红 #C63D2F（敌）、松石绿（我方）、圣物金 #E8B33C、青色霓虹 #35E0D8。
> 单位造型：3 头身，头部占 40%，小尺寸剪影可读。竖屏基准画布 720×1280（@1x）。
