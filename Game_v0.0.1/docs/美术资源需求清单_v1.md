# 《巴别回路》美术资源需求清单 v1

> 依据：docs/SRPG组队肉鸽策划书_v1.md §6 UI 规格 / §7 美术与音效规格
> 基准分辨率：**9:16 竖屏 720×1280**（策划书原文为 1920×1080 横版，本文档按竖屏移植需求重排）
> 单位原图：256×256@2x（即设计稿 128×128 逻辑尺寸，输出 2 倍图）
> 风格锚点：粗描边卡通（4px 等宽描边）+ 泥塑质感（噪声贴图 20% 叠加）+ 科幻只走发光纹路（青色霓虹 #35E0D8）
> 全局主色 ≤ 6：暖沙 #D8B98A（底色）、骨白（辅底）、朱砂红 #C63D2F（敌方）、松石绿（我方）、圣物金 #E8B33C、青霓虹 #35E0D8
> 单位比例：3 头身，头部占 40%（小尺寸剪影可读）
> 优先级：P0 = 必需（缺了跑不通原型）；P1 = 增强（提升表现，可后补）
> 占位方案：① 色块占位（纯色矩形+文字标注）② draw 占位（程序化绘制：Canvas 简笔圆/线/环）——逐条标注

## 交付优先级摘要

- **P0 最小可跑集合**：6 祭司色块+3 段动作 → 4 种核心小怪 → 1 Boss → UI draw 占位全套 → 6 金圣物图标 → tileset_ch1_a + 地形格 hover → 5 首 BGM 换免费曲库 + 命中/格挡/预警/UI 约 25 条音效。
- **P1 完整表现集合**：12 祭司全动作+立绘变体、14 敌+6 Boss 全量、40 圣物+9 图腾图标、特效序列帧、tileset b 图与视差层、剩余 35 条音效。
