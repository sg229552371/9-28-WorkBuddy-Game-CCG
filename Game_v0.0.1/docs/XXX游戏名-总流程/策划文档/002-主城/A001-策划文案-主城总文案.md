## 一、这一屏是干什么的

**一句话**：主城是玩家的「家」。他每次打完一局回来，都在这里数结晶、升英雄、换武器、改名字，然后从这个家里再一次出门送死。

**它不是菜单。** 玩家在主城里是**一个小圆点**，要自己走过去找 NPC。走过去这件事本身，就是主城的意义——让玩家觉得「我有个据点」，而不是「我有个菜单列表」。

**三条设计底线**（太奶奶要求：不识字也能玩）

| 底线 | 具体做法 |
|---|---|
| 走过去就说话 | 不用点按钮，走进圈里面板自己弹出来。不会出现「不知道怎么打开」 |
| 一眼看出有几个地方去 | 地面上 9 个圆圈，每个圈一个颜色一个符号，从远处就能认 |
| 走错了也不要紧 | 走出圈，面板自己关。没有「必须点关闭」这种事 |

**这一屏在整款游戏三段式里的位置**

| 阶段 | 主城的作用 |
|---|---|
| 前期 30~60 分钟（学内核） | 玩家在「出征传送门 → 打一局 → 回主城」之间来回，主城只需要他能找到传送门 |
| 中期约 30 小时（构建流派、认识世界） | 主城是唯一的养成基地：升英雄、强化武器、收图鉴。这里是他「舍不得走」的地方 |
| 后期（毕业关 + 无限模式） | 深渊之门打开，主城多一个「不设上限」的出口 |

> **记住这句话**：主城不是用来玩的，是用来**犹豫**的。「再升一级就走」这句话，应该发生在这一屏。

## 三、界面布局（0 ~ 2080 像素横屏，其中地图比屏幕高）

### 3.1 先弄清一件事：地图比屏幕大

| 项目 | 数值 | 说明 |
|---|---|---|
| 屏幕 | 1280 × 720 像素 | 玩家眼睛看到的窗口大小 |
| 地图 | 1280 × 960 像素 | 主城这张「大纸」的大小 |
| 结果 | 横向正好，**纵向多出 240 像素** | 镜头必须上下跟着玩家跑，否则下半截看不见 |

> 太奶奶注意：**横向刚好装下，屏幕不会左右晃；纵向装不下，屏幕会上下跟着人跑。** 所以档案卡必须固定在屏幕角上，不然玩家往下走的时候，档案卡会被「甩出屏幕」。

## 五、这个界面能做和不能做的事

### ✅ 能做

| 玩家动作 | 结果 |
|---|---|
| 按 W A S D 走路 | 青点移动，速度 210 像素/秒 |
| 按方向键走路 | 同上（键盘两种都能用） |
| 走进 NPC 圈 | 右边自动弹出该 NPC 的面板 |
| 走出 NPC 圈 | 面板自动关闭 |
| 按 Esc | 如果面板开着，关掉它；如果没开，什么都不发生 |
| 走进出征传送门圈 | 圈上开始画金色读条，2 秒后弹出选关屏 |
| 走进深渊之门圈 | 圈上开始画金色读条，2 秒后……（见第七节的 ❌ 项） |
| 在面板里点按钮 | 扣结晶、升级、买货等，见各 B 文档 |

### ❌ 不能做（必须挡住）

| 情况 | 处理 |
|---|---|
| 站在门圈里反复刷读条 | 不许。同一个圈只触发一次，走出去再进来才重置（防「选关屏被反复弹回」的老 bug） |
| 没看完价格就点升级 | 不许弹出确认框。**主城不设确认框**，价格必须写在按钮上（「升级 ◆330」） |
| 在传送门读条中途走开 | 读条立刻清零，回来重新数 2 秒 |
| 名字改成一两个字或十个字 | 不许。名字限 2~8 个字，超了不给改 |
| 在面板里时继续走 | 允许（面板不锁移动），但走出圈自动关面板——这样玩家不用专门去关它 |
| 档案卡跟着人动 | 不许。档案卡钉在屏幕左上角，玩家跑到地图最下面也要看得见 |
| 一进主城就弹欢迎弹窗 | 不许。玩家刚从选关/结算回来，最烦弹窗 |

## 六、这一屏和其他文档的约定

| 对象 | 约定 | 数据从哪来 |
|---|---|---|
| 名字 | 档案卡显示玩家的名字，没名字显示「无名旅者」 | `GameState.meta.profile_name()`（刷新档案卡第 105 行） |
| 称号 | **目前写死「初出茅庐」**，没有映射表 | 刷新档案卡第 101、106 行注释已注明 |
| 结晶 | 档案卡右上「✦数字」，每次升级/购买后立刻刷新 | `GameState.meta.crystals()`（第 99、104 行） |
| 英雄列表 | 强化导师面板里一行一个英雄 | `hero_growth.gd` 的英雄花名册 |
| 武器列表 | 武器匠面板里一行一个武器 | `cfg/weapons.json` |
| 升级成本 | 英雄升级成本在 `hero_growth.gd` 里算，**本文不写具体公式** | 见 `B003` |
| 强化成本 | 武器强化成本公式：先把成本按倍率乘上去，再向上取整到指定倍数 | 第 397~401 行，参数读 `cfg/weaponLevel.json` |
| 图鉴内容 | 只有**怪物**，没有英雄 | `cfg/monsters.json`（第 475 行） |
| 货架内容 | 商人卖的服务清单 | `cfg/artisanServices.json`（第 420 行） |
| 名字长度 | 2~8 个字 | `cfg/profile.json`（第 500~503、509 行） |
| 谁能进城 | 只有从主菜单点「开始游戏」进来 | `001-主菜单` B001 |
| 出征去哪 | 通知流程控制：「弹出选关屏」，主城不切场景、不消失 | 第 162~164 行 |

**三条重要的边界约定**

1. **主城不负责战斗。** 主城只负责「说我准备好了」。加载关卡、抽英雄、算波次全是别的地方的事。
2. **主城不负责存盘规则。** 它只往存档里写名字和等级，什么时候落盘由存档系统决定。
3. **主城不负责称号。** 称号表是别的屏的事，主城只负责「显示」，没有就不显示——但现在代码把它写死成「初出茅庐」，等于给所有玩家戴了一顶假帽子。
