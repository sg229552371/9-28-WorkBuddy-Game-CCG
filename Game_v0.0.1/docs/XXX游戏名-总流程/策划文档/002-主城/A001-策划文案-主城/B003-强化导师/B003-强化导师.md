## 一、这个功能是干什么的

**一句话**：主城里**唯一一个能让英雄变强的地方**。玩家花结晶，把某个英雄的「局外等级」往上买一级。

**「局外等级」是什么，说人话**：你在关卡里捡到的东西，死了就全没了——但**你在这里买的等级不会没**。局外等级就是「上次死掉也没白死」的那部分。它决定你下一局开局有多少血、有多少底子。

**为什么这个功能是主城的心脏**：整款游戏的核心情绪是「舍不得走」——玩家反复回主城，绝大多数时候就是为了来这里点一下「升级」。**这一下点击是整款游戏的奖励兑现点。** 别的都能凑合，这个不能。

**对新手（前 30~60 分钟）的意义**：第一局打完可能只够升一级。那一次升级必须**特别清楚地让他看到「我变强了」**，否则他不会回来。

## 三、点「升级」以后发生什么（完整流程）

```
玩家控制青点走进紫色圈 → 面板自动弹出
   ↓
① 玩家把鼠标移到某个英雄右边的按钮上               0 秒
   ↓
② 按钮亮起来（鼠标变手形）                        0 秒
   ↓
③ 玩家点下去「升级 ◆330」                        0 秒
   ↓
④ 系统检查两件事：结晶够不够？满级了没有？          瞬间
   ↓
⑤ 都通过 → 扣掉 330 结晶，这个英雄等级 +1           瞬间
   ↓
⑥ 左上角档案卡的结晶数字变小                        瞬间
   ↓
⑦ 面板整个重新画一遍（成本数字也跟着变贵了）          瞬间
   ↓
⑧ 玩家看到「Lv.3 → Lv.4」，钱的数字从 ✦1200 变成 ✦870
```

**耗时**：**小于 0.1 秒**。点了就变，不许转圈等待。

**为什么第 ⑦ 步要整个重画**：因为升级后下一级的成本会变（越升越贵）。如果只改数字不改成本，玩家会一直点，然后莫名其妙发现钱扣多了。

**升级一次之后，成本会涨。** 涨多少由 `hero_growth.gd` 的规则决定，本文档不写具体数值——**但界面上必须把下一个数老老实实写出来**，让玩家自己判断「还升不升」。

## 四、各种状态

### 4.1 NPC 圈的四态

| 状态 | 什么时候 | 样子 |
|---|---|---|
| **常态** | 玩家不在圈里 | 紫色虚线圆，透明度 70%，头顶名字 + 副标题正常 |
| **悬停 / 靠近** | 玩家走进圈（76 像素内） | 圈变实（100%），**面板立刻弹出** |
| **按下** | 无此状态 | 圈不是按钮，没有「按下」 |
| **禁用** | 不会出现 | 这个 NPC 永远在。就算没有英雄可升，他也站着 |

### 4.2 升级按钮的四态

| 状态 | 什么时候 | 样子 |
|---|---|---|
| **常态** | 结晶够、没满级 | 亮底，可点，「升级 ◆330」 |
| **悬停** | 鼠标移上去 | 按钮提亮，鼠标变手形 |
| **按下** | 按住没松 | 按钮压暗一点 |
| **禁用（已满级）** | 这个英雄到了 46 级 | 灰底灰字「已满级」，点不动 |
| **结晶不足**（**现在是真事**） | 钱不够 | 按钮**看起来还是能点**，点了什么也不发生，只在后台记一条警告。**这是个问题，见第十节** |

## 五、声音 / 反馈

| 时机 | 现在有没有 | 建议 |
|---|---|---|
| 走进圈、面板弹出 | ❌ 没有 | 一声轻「唰」（25%），像拉开抽屉 |
| 鼠标移到升级按钮 | ❌ 没有 | 极轻的「嗒」（20%） |
| 点击升级成功 | ❌ 没有 | 「叮——」+ 一声短促的上升音（60%）。**这是全游戏最该有音效的地方** |
| 升级后等级数字变化 | ❌ 没有 | 等级数字闪一下，由白变金再变回白，0.4 秒 |
| 结晶扣掉的反馈 | ❌ 没有 | 档案卡上的数字往下掉一下（见 B002） |
| 结晶不足时点击 | ❌ 没有 | 按钮抖一下 + 一声低沉的「咚」（40%），**别用「错误」那种刺耳音** |
| 已满级按钮被点 | ❌ 没有 | 不要有反应。灰按钮点了没反应是对的 |

> **现在一个音效都没有。** 如果只能加一个音效，就加「升级成功」的那一声。

| 情况 | 处理 | 玩家看到什么 |

| 结晶不够 | **不扣钱、不升级**，后台记日志 | 现在：什么也看不出来（要改成：按钮抖一下 + 变灰） |

## 七、这个功能不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| 弹出「确定要花 330 结晶吗」 | 每升一级弹一次，玩家会被烦死。**主城不设确认框** |
| 升级后不刷新成本数字 | 玩家会以为「升了还是这个价」，然后钱被扣光 |
| 结晶不够时偷偷扣成负数 | 绝对不行。要么够，要么不给升 |
| 升级成功后关掉面板 | 玩家通常要连升好几级。关掉他就得走出去再走进来 |
| 用「经验值」概念 | 这里是「直接花钱买等级」，中间不塞一道「攒经验」的墙 |
| 显示百分比、进度条 | 一级就是一级，写清楚 Lv.3 比画个 73% 的条清楚一百倍 |
| 让英雄列表可滚动但没提示 | 如果英雄超过 10 个，必须有可见的滚动条，否则玩家以为只有 10 个英雄 |
| 把成本数字写死进文档 | 成本是 `hero_growth.gd` 算的，调平衡时会改。文档不许抄死数字 |

## 八、和其他文档的约定

| 对象 | 约定 |
|---|---|
| 输入 | 走进圈（自动开面板）+ 点「升级 ◆N」按钮 |
| 输出 1 | 改英雄的局外等级，存进存档 |
| 输出 2 | 扣结晶，扣完通知档案卡刷新（第 364 行） |
| 依赖 | `hero_growth.gd` 提供：英雄花名册、当前等级、升一级要多少钱、能否升级 |
| 依赖 2 | `cfg/heroes.json` 之类的英雄配置（英雄名从那里读） |
| 和 `B002-档案卡` | 升级成功必须让左上角的结晶数字跟着变 |
| 和 `B004-武器匠` | 两个面板长得几乎一样，但一个花结晶升「人」，一个花结晶升「武器」。**玩家容易搞混，所以颜色必须不同**（导师紫、武器匠金） |
| 和 `005-战斗` | 这里买的等级，下一局开局就要生效。主城不管怎么生效，只负责写进存档 |
