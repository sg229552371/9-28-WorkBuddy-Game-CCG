## 一、这个功能是干什么的

**一句话**：**现在什么也不干。** 玩家走进去，只看到一句话：「赛季系统尚未开放，敬请期待」。

**它是主城里唯一一个「完全没有功能」的点位。** 别的 NPC 至少能买、能升、能改，它连个按钮都没有。

**它的存在本身就是一个矛盾**（这是本文档最想指出的事）：

| 主城里有什么 | 该有的配套 | 现状 |
|---|---|---|
| 有一个「赛季使者」NPC，头顶写「赛季挑战大厅」 | 应该有一扇通到赛季大厅的门 | **`seasonPortal` 配置里是 `null`，门根本没有** |
| 有一句「赛季系统尚未开放」 | 应该有个大概的时间或条件 | **没有，永远都是这句** |
| 玩家能看到这个 NPC | 至少应该能点出点什么 | **面板里一个字都没有多的** |

> 太奶奶用一句话总结：**门口挂了个「赛季大厅」的招牌，推门进去是个空房间，墙上贴着一张「装修中」。而且连通往这个房间的门本身也不存在。**

## 三、走进圈以后发生什么

```
玩家走进亮蓝 ◈ 圈
   ↓
① 圈变实，右边面板弹出                   0 秒
   ↓
② 面板显示标题 + 副标题 + 一句申请         瞬间
   ↓
③ 玩家看着这句话，没有任何东西可以点        —
   ↓
④ 玩家一般会：等两秒，确认确实没东西 → 走开   2~5 秒
   ↓
⑤ 走出圈 → 面板自动关                    0 秒
```

**耗时**：**打开瞬间，但玩家的失望是即时的**。

**这个流程最大的问题**：玩家为了这一个面板，必须先在地图上找到这个 NPC、走过去、看着它弹出来、再确认「哦，什么都没有」。**这一整段路是白走的。** 主城里的走路是宝贵的——每一步都该有回报。

## 四、各种状态

### 4.1 NPC 圈

| 状态 | 什么时候 | 样子 |
|---|---|---|
| **常态** | 不在圈里 | 亮蓝虚线圆，70% 透明。**看起来和别的 NPC 一模一样** |
| **悬停 / 靠近** | 走进 76 像素内 | 圈变实，面板弹出 |
| **按下** | 无 | 圈不是按钮 |
| **禁用** | **应该禁用，但现在没有** | 它看起来是个正常可用的 NPC |

> **这是关键问题**：一个完全没功能的 NPC，**在视觉上应该让人一眼看出「这里还没开」**——比如圈变暗灰、符号变成一把锁、头顶副标题写「未开放」。现在它和强化导师长得一样有活力。

### 4.2 面板

| 状态 | 什么时候 | 样子 |
|---|---|---|
| **常态** | 打开时 | 三行字，没有按钮 |
| **悬停** | 鼠标移上任何地方 | 无变化（因为没有任何可点的东西） |
| **按下** | 鼠标点任何地方 | 无反应 |
| **禁用** | 不会出现 | 这个面板没有「可用」状态 |

| 时机 | 现在有没有 | 建议 |

| 面板弹出 | ❌ 没有 | **如果保留这个 NPC**：加一声很轻、有点「空」的回声（25%），暗示「这里还没有东西」 |

> **现在一条音效都没有。** 这里不是「缺音效」，这里的问题是**玩家走过来本来就是白跑一趟**。

## 六、异常情况怎么处理

| 情况 | 处理 | 玩家看到什么 |
|---|---|---|
| 赛季还没做 | 显示那一句话 | 一句「敬请期待」。**这是现在唯一的行为** |
| **`seasonPortal` 是 `null`** | 主城里根本没有赛季之门 | 玩家找不到通往赛季大厅的路。**但 NPC 又告诉他「有赛季挑战大厅」** |
| 玩家反复走进去 | 每次都弹同一句话 | 玩家会记住「这里没用」，以后绕开走 |
| 玩家问「什么时候开」 | 没有答案 | 没有答案 |
| 面板开着走了 | 自动关闭 | — |

## 七、这个功能不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| 用「敬请期待」当唯一内容 | 这句话是给开发自己看的，不是给玩家看的。玩家看到的是「**这游戏没做完**」 |
| 摆一个能走进去但没功能的 NPC | 玩家会走过去、花时间、失望。**不如不摆** |
| 副标题写「赛季挑战大厅」，但门不存在 | **现在就是这样。** 说了有个大厅，但根本没修通往大厅的路 |
| 在视觉上和其他 NPC 一样活泼 | 一个死掉的功能看起来和活的一样，是最让人失望的设计 |
| 承诺具体时间又做不到 | 不许写「下周开放」这种话 |
| 让玩家以为打完了就有赛季 | 玩家会一直惦记一个不存在的东西 |

## 八、和其他文档的约定

| 对象 | 约定 |
|---|---|
| 输入 | 走进圈。**没有按钮** |
| 输出 | **无。它什么都不做，不写任何数据** |
| 依赖 1 | 赛季系统的整体设计（**目前不存在**） |
| 依赖 2 | `seasonPortal` 的配置（**目前是空的**） |
| 和 `B007-神秘商人` | 两个 NPC 用同一个符号 ◈，必须改掉其中一个 |
| 和「赛季」相关的未来文档 | 赛季真做起来，应该是「大厅 → 赛季任务 → 赛季奖励」一整套。**现在连大门都没有** |
| 和主城布局 | 它在地图右下偏中（870,595），视野内很显眼。**一个空壳占了主城一个显眼的位置** |

## 九、实现状况

| 项目 | 状态 | 说明 |
|---|---|---|
| 亮蓝 ◈ 圈 + 头顶文字 | ✅ 有 | 位置 870,595。**但它看起来和能用的 NPC 一样** |
| 走进圈弹面板 | ✅ 有 | — |
| 面板标题 + 副标题 | ✅ 有 | 「赛季使者」/「赛季挑战大厅」 |
| 面板正文 | ❌ **空壳** | 只有「赛季系统尚未开放，敬请期待」一句 |
| 任何可以点的东西 | ❌ 没有 | 一个按钮都没有 |
| **赛季传送门** | ❌ **不存在** | `seasonPortal` 配置是 `null`（第 15 行），主城里根本没有这扇门 |
| 「未开放」的视觉提示 | ❌ 没有 | 圈和其他 NPC 一样亮 |
| 音效 | ❌ 没有 | — |

**要补的**：二选一——**要么做**（先做一扇门 + 一个能玩的赛季任务入口），**要么藏**（把 NPC 从配置里删掉，赛季做好再放回来）。中间状态「摆着但不能用」是最差的。

> 真话：**这个 NPC 目前的全部价值是「告诉玩家这里以后会有一个赛季」。** 但这句「以后」，玩家已经听了一整轮了。而且它还暴露了另一件事——`seasonPortal` 配置是空的，说明**做这个 NPC 的时候，后面那扇门压根还没开始做**。这是典型的「先摆招牌，后盖房子」。
