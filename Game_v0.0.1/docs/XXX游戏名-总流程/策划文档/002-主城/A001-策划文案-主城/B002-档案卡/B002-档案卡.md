# B002-档案卡

> 父级：`002-主城`　｜　版本 v1.0　｜　2026-10-26
> 对应代码：`mods/jes-city/scripts/city_visual.gd` 第 43~51 行（建界面层）、第 54~90 行（搭档案卡）、第 96~111 行（刷新卡片内容）

---

## 一、这个功能是干什么的

**一句话**：屏幕左上角那张巴掌大的小卡，永远显示三样东西——**你是谁、你什么称号、你有多少结晶**。

**它不能点。** 这是故意的。玩家想改名字，得去找形象师；想看自己有几个英雄，得去找强化导师。档案卡只负责「随时提醒你是个什么样的人」。

**为什么它必须钉在屏幕上**：主城地图比屏幕高（1280×960 的地图，1280×720 的屏幕），镜头会上下跟着玩家跑。如果档案卡画在地图上，玩家走到地图最下面时，这张卡就跟着跑到屏幕外面去了——**玩家攒了一整天结晶，回来却看不到数字**，这是最扫兴的事。

**所以**：档案卡挂在「屏幕层」上，不挂在「地图层」上。玩家怎么跑，它都在左上角 (16,12) 一动不动。

## 二、界面长什么样

### 2.1 卡片外壳

| 项目 | 规格 | 出处 |
|---|---|---|
| 位置 | **屏幕坐标 (16, 12)**，左上角往右 16 像素、往下 12 像素 | 第 64 行 |
| 宽度 | 自动撑开（内容多宽它就多宽），最窄大约 90 像素 | 容器自动布局 |
| 高度 | 自动撑开，大约 48 像素 | 容器自动布局 |
| 底色 | 深色半透明 `rgba(0.07,0.11,0.18,0.9)` | 第 57 行（引用 `STAMP_BG`） |
| 圆角 | 8 像素 | 第 58 行 |
| 内边距 | 左右各 12 像素，上下各 6 像素 | 第 59~62 行 |
| 边框 | **没有边框** | — |
| 是否随镜头移动 | **不移动** | 挂在屏幕层（第 43~47 行建的 `CanvasLayer`，层号 10） |

### 2.2 卡片里的四样东西（从左到右排一行）

| 位置 | 内容 | 字号 | 颜色 | 出处 |
|---|---|---|---|---|
| 第 1 格 | ✦ 一个金色小星 | 18 号 | 金色 `#ffd76a` | 第 67~71 行 |
| 第 2 格（上排） | 玩家的名字，默认「无名旅者」 | 16 号 | **纯白** `#ffffff` | 第 74~77 行 |
| 第 2 格（下排） | 称号，**目前写死「初出茅庐」** | 12 号 | 灰蓝 `rgba(0.65,0.7,0.78)` | 第 78~81 行 |
| 第 3 格 | ✦ 加数字，例如「✦330」 | 16 号 | 金色 `#ffd76a` | 第 83~87 行 |

**格与格之间**：间隔 8 像素（第 66 行）。名字和称号上下贴紧，中间不留空（第 73 行间隔 0）。

### 2.3 实际长什么样

```
┌────────────────────────────────────┐
│  ✦   无名旅者              ✦330    │  ← 名字 16 号白
│      初出茅庐                      │  ← 称号 12 号灰
└────────────────────────────────────┘
  ↑                    ↑
  徽章 18 号金         结晶 16 号金
 (16, 12) 起，卡片宽高跟着内容走
```

### 2.4 为什么用「✦」当徽章

整款游戏里 **✦ 就是结晶**（一种攒起来花在英雄升级上的东西）。左上角先来一个 ✦，再是名字，最后一排 ✦330 —— 一头一尾都在说「钱」。玩家扫一眼就知道：**我叫啥、我有多少钱**。中间夹着称号，是「我混到什么位置」。

## 三、它什么时候刷新（这不是按钮，所以没有「点击」，只有「变化」）

```
玩家做了一件事（升级英雄 / 强化武器 / 买东西 / 改名字）
   ↓
① 那件事的代码做完自己的活                    0 秒
   ↓
② 通知档案卡「重新读一遍数据」                0 秒
   ↓
③ 档案卡重新读三样：结晶数、名字、称号        0 秒
   ↓
④ 卡片上的数字/文字立刻变                     0 秒（同一帧）
```

**耗时**：**0 秒，玩家感觉不到延迟**。结晶是当场扣、当场变的。

**什么时候会刷新**（代码里实际调用的地方）：

| 触发点 | 出处 |
|---|---|
| 主城刚建好 | 第 90 行 |
| 强化导师升级成功 | 第 364 行 |
| 武器匠强化成功 | 第 413 行 |
| 神秘商人买到东西 | 第 458 行 |
| 形象师改名成功 | 第 517 行 |

## 四、各种状态

| 状态 | 什么时候 | 样子 |
|---|---|---|
| **常态** | 任何时候 | 深色半透明卡，三样内容都显示 |
| **悬停** | 鼠标移上去 | **无变化**。它不是按钮，鼠标不会变手形 |
| **按下** | 鼠标点它 | **无反应**。点了不掉血、不掉钱 |
| **禁用** | 不会出现 | 这张卡永远显示，没有「隐藏」状态 |
| **没读存档** | 存档系统没准备好 | 名字显示「无名旅者」，称号「初出茅庐」，结晶显示 ✦0。后台会记一条警告日志，**玩家什么也看不出来** |
| **名字超长** | 名字改到 8 个字（上限） | 卡片自动变宽，不换行、不省略 |

> **重要**：不要让档案卡的宽度盖住别的界面。主城右边是 NPC 面板（从横 810 起），档案卡最多撑到 200 像素宽，两者永远不会碰。

## 五、声音 / 反馈

| 时机 | 现在有没有 | 建议 |
|---|---|---|
| 玩家点它 | ❌ 没声音 | **保持没声音**。它不可点，千万别加「点了有声音」——那会让玩家以为能点开 |
| 结晶数字变化 | ❌ 没有 | 加一个「数字往上蹦一下 + 由白闪到金」的小动画，0.3 秒。数字变大时明显能看见 |
| 结晶减少（花钱） | ❌ 没有 | 数字往下掉一下，同时淡红闪 0.2 秒。**让玩家看见钱少了**，这比「确认框」更有说服力 |

> **当前完全没有反馈。** 玩家点了个「升级 ◆330」，面板刷新了，但左上角的结晶数字**在他视野边缘悄悄变了**——他很可能没注意到。数字动一下，比什么音效都管用。

## 六、异常情况怎么处理

| 情况 | 处理 | 玩家看到什么 |
|---|---|---|
| 存档系统读不出来 | 用默认值兜底，后台记一条日志 | 「无名旅者 / 初出茅庐 / ✦0」。**不许弹报错框** |
| 名字是空的（存档里存了个空白） | 用默认名「无名旅者」 | 正常显示默认名 |
| 名字里带特殊符号 | 照显示，不做过滤 | 那就显示。过滤是形象师（B005）那边的事 |
| 结晶是负数（理论上不该有） | 照显示 | 「✦-5」。**这是 bug 的信号，不许偷偷改成 0** |
| 称号映射表没做 | 显示写死的「初出茅庐」 | 所有玩家都一样。这是**已知的假数据**，见第九节 |

## 七、这个功能不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| 让它可点 | 玩家点了没反应会以为坏了。不可点的东西就必须「看起来不可点」 |
| 跟着镜头上下跑 | 它挂在屏幕层，不是地图层。跟着跑就失去了「随时看得见」的意义 |
| 显示全部数据（英雄数、武器数、图鉴进度） | 一张小卡塞不下。玩家想看详细数据，去找对应的 NPC |
| 称号写死还不说 | **现在就是这么干的。** 必须尽快接上真的称号表 |
| 把结晶「四舍五入」简化显示（如 ✦1.2k） | 主城的结晶一般不超四五位数，直接显示全数更好 |
| 主城加载失败时也显示卡片 | 如果主城根本没建起来，卡片会出现一个「孤儿卡」浮在黑屏上 |

## 八、和其他文档的约定

| 对象 | 约定 |
|---|---|
| 输入 | 无玩家输入。它只读数据 |
| 输出 | 无。它不通知任何人 |
| 依赖 | 存档系统必须能给出：结晶数、名字 |
| 依赖 2 | **称号目前没有数据源**，写死「初出茅庐」（第 101、106 行注释已写明「称号映射表尚未建表」） |
| 和 `B005-形象师` 的关系 | 形象师改名成功后，档案卡立刻显示新名字（第 517 行 → 第 96 行刷新） |
| 和 `001-主菜单` 的关系 | 主菜单底部那行「无名旅者 ·「初出茅庐」 · ✦330」是同一个数据源，两处必须一致 |
