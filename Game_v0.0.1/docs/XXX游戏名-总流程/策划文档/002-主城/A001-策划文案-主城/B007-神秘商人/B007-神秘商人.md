## 一、这个功能是干什么的

**一句话**：花结晶，在货架上买几件东西塞进包里。

**它的位置有点尴尬，必须说清楚**：这个 NPC 头顶的副标题写的是「敬请期待」——也就是「还没开放」。但玩家走进去，**面板里摆着一个能买、能刷新、还能显示买了多少件的真货架**。

> **这是一个明显的自相矛盾。** 门口挂着「还没开张」，推门进去发现已经在做生意了。玩家会觉得「这游戏到底做完了没有」。**必须在两者之间选一个**（见第十节）。

**它应该起什么作用**：如果要做，它就该是主城里唯一一个「花小钱赌一把」的地方——买的东西是随机的、可能没用，也可能很关键。这和强化导师那种「稳赚」的升级完全相反，形成互补：**钱稳着花找人升，钱浪着花找商人。**

## 三、点按钮以后发生什么

### 3.1 点「购买」

```
玩家走进橙黄 ◈ 圈 → 面板弹出，货架上有几行商品
   ↓
① 玩家点某一行右边的「购买」                     0 秒
   ↓
② 系统按这一行的编号去找商品、算价钱               瞬间
   ↓
③ 检查结晶够不够                                 瞬间
   ↓
④ 够 → 扣结晶，东西塞进背包                       瞬间
   ↓
⑤ 左上角档案卡结晶变小                            瞬间
   ↓
⑥ 面板重画，「已购入」的数字 +1                    瞬间
```

**耗时**：**小于 0.1 秒**。

### 3.2 点「刷新货架」

```
玩家点「刷新货架」
   ↓
① 重新掷一次随机数                               瞬间
   ↓
② 面板整个重画                                   瞬间
   ↓
③ 玩家看到（理论上）不一样的货                     瞬间
```

**耗时**：**瞬间**。

> ⚠️ **这里有个真问题**：代码里「刷新」只是重掷了一次随机数，**但货架上的商品是从固定清单里按顺序读出来的，并没有用上这个随机数**（第 420~432 行是遍历整份服务清单，没有随机挑选）。也就是说——
> **现在点「刷新货架」，货架根本不会变。** 玩家会以为按钮坏了。

## 五、声音 / 反馈

| 时机 | 现在有没有 | 建议 |

| 面板弹出 | ❌ 没有 | 轻「唰」（25%） |

## 六、异常情况怎么处理

| 情况 | 处理 | 玩家看到什么 |
|---|---|---|
| 结晶不够 | 不扣钱、不给东西，后台记日志 | 现在：没反应（要改：按钮变灰 + 抖） |
| 服务清单是空的 | 面板只剩标题、「刷新货架」和「已购入 0 件」 | 一个能刷但刷不出东西的面板 |
| 反复买同一件 | **允许，无限买** | 已购入数字一直涨 |
| 刷新货架 | **货架内容不变** | 玩家以为刷新坏了 |
| 背包满了 | **没有「满」的检查** | 买的东西会一直往背包里塞 |
| 商品数据有问题 | 整条购买失败，只记日志 | 没反应 |
| 面板开着走了 | 自动关闭 | — |

## 七、这个功能不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| 门口写「敬请期待」但里面能买东西 | **现在就是这样。** 这是骗人，也是最容易被玩家截图吐槽的地方 |
| 货架上显示内部编号（`SV_01`） | 玩家看不懂。**必须显示商品名 + 价格** |
| 不写价格就让人点购买 | 玩家不知道自己花多少钱。**这是主城里唯一必须显示价格的地方之一** |
| 免费无限刷新 | 那「随机」就没有意义了，玩家刷到满意为止 |
| 「刷新」按钮点了没反应 | 现在就是这样，玩家会认为游戏坏了 |
| 买完不给任何确认 | 至少要让「已购入」的数字跳一下 |
| 让它变成第二个强化导师（稳定变强） | 商人的价值就是「不确定」。稳赚的东西去找导师和铁匠 |
| 买的东西直接进战斗背包、下一局就一定带 | 这里的定位是「攒着用」，具体怎么用归别的文档管 |

## 八、和其他文档的约定

| 对象 | 约定 |
|---|---|
| 输入 | 走进圈 + 点「购买」/「刷新货架」 |
| 输出 | 扣结晶、往背包塞东西、通知档案卡刷新（第 458 行） |
| 依赖 1 | `cfg/artisanServices.json` 提供货架清单——**但这份表里只有内部编号，没有名字和价格说明**，这就是界面上显示 `SV_01` 的原因 |
| 依赖 2 | `shop.gd` 负责「买」的全部规则（真假判定、扣钱、给东西） |
| 和 `B003-强化导师` / `B004-武器匠` | **互相补充，不是互相替代。** 那两家稳、这家赌 |
| 和「背包」 | 买到的东西进的是「背包」，不是「装备」。**全游戏规定：装备存背包不自动穿。** 这里也一样 |
| 和「局内流派」 | 流派靠局内临时搭配，这里买的是「带进去的材料」，不是「直接变强」 |
