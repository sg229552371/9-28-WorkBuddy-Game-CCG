## 一、这个功能是干什么的

**一句话**：一面「你见过哪些怪物」的墙。见过的是亮的、写着名字；没见过的是一块暗块，写着 `???`。

**它管的是「收集欲」，不是「变强」**。玩家来这里不花钱、不变强，只为了看一眼「我还差几个」。

**为什么这个东西对这款游戏特别重要**：整款游戏的目标是「中期约 30 小时认识世界 + 意外惊喜」。**图鉴就是把「我见过什么」变成看得见的进度条。** 玩家打了一整晚，回主城打开图鉴，多亮了 3 格——这 3 格就是「今晚没白打」的证据。

**它也是一张「预告片」**：那些 `???` 暗块在告诉玩家「这游戏里还有你没见过的东西」。**暗块比亮块更有用。** 一片 `???` 让玩家心里痒，这就是「舍不得走」的燃料。

## 三、走进圈以后发生什么

图鉴**没有按钮**，进圈就等于打开，所以这个流程很短：

```
玩家走进蓝色 ❖ 圈
   ↓
① 圈变实，右边面板弹出                           0 秒
   ↓
② 面板把怪物配置整个读一遍                        瞬间
   ↓
③ 挨个查：这只怪物在不在「已收录」名单里           瞬间
   ↓
④ 在 → 画彩色块 + 怪物名                          瞬间
   不在 → 画暗块 + ???
   ↓
⑤ 4 列一行，排满往下长                            —
   ↓
⑥ 玩家自己上下看                                  —
   ↓
⑦ 走出圈 → 面板自动关                            0 秒
```

**耗时**：**打开就是瞬间**。

> **注意**：这个面板**没有滚动功能**。怪物一多，格子会一直往下长，长到屏幕外面去，玩家就看不到了。这是**现在的一个实际问题**（见第九节）。

## 四、各种状态

### 4.1 NPC 圈

| 状态 | 什么时候 | 样子 |
|---|---|---|
| **常态** | 不在圈里 | 蓝色虚线圆，70% 透明 |
| **悬停 / 靠近** | 走进 76 像素内 | 圈变实，面板弹出 |
| **按下** | 无 | 圈不是按钮 |
| **禁用** | 不会 | 永远在 |

### 4.2 格子

| 状态 | 什么时候 | 样子 |
|---|---|---|
| **已解锁（常态）** | 见过这只怪物 | 彩色块 + 真名 |
| **未解锁** | 没见过 | 暗块 + `???` |
| **悬停** | 鼠标移到格子上 | **现在完全没反应**。建议：格子上浮 1 像素 + 边框微亮 |
| **按下 / 点击** | 鼠标点某个格子 | **现在完全没反应**。建议：显示这只怪物的详情（血量、出没地） |
| **禁用** | 不会 | 图鉴没有禁用状态 |

> **这是个大缺口**：玩家看到一只亮的怪物，**一定想点它看看是啥**。现在点了没反应。

## 五、声音 / 反馈

| 时机 | 现在有没有 | 建议 |
|---|---|---|
| 面板弹出 | ❌ 没有 | 轻「唰」（25%），和其他 NPC 统一 |
| 鼠标移到已解锁格子 | ❌ 没有 | 极轻「嗒」（15%） |
| 点开一只怪物详情 | ❌ 没有 | 轻「翻页」声（30%），像翻书 |
| **在战斗里第一次见到新怪物** | ❌ 没有 | ⚠️ 这一条不在主城，但很重要：图鉴解锁的那一刻应该「一声很轻的『叮』+ 屏幕角落一个小图标亮一下」。**玩家必须当场知道自己解锁了，不然他不会为了收集去回主城看图鉴** |
| 图鉴集满一个分类 | ❌ 没有 | 一串上扬的短音（60%），类似「完成」 |

> **主城这边一条音效都没有。** 但图鉴这个功能真正的「爽点」在战斗里——**解锁的那一刻**。主城只是验收清单。

## 六、异常情况怎么处理

| 情况 | 处理 | 玩家看到什么 |
|---|---|---|
| 怪物配置里一只都没有 | 面板只剩标题和横线 | 空面板，玩家以为坏了 |
| 怪物数量不是 4 的倍数 | 最后一行不满 4 个，剩下的空着 | 正常，右下角留白 |
| 怪物多到超出屏幕 | **现在会超出，没有滚动** | 下面一半怪物看不见，**看不见等于不存在** |
| 怪物的颜色字段是空的 | 兜底用中灰蓝 | 已解锁的怪物是一块灰块，但名字对。**玩家会以为没解锁但名字又露了，很怪** |
| 「已收录」名单缺失 | 全部显示 `???` | 一整片问号。玩家会觉得「我明明打过」 |
| 玩家一次都没玩过 | 全部 `???` | 这是**正确**的初始状态，不用处理 |
| 面板开着走了 | 自动关闭 | — |

## 七、这个功能不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| 显示未解锁怪物的名字、血量、样子 | 那图鉴就失去了「我想知道那是什么」的钩子 |
| 一进游戏就全解锁 | 收集就没意义了 |
| 让玩家在图鉴里打怪 | 图鉴是「看」的地方，不是「玩」的地方 |
| 只有 `???` 没有数量指示 | 玩家不知道总共有多少，就不知道「还差几个」。**必须让人觉得有个头** |
| 副标题写「英雄 / 怪物」但只有怪物 | **现在就是这么写的。** 让人白点进来找不到英雄 |
| 用百分比进度（「已收集 37%」） | 用「已收录 12 / 共 40」这种数数，比百分比直观 |
| 点格子没反应还不说 | 格子看起来是可点的方块，点了没反应最伤手感 |

## 八、和其他文档的约定

| 对象 | 约定 |
|---|---|
| 输入 | 走进圈。**没有按钮** |
| 输出 | 无。图鉴纯只读，不写任何数据 |
| 依赖 1 | `cfg/monsters.json` 提供怪物名单、名字、颜色 |
| 依赖 2 | 存档里的「已收录」名单（谁写进去的？见下） |
| **缺的数据源** | **谁在什么时候往「已收录」里写东西，本文档管不到。** 这事必须在 `005-战斗` 或结算那边做，主城只负责读。**现在这条链路要确认是否通**——如果战斗那边从来不写，图鉴永远是全 `???` |
| 和 `B002-档案卡` | 无关。图鉴不显示在档案卡上 |
| 和 `001-主菜单` 的 `B002-图鉴` | 主菜单里也有一个图鉴按钮。**两处必须是同一份数据**，否则玩家在两个地方看到两个不同的收集进度 |
| 和「12 个英雄」 | 全游戏有 12 个英雄，副标题说这里是英雄图鉴——但英雄那边一个都没做。要么补上英雄页，要么改副标题 |
