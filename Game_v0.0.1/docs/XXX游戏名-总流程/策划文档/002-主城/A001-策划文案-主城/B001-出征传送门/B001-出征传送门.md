## 一、这个功能是干什么的

**一句话**：玩家走进这个圈，站着数 2 秒，就会被送去选关卡——**这是主城里唯一一条「出门」的路**。

**为什么它是 B001（最重要的一份）**：主城里有 8 个地方能去，但玩家 90% 的进出都是走这一道门。别的点位是「有钱有闲才去」，这道门是「每天必走」。它要是卡一下、误弹一次，玩家第一反应就是「这游戏 bug 真多」。

**为什么是「走进圈数 2 秒」而不是「点一下按钮」**：因为要有一点仪式感。数那 2 秒的时候，玩家脑子里在过「这次我要练哪个英雄」——这一小段停顿，就是「出门」的感觉。

**和整款游戏的关系**：走完这道门，玩家进入的是一场**会掉东西的局**。打死 Boss 算赢；死了，这一局捡到的东西全丢，局外等级保住。所以这道门对玩家来说是「我准备好了」的确认动作，不能随便误触。

## 三、走进圈以后发生什么（完整流程）

```
玩家用 WASD/方向键走进金圈（半径 90 以内）
   ↓
① 圈的颜色立刻从「淡」变「实」（透明 70% → 100%）     0 秒，瞬间
   ↓
② 圈外面出现金色读条环，从 12 点方向开始长              0 秒
   ↓
③ 站着不动，读条长满                                 2 秒
   （这 2 秒里可以动，但一出圈读条立刻清零）
   ↓
④ 读条长满 → 主城广播「我要出征了」                    瞬间
   ↓
⑤ 主城上方弹出选关屏（主城不消失，只是被盖住）          约 0.2 秒
   ↓
⑥ 玩家在选关屏选关卡 → 选人屏选英雄 → 进战斗
   ↓
（打完回主城，还站在圈里 → 不会再弹一次）
```

**耗时**：走进圈到看见选关屏，**约 2.2 秒**。

**为什么第 ⑤ 步是「盖住」而不是「切走」**：因为玩家选完关、打完回来，主城还在原位，玩家还是站在圈边。如果切场景，回来要重新加载整张地图，还会闪一下屏。

## 四、各种状态

| 状态 | 什么时候 | 样子 |
|---|---|---|
| **常态** | 玩家不在圈里 | 金色虚线圆，透明度 70%（淡淡的）；印章 `>>` 金色；头顶名字和副标题正常显示；没有读条环 |
| **悬停 / 靠近** | 玩家走进圈里（还没开始读条的那一瞬间） | 圈变实（100% 透明），其余不变。这一下变化等于告诉玩家「你踩对地方了」 |
| **按下 / 读条中** | 读条计时正在进行 | 圈实心金色 + 圈外一道金色读条环从 12 点方向顺时针长 |
| **禁用 / 条件不满足** | `cfg/city.json` 里 `portal` 段整段被删掉 | 圈不出现。代码里「表里没有就不建这个点」是硬判断，所以删掉就是彻底不出现 |
| **读条被打断** | 玩家读条途中走出圈 | 读条环立刻消失，计时清零。再进来从 0 开始 |
| **误触保护中** | 已经在这个圈里触发过一次，还没走出去 | 圈的样子和常态一样（没有读条环），再站多久都不会再弹 |

## 五、声音 / 反馈

| 时机 | 现在有没有 | 建议 |
|---|---|---|
| 踩进圈那一刻 | ❌ 没有 | 加一声很轻的「嗡」（音量 25%），像磁铁吸住 |
| 读条过程中 | ❌ 没有 | 加一段逐渐升高的呼吸音，2 秒爬满。**这是最关键的一条**——有声音玩家可以不用看屏幕 |
| 读条满、弹选关屏 | ❌ 没有 | 「叮——」一声，音量 60% |
| 走出圈、读条中断 | ❌ 没有 | 一声下滑的短音（「噗」），音量 20%，告诉玩家「读条废了」 |
| 误触保护触发（站在圈里不动） | ❌ 没有 | 不加声音。这里静默最好，不要提醒玩家「你被保护了」 |

> **当前一个音效都没有。** 建议优先加「读条爬升音」，因为这一个声音能顶掉半个界面。

## 六、异常情况怎么处理

| 情况 | 处理 | 玩家看到什么 |
|---|---|---|
| 读条途中走开 | 计时清零，环消失 | 环突然没了，没有提示。**这是对的**，别弹「读条已取消」 |
| 读条完成后选关屏被关掉、人还站在圈里 | 不重复弹。必须走出圈再进来 | 无感。这就是防「莫名被弹回选关」的补丁 |
| 玩家在读条途中同时踩到别的门 | 两道门的圈不会重叠（最近的两道门相距 200 像素以上），实际不会发生 | — |
| 表里 `portal` 的 `desc` 字段丢了 | **会显示乱码**「游荡图签 2×9 · 凯觎关卡进程」 | 屏幕上一行看不懂的字。**这是 bug，见第九节** |
| 表里 `portal` 整段丢了 | 圈不出现，玩家找不到出门的路 → 会以为游戏坏了 | 什么都没有 |
| 读条时长配成 0 或负数 | 一进圈立刻触发，等于踩一下就走 | 玩家会觉得「不小心就进关了」 |

## 七、这个功能不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| 站在圈里反复触发 | 出现「打完了又被弹回选关屏」的死循环，这个 bug 已经修过一次，不许再犯 |
| 读条途中出圈还继续读 | 那就等于「读条是个摆设」。要求站在那里，是这道门的全部仪式感 |
| 弹「确定要出征吗」确认框 | 多一层点击没有任何价值，读条 2 秒本身就是确认 |
| 读完直接切场景、把主城毁掉 | 主城必须留着。选关屏是盖上来的，不是替换 |
| 读条到一半被 NPC 面板打断 | 门优先。走门的时候不能弹出强化导师那种面板 |
| 用红色/橙色画 | 金色是「安全、可去」，红色是「危险」。出征门不许用红色（红色留给深渊之门） |
| 在圈里显示倒计时数字 | 一圈环已经够清楚了，加数字反而让人紧张 |

## 八、和其他文档的约定

| 对象 | 约定 |
|---|---|
| 输入 | 玩家位置进入圈内（距离 < 90 像素），不需要点击 |
| 输出 | 广播两个消息：「门已就绪」+「玩家要出征了」。`003-选关` 负责接第二个消息并弹屏 |
| 依赖 | `003-选关` 必须已经建好，否则读条走完会「弹了个空」 |
| 前置 | 无。任何时候都能走，没有等级门槛、没有次数限制 |
| 不许碰的数据 | 这道门**不扣结晶、不改存档**。它只是一个门 |
| 和 B009 的区别 | 这道门去「有尽头的关卡」，深渊之门去「没有尽头的深渊」。两者读条时长都是 2 秒，但颜色不同（金 / 橙红） |
