## 一、这个功能是干什么的

**一句话**：让玩家给**自己**起一个名字（现在只做了这一件事）。

**它的真实分量比看起来大**：这是一款「死了就掉光、明天还想再来」的游戏。玩家愿意回来，很大程度是因为他觉得自己在养一个「人」。**给这个「人」起个名字，是让玩家认领它的第一步。** 一个叫「无名旅者」的玩家和一个叫「老张」的玩家，粘性完全不一样。

**但要说清楚现在的实际情况**：这个 NPC 头顶的副标题吹了四样东西——「头像 · 更名 · 称号 · 皮肤」，面板里**只有一样：更名**。剩下三样一个都没做。这是**过度承诺**，必须指出（见第九节）。

## 三、点「确定更名」以后发生什么

```
玩家走进绿色 ☺ 圈 → 面板弹出，输入框里是现在的名字
   ↓
① 玩家点进输入框，删掉旧名字，打上新名字（比如「老张」）     玩家自己控制
   ↓
② 点「确定更名」                                          0 秒
   ↓
③ 系统去掉前后空格，数一数字数                              瞬间
   ↓
④ 少于 2 个字 → 拒绝，什么也不改                            瞬间
   ↓
⑤ 够 2 个字 → 名字存起来（存两处，见下）                     瞬间
   ↓
⑥ 左上角档案卡的名字立刻变成新名字                           瞬间
   ↓
⑦ 面板不关，输入框里还是新名字，玩家可以接着改               —
```

**耗时**：**小于 0.1 秒**。

### 3.1 名字存在哪里（开发看）

| 存哪 | 干什么用 |
|---|---|
| 内存里的玩家档案 | 当前这一把用，面板和档案卡读这个（第 512 行） |
| 存档文件里的「形象」段 | 关掉游戏再开还在（第 515~516 行，**当场落盘**） |

**两处都要写**，少写一处就会出现「这一把是新名字，重开游戏又变回旧名字」的经典 bug。现在两处都写了，这点做得对。

## 四、各种状态

### 4.1 NPC 圈

| 状态 | 什么时候 | 样子 |
|---|---|---|
| **常态** | 不在圈里 | 绿色虚线圆，透明度 70% |
| **悬停 / 靠近** | 走进 76 像素内 | 圈变实，面板弹出 |
| **按下** | 无 | 圈不是按钮 |
| **禁用** | 不会 | 永远在 |

### 4.2 输入框

| 状态 | 什么时候 | 样子 |
|---|---|---|
| **常态** | 没有正在改 | 白底/深底的框，里面是当前名字，**光标不闪** |
| **悬停** | 鼠标移上去 | 框边微微亮起，鼠标变成「文字」形状 |
| **按下 / 激活** | 点进框里 | 框边亮金，出现闪烁光标，可以打字 |
| **禁用** | 不会 | 永远可编辑 |

### 4.3 「确定更名」按钮

| 状态 | 什么时候 | 样子 |
|---|---|---|
| **常态** | 随时 | 亮按钮「确定更名」 |
| **悬停** | 鼠标移上去 | 提亮 |
| **按下** | 按住 | 压暗 |
| **禁用** | **现在是假的**——按不按都能按 | 见下 |

> **这是本功能最大的问题**：字数不够时，按钮**看起来完全可以点**，点了却什么也不发生（只在后台记一条「名号过短」的日志）。玩家的感受是「按了没反应，是不是卡了」。**按钮应该在字数不够时变灰，或者在框下面用红字提示「至少要 2 个字」。**

## 五、声音 / 反馈

| 时机 | 现在有没有 | 建议 |
|---|---|---|
| 走进圈弹面板 | ❌ 没有 | 轻「唰」（25%），和其他 NPC 一致 |
| 点进输入框 | ❌ 没有 | 极轻的一声「嗒」（15%） |
| 打字时 | ❌ 没有 | 每打一个字一声极轻的「嗒」（10%）。如果嫌吵可以不做，但**改中文名时需要输入法，输入法自己会有反应，别抢** |
| 改名成功 | ❌ 没有 | 一声温和的「嗯——」（像盖章）50% + 档案卡上的名字闪一下金色，0.5 秒 |
| 字数不够被拒 | ❌ 没有 | 输入框边框**红闪一下**，0.4 秒 + 框下面出现一行红字「至少要 2 个字」，2 秒后消失 |
| 超出 8 个字（打字时） | ❌ 没有 | 根本打不进去（输入框有硬上限），**不加提示**。打不进去比弹提示友好 |

> **现在一条音效都没有。** 改名这件事对玩家很重要，是「认领角色」的时刻，值得一个正式一点的声音。

## 六、异常情况怎么处理

| 情况 | 处理 | 玩家看到什么 |
|---|---|---|
| 只打 1 个字 | 拒绝，不改 | 现在：按了没反应（要改：红框 + 提示） |
| 只打空格 | 去空格后变空，拒绝 | 同上 |
| 打超过 8 个字 | 打不进去，输入框停在 8 个 | 第 9 个字打不出来 |
| 名字和原来一模一样 | **照样算「成功」**，落一次盘 | 无感。不提示「名字没变」 |
| 名字里带奇怪符号（表情、特殊字） | 现在的输入框**不过滤**，能存进去 | 照显示。**风险**：有些表情在画字的时候会变成方块 |
| 存档落盘失败 | 内存里改了，文件没改成 | **玩家会以为改了**，下次开游戏发现变回去了 |
| 面板开着走了 | 面板自动关，**没按确定的名字不算** | 没点确定的就不生效（符合预期） |
| 面板开着按 Esc | 面板关掉，没点确定的名字不算 | 同上 |

## 七、这个功能不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| 允许 0~1 个字的名字 | 一个字的名字在界面上很难看，也不像个名字 |
| 允许 20 个字的名字 | 档案卡会被撑爆，还会盖住右上角的结晶 |
| 弹「确定改名吗？这会花 100 结晶」 | 改名必须免费、无限次。**没有理由收费** |
| 改完名把面板关掉 | 玩家常常要试两三个名字才满意，关了他得走出来再进来 |
| 只在内存里改、不落盘 | 这是最典型的「看着改了其实没改」 |
| 过滤掉玩家的名字（比如不许叫「管理员」） | 这是单机游戏。玩家爱叫啥叫啥 |
| 在副标题上继续吹没做的功能 | **现在就是这么干的。**「头像 · 称号 · 皮肤」三样一个都没有 |
| 允许改成空名字 | 空名字会让档案卡显示一片空白 |

## 八、和其他文档的约定

| 对象 | 约定 |
|---|---|
| 输入 | 走进圈（弹面板）+ 在输入框打字 + 点「确定更名」 |
| 输出 | 名字同时写进「当前档案」和「存档文件」 |
| 依赖 | `cfg/profile.json` 里的 `nameMin`、`nameMax`、`defaultName` |
| 和 `B002-档案卡` | 改名成功后档案卡立刻生效（第 517 行） |
| 和 `001-主菜单` | 主菜单底部那行也是同一个名字来源，必须一致 |
| 和未来的「称号表」 | `cfg/profile.json` 里已经有一张称号表（初出茅庐、撤离者……每一项带一个「解锁条件标记」），**但档案卡现在没用它**。接称号是 B002 的活，不是这里的活 |
| 和未来的「头像 / 皮肤」 | `cfg/profile.json` 里有 `defaultSkin` 字段，说明以后要做皮肤。**做之前不许在副标题上继续吹** |
