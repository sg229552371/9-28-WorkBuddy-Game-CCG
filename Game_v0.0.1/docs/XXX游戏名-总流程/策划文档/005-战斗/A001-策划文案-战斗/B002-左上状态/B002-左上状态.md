# B002-左上状态

> 父级：`005-战斗`　｜　版本 v1.0　｜　2026-10-26
> 对应代码：`battle.gd` `_build_hud()` 第 488~515 行（READY 徽章 + HP 行）、`_update_hud()` 第 708~713 行（刷新）

---

## 一、这个功能是干什么的

**一句话**：屏幕左上角贴着两样东西——一行「我还剩多少血」，一个绿圈徽章「READY（全场冻结）」。

**对太奶奶级玩家的意义**：左上角是老玩家眼睛第一个扫的地方。血条 = 命，命一眼看不见，玩家就不敢往前冲。这个位置必须最稳、最亮、最不会看错。

**这块其实包含两个独立的东西**

| 东西 | 一句话 | 一局里出现多久 |
|---|---|---|
| HP 行 | `HP 94/94   Lv1   经验 0` | 全程 |
| READY 徽章 | 绿圈 + 「READY」+ 小字「全场冻结」 | 只有开局的 3 秒 |

| 项目 | 数值 |
|---|---|
| 位置 | 距屏幕左 16 像素，距屏幕顶 10 像素 |
| 字号 | 24 |
| 颜色 | 冷白 `rgb(0.95, 0.98, 1.0)`，即 `#F2FAFF` |
| 描边 | 6 像素黑边 |

**里面的字**

| 项目 | 数值 |

| 主字字号 | 14 |

| 主字位置 | 满铺外框，水平垂直都居中 |
| 小字 | `全场冻结` |
| 小字字号 | 12 |
| 小字颜色 | 淡翡翠 `rgb(0.55, 0.85, 0.6)` |
| 小字位置 | 往右 2、往下 58（**在圆章外面下方**） |

        ┌────────────┐
        │   ●●●●     │  ← 绿圈边框，56×56，圆心 (44, 70)

## 三、怎么变化

### 3.1 HP 怎么变

| 情况 | 显示 | 说明 |
|---|---|---|
| 满血 | `HP 94/94` | 94 是 1 号英雄的初始血量（`cfg/heroes.json`），不同英雄不一样 |
| 掉血 | 分子跟着掉，比如 `HP 30/94` | 实时刷新，每帧都算 |
| 掉到 0 | `HP 0/94` 并弹结算 | 代码把血钳在 0，不会出现负数 |
| 升级加血 | 分子分母**同时涨** | `cfg/levelUp.json` 的 `坚韧包` 一次 +15 血，`HP 109/109` |

> **注意一件爽事**：升级加血是**把上限和当前血一起加**，等于「升级顺便回一点血」。这是刻意的，让升级有救命的感觉。

### 3.2 等级和经验的数字怎么变

| 数字 | 含义 | 每只怪 | 说明 |
|---|---|---|---|
| `Lv1` | 本局等级 | 不看单只，看累计经验 | 满级 46（设计口径），升 1 级约需 `8 × 1.32^(等级-1)` 点经验，12 级以后需求打七折 |
| `经验 0` | 本局总经验 | +3 | 这是「本局赚了多少」，**不是**「离下一级还差多少」 |

> **这里最容易让人误会**：玩家看到「经验 0 → 经验 40」会以为「40 就快升级了」，其实这两回事：一个是本局总收获，一个是升级进度。`经验` 这个字用在两个意思上，容易乱。见「不许干的事」和第十节。

### 3.3 READY 徽章什么时候亮

| 条件 | 徽章 | 说明 |
|---|---|---|
| 开局前 3 秒 | **亮** | `cfg/levelFreeze.json` `freezeTime=3`，`hint="准备战斗"`；`combat.gd` 第 198~202 行读入，第 249~252 行每秒递减 |
| 3 秒过完 | **灭** | `combat.freeze_time` 归零，`visible=false`（第 710 行） |
| 一局里其他任何时刻 | **灭** | 代码里**再没有第二个地方**把冻结时间调起来 |

> **这就是问题所在**：截图阶段大家都以为「READY / 全场冻结」是个正经机制——某个时刻全场定住让玩家选东西。实际上它只对应「开局 3 秒倒计时」，而且这 3 秒连怪都还没刷（`combat.gd` 第 249~252 行冻结期间直接 return，什么都不更新）。所以玩家看到的只是一个**闪了 3 秒就消失、没有任何作用**的绿圈。

## 四、各种状态

| 状态 | 什么样 | 什么时候 |
|---|---|---|
| **常态** | 只有 `HP 94/94   Lv1   经验 0`，徽章不出现 | 99% 的时间 |
| **低血（警告）** | 代码**没有任何变化**，字还是白色 | 血量低于三成时应该变红，现在没做 |
| **冻结（特殊）** | 绿圈出现，READY + 全场冻结小字，3 秒后消失 | 开局 |
| **阵亡（危险）** | `HP 0/94` 白字不动，马上弹结算 | 一瞬间 |
| **隐藏** | 从不隐藏 | — |

> **关键缺陷**：**血量再低，左上这行字都不会变色**。地图上玩家脚底下倒是有条小血条（`battle.gd` 第 844~847 行），血量低于 35% 会从绿变红——但那条只有 48×6 像素，在人物脚底下，乱战时根本看不见。左上这行大字反而一直白着，没用上。

## 五、声音 / 反馈

| 时机 | 现在 | 应该 |
|---|---|---|
| 掉血 | 无 | 不需要音效，但要**数字闪红**一下（掉血的那一帧） |
| 血量低于 30% | 无 | **该有**：心跳声 + 屏幕边缘泛红（这是最需要提醒的时刻） |
| 冻结开始 | 无（`EventBus.freeze_started` 有信号，HUD 没接） | 一声「咔」的定身声 |
| 冻结结束 | 无 | 一声「走」的重音，告诉玩家可以动了 |
| 升级 | 无 | 一声清脆的「叮」 |

**给太奶奶的大白话**：整块左上现在是**完全哑的**。血流干之前不会叫、不会闪、不会变红，全靠玩家自己盯着那几个数字。这对眼睛不好的玩家很不友好。

## 六、异常情况

| 情况 | 现在会怎样 | 玩家看到什么 | 该怎样 |
|---|---|---|---|
| 队伍里换了个血更厚的英雄 | 数字跟着变，没问题 | `HP 140/140` | ✅ 正常 |
| 血量上限涨了但当前血没满 | 代码是同时加的，不会出现 | — | ✅ 设计上已经避开 |
| 冻结 3 秒里按 Esc | 冻结时间**不递减**（暂停优先返回） | 徽章一直亮着，好像卡了 | 应允许暂停时也走完，或者干脆藏徽章 |
| 冻结期间升级弹窗正好弹出 | 不可能（3 秒里还没经验） | — | ✅ |
| 结算面板弹出 | HP 行还在，压在结算下面几行 | 字叠字 | 结算时应整层隐藏 |
| READY 小字「全场冻结」超出圆章 | 压到下面去了 2 像素 | 有一点点挤 | 调整小字位置 |
| 三名英雄时血量怎么算 | **只显示队长一个人的血** | 队员血量看不见 | 见第十节 |

## 七、不许干的事

| ❌ | 为什么 |
|---|---|
| 血量低于三成还不变色 | 这是玩家最需要被提醒的时刻，白了就是失职 |
| 用小数显示血（`HP 31.7/94`） | 太奶奶看整数，四舍五入就好 |
| READY 徽章搞成一个「能点」的按钮 | 它是个状态灯，不是按钮，点了没反应会让人以为坏了 |
| 在冻结 3 秒里让怪能动 | 冻结就是谁都不动 |
| 把「经验」两个字用在两种意思上（本局总经验 / 离升级还差多少） | 玩家会算错，必须改口径 |
| 左上重复显示等级（右上已经有了） | 一块屏幕同一件事说三遍，浪费地方 |
| 队员血量完全不显示 | 三人同场，队员死了玩家不知道，会觉得「怎么突然少一个」 |

## 八、和其他文档的约定

| 项目 | 内容 |
|---|---|
| **输入** | `combat.player.hp` / `hp_max`（血）、`combat.player_lv`（等级）、`combat.exp_gained`（本局总经验）、`combat.freeze_time`（冻结剩余）、`combat.freeze_hint`（冻结提示语） |

| **和 B003 的关系** | **等级和经验在这两块重复显示**。建议：左上只留 HP，等级经验全部归 B003（右上） |

| **和 006-结算 的关系** | 结算弹出时整层 HUD 要隐藏 |
| **依赖配置** | `cfg/levelFreeze.json`（冻结时长与提示语）、`cfg/heroes.json`（各英雄初始血量）、`cfg/levelUp.json`（升级加血幅度） |

## 十、太奶奶要定的事

| 问题 | 选项 |
|---|---|
| **一、READY「全场冻结」徽章怎么办？** 它现在只在开局亮 3 秒，之后就再也没用了 | (A) **删掉**，开局改成一个盖满屏的「准备战斗 3」大字（更气派）　(B) **留着**，开局和每个 Boss 出场都亮一次（有仪式感）　(C) **升级成机制**：每 10 级自动冻结全场 2 秒，让玩家安心选强化 |
| **二、左边这行字留哪些？** 现在塞了血、等级、经验三样 | (A) **只留血**（干净，等级去右上）　(B) 血 + 等级（经验去右上）　(C) 保持原样三样都留 |
| **三、掉到多少血开始报警？** | (A) 三成（30%）　(B) 一半（50%，更谨慎）　(C) 两成（20%，只在真的快死时叫） |
