> 父级：`005-战斗`　｜　版本 v1.0　｜　2026-10-26
> 对应代码：`battle.gd` 第 3 行（文件头操作注释）、`_unhandled_input()` 第 391~409 行（按键）、`_process()` 第 418~424 行（暂停闸门）、`_build_hud()` 第 551~582 行（右下按钮与提示）、`_toggle_auto_fight()` 第 210~213 行、`_toggle_bag()` 第 681~686 行、`_update_hud()` 第 705~706 行（「已暂停」）

## 一、这个功能是干什么的

**一句话**：这一块管三件事——**按 Esc 停一下**、**右下两个按钮（自动战斗、背包）**、**右下角那一行教你怎么玩的小字**。

**对太奶奶级玩家的意义**：这一块是「说明书」。一个游戏操作再顺，玩家不知道按什么键就等于没有。而且——**太奶奶级玩家会真的忘了怎么操作**，所以那行小字必须一直在，不能自动消失。

### 2.3 暂停时屏幕什么样

| 项目 | 变化 |
|---|---|
| 顶部条下文字 | 变成 `已暂停`（第 705~706 行） |
| 地图 | **完全静止**（怪不动、子弹不动、时间不走） |
| 遮罩 | **没有**。就是画面冻住 |

## 三、怎么变化

### 3.1 Esc 的完整行为

| 步 | 发生什么 | 代码 |
|---|---|---|
| ① | 按 Esc → 暂停开关翻转 | 第 395~396 行 |
| ② | 状态切成「菜单」（暂停）或「游戏中」（继续） | 第 397 行 |
| ③ | 主循环看到暂停 → 不再更新世界，只重绘 | 第 418~424 行 |
| ④ | 顶部文字变 `已暂停` | 第 705~706 行 |
| ⑤ | 再按 Esc → 一切恢复 | — |

**会不会弹出一个暂停菜单？** **不会**。代码里 Esc 只做「停 / 继续」两态切换，没有任何菜单、没有「返回主城」、没有「重开」。玩家按了 Esc 之后，除了冻住，什么也做不了。

### 3.2 自动战斗按钮 / G 键

| 步 | 发生什么 | 代码 |
|---|---|---|
| ① | 点按钮 或 按 G | 第 561 行 / 第 408~409 行 |
| ② | 开关翻转 | 第 212 行 |
| ③ | 广播一个信号 `EventBus.auto_fight_toggled` | 第 213 行 |
| ④ | 按钮文字变 `自动战斗 · 开` / `自动战斗 · 关` | 第 734 行 |
| ⑤ | 底部回退文字里的 `自动战斗[开]` / `[关]` 同步变 | 第 727~729 行 |

**「自动战斗」到底做了什么**：**只影响技能自动施放**（`combat.gd` 第 322~325 行，每到一个冷却就朝瞄准方向放一次技能爆发）。**它不会自动走位、不会自动开枪、不会自动躲子弹**。

> **这和玩家的预期差距极大**。名字叫「自动战斗」，玩家会以为「开了以后我可以去倒杯水」。实际上开了以后人还是站着不动，只是技能自己放。

### 3.3 背包按钮 / Tab

| 步 | 发生什么 | 代码 |
|---|---|---|
| ① | 点按钮 或 按 Tab | 第 572 行 / `bag_ui.gd` 第 66~70 行 |
| ② | 背包面板出现 / 消失 | `bag_ui.gd` 第 72~75 行 |
| ③ | **世界不暂停**（面板只是盖在上面） | 代码里没有暂停逻辑 |

> **问题**：开着背包的时候，怪照打、子弹照飞。玩家在翻包时被摸死，会觉得「我明明在菜单里怎么还会死」。

### 3.4 那一行操作提示

| 情况 | 表现 |
|---|---|
| 一直显示 | 从开局到结算 |
| 会不会自动淡出 | **不会** |
| 会不会跟着分辨率变 | 右对齐锚定，会跟着贴右边 |
| 内容会不会随场景变 | **不会**，永远这 7 段 |
| 有没有写 M 键 | **没有**。M 键能唤出三合一屏（主城 / 选人 / 结算），但提示里一个字都没提 |

## 四、各种状态

**按 Esc 相关的四种状态**

| 状态 | 什么样 | 什么时候 |
|---|---|---|
| **常态（游戏中）** | 没有「已暂停」字，一切在动 | 正常打 |
| **暂停** | 画面冻住，顶部显示 `已暂停` | 按 Esc |
| **升级弹窗中** | 世界已经停住（不是靠 Esc，是靠升级闸门），同时按 Esc 会造成状态打架 | 升级时误按 Esc |
| **阵亡** | 画面停住，顶部显示 `阵亡`，立刻弹结算 | 血归零 |

**自动战斗按钮的四种状态**

| 状态 | 什么样 | 说明 |
|---|---|---|
| **关（常态）** | 文字 `自动战斗 · 关` | 灰底，和开的时候一模一样 |
| **开** | 文字 `自动战斗 · 开` | **只有文字变了**，底色、边框、图标全都没变 |
| **鼠标悬停** | 系统默认微亮 | 没特别设计 |
| **按下** | 系统默认 | 没特别设计 |

**背包按钮的四种状态**

| 状态 | 什么样 |
|---|---|
| 常态 / 悬停 / 按下 | 系统默认 |
| 背包已打开 | 按钮**没有任何变化**（不会变「已打开」） |

## 五、声音 / 反馈

| 时机 | 现在 | 应该 |
|---|---|---|
| 按 Esc 暂停 | 无 | 一声「嗡——」的下沉音 + 画面加一层轻微灰蓝 + 屏幕正中出一个大字「暂停」 |
| 按 Esc 继续 | 无 | 一声「嘟」的上扬音 |
| 点自动战斗按钮 | 无 | 一声「咔」；按钮**底色反过来**（开 = 绿底，关 = 灰底），加个图标 |
| 点背包按钮 | 无 | 一声「哗」的拉链声 |
| 捡到东西（提示要不要） | 无 | 不提示，那一行是说明书不是通知栏 |

**给太奶奶的大白话**：这一整块现在是**哑的、单色的**。按了 Esc 屏幕冻住，连个字都小得看不见；按自动战斗，按钮除了字变了一下别的没变。玩家完全没有「我按对了」的确认感。

## 六、异常情况

| 情况 | 现在会怎样 | 玩家看到什么 | 该怎样 |
|---|---|---|---|
| 升级弹窗开着按 Esc | 状态从「升级」被改成「菜单」，选完又改回「游戏中」 | 可能升级框和暂停状态混在一起 | 升级期间 Esc 应无效 |
| 暂停时按 Tab | 背包打开，盖在冻结画面上 | 能翻包 | 未定，看第十节 |
| 暂停时按 G | 自动战斗切换成功 | 按钮字变了，画面还冻着 | 可接受 |
| 暂停时按数字键 | 不触发（升级闸门优先，没升级就走无尽奖励） | 无反应 | ✅ |
| 背包 UI 没加载成功 | 点背包按钮只打一行程序警告，界面无反应 | 按钮是坏的，但没崩 | ✅ 不崩，但玩家会以为按钮坏了 |
| 窗口分辨率不是 1280×720 | 提示右对齐，会跟着贴边；但 7 段文字太长，小窗口会挤出屏幕 | 文字被切掉 | 需要按分辨率缩短文案 |
| 提示和底部技能栏撞车 | 技能栏底板底边在 y=660，它下面那行回退文字在 y≈698；操作提示在 y≈680 | 底部右侧两行字可能挤在一起 | 要核对间距 |

## 七、不许干的事

| ❌ | 为什么 |
|---|---|
| 按 Esc 直接把当前局丢掉 | 玩家只是想暂停，不是想死 |
| 暂停时不给任何提示 | 画面冻住没提示，玩家以为游戏卡死 |
| 「自动战斗」开着人还站着不动却叫「自动」 | 名字骗人，玩家会觉得是 bug。要么改名字（改成「自动放技能」），要么真做成自动战斗 |
| 自动战斗按钮只变文字不变色 | 30 像素高的灰按钮，字只差一个字，玩家看不清现在是开还是关 |
| 操作提示自动淡出 | 太奶奶级玩家需要说明书一直在 |
| 提示里写「WASD」但不解释 | 太奶奶不认识 WASD，要写「WASD（方向键也行）」 |
| 提示文字被屏幕边缘切掉 | 那行已经很长了，小屏必切 |
| 背包打开时世界照常跑 | 会冤死 |

## 八、和其他文档的约定

| 项目 | 内容 |
|---|---|
| **输入** | 键盘 Esc / G / 数字键；按钮点击 |
| **输出** | Esc → 把全局状态切成「菜单」/「游戏中」；G 与按钮 → `EventBus.auto_fight_toggled` |
| **和 B006 的关系** | **升级期间 Esc / Tab / C 应该全部无效**。这条约定两边都要遵守 |
| **和 B004 的关系** | 底部技能栏在 y=530~660，回退文字在 y≈698，操作提示在 y≈680，**三者挤在右下和底部**，要统一排一次 |
| **和 B007 的关系** | 读条期间能不能暂停，取决于 B007 的拍板 |
| **和 006-结算 的关系** | 阵亡 / 撤离成功后，这一整块（按钮、提示）应该全部隐藏，只留结算面板 |
| **和 C 水晶面板的关系** | 操作提示里写了 `C水晶`，这个是能用的（`crystal_panel.gd` 第 46~48 行接管了 C 键）。但水晶面板是**透明盖在战斗上、不暂停世界**，小屏上会不会挡视线**没有验证** |
| **和 Tab 背包的关系** | 文案一致 ✅，但打开时世界不暂停 ⚠️ |

## 十、太奶奶要定的事

| 问题 | 选项 |
|---|---|
| **一、按 Esc 以后，除了停住，还要不要给个菜单？** 现在除了冻住什么也没有 | (A) **加一个暂停菜单**：继续 / 返回主城（放弃本局）/ 设置　(B) **只加个遮罩和大字「暂停」**，别的不要（最简）　(C) 保持原样，就冻一下（最省事） |
| **二、「自动战斗」这个名字留吗？** 它现在只自动放技能，人不会动 | (A) **改名「自动技能」**（说实话，玩家不会误会）　(B) **做成真自动战斗**：会自己走位、瞄准、开枪（好，但工作量大）　(C) 名字留着，在提示里加一句「（只自动放技能）」 |
| **三、打开背包 / 水晶面板时，世界停不停？** | (A) **停**，跟暂停一样（安全）　(B) **不停**，边翻边挨打（紧张，但会冤死）　(C) 只停怪不动子弹（很难做到，别选） |
