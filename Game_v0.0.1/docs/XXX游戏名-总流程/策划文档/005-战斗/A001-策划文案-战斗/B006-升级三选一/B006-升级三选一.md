## 一、这个功能是干什么的

**一句话**：经验够了就弹一个框，让玩家从几个强化里挑一个，挑完变强，接着打。

**对太奶奶级玩家的意义**：「升级」是玩家一局里最期待的时刻——变强、爽。这个框要是看不清、看不懂、选错了会肉疼，整个爽感就毁了。

**它和「三选一」这个名字对不上**：名字叫三选一，**实际弹 4 个**（配置 `cfg/levelUp.json` `choiceCount=4`，代码按配置来）。文档标题沿用「三选一」是习惯叫法，实际请按 **4 个** 看。

## 三、怎么变化

### 3.1 什么时候弹

| 条件 | 动作 | 代码 |
|---|---|---|
| 经验够了，升 1 级 | 记一笔「待处理升级」 | `combat.gd` 第 421~426 行 |
| 下一帧 | 检查到有待处理升级 → 弹窗 | `battle.gd` 第 413~414 行 |
| 一次升了好几级（比如打 Boss 经验一大笔） | **一次只弹一轮**，选完接着弹下一轮 | 第 204~206 行 |
| 弹窗期间 | **世界停住**（怪不动、子弹不动、时间不走），但**画面照常画** | 第 411~417 行 |
| 玩家已死 | 不弹 | 第 413 行条件里带 `player.alive` |

**大白话**：升级的那一瞬间，整个战场「定格」了，只有这个框能动。选完，战场接着动。

### 3.2 玩家怎么选

| 方式 | 操作 | 代码 |
|---|---|---|
| 鼠标 | 直接点那个按钮 | 第 193 行 |
| 键盘 | 按数字键 **1 / 2 / 3 / 4** | 第 402~405 行 |

> 注意：数字键的判断条件是「有待处理升级就优先选升级」。所以如果同时有无尽模式的层间奖励，**升级会抢走数字键**。

### 3.3 选完发生什么

| 步骤 | 发生什么 | 代码 |
|---|---|---|
| ① | 待处理升级数 -1 | `combat.gd` 第 475 行 |
| ② | 属性加给**队长一个人**，队员不加 | `combat.gd` 第 455~475 行 |
| ③ | 框消失 | `battle.gd` 第 201~203 行 |
| ④ | 如果还有待处理的升级 | **立刻弹下一轮**（没有间隔，没有喘息） |
| ⑤ | 否则 | 世界恢复运动 |

### 3.4 强化都是些什么（当前池子）

**属性包 4 种**（`cfg/levelUp.json` `statPack`，每次从池里随机抽 4 个不重复）

| 名称 | 属性字段 | 数量 | 大白话 |
|---|---|---|---|
| 强攻包 | `atk` | +3 | 攻击力 +3 |
| 坚韧包 | `hp` | +15 | 血上限 +15（当前血也 +15） |
| 铁壁包 | `def` | +1 | 防御 +1 |
| 疾行包 | `spd` | +8 | 移动速度 +8 |

**战斗 buff 词条**（`cfg/warBuffs.json`，每项最多叠 10 层）

| 名称 | 效果文字 | 大白话 |
|---|---|---|
| 狂力 | 攻击力 +30% | 打得疼 |
| 迅击 | 攻速 +30% | 打得快 |
| 疾风 | 移速 +30% | 跑得快 |
| 汲血 | 吸血 15% | 打人回血 |

> 注意：属性包总共只有 4 个，而一次要抽 4 个——**意思是每一次弹窗，属性包就可能全上，四个选项全是「+3 / +15 / +1 / +8」**，缺少惊喜。这是内容不够的问题。

### 3.5 数值怎么涨

| 项目 | 规则 | 出处 |
|---|---|---|
| 升 1 级要多少经验 | `8 × 1.32^(当前等级-1)`，12 级以后打七折 | `combat.gd` 第 409~417 行 |
| 等级上限（设计口径） | **46 级** | 全局设计 |
| 等级上限（配置写的） | 99（`cfg/levelUp.json` `curve.maxLv=99`） | 需要统一，进总纲待办 |
| 每级自动涨多少 | 配置里有一套自动成长（`growth.stats` = hp/atk/def，每级 +6%） | `cfg/levelUp.json` `growth` |

**大白话**：每次升级，**先自动涨一点基础能力**（不用选），**再让玩家挑一个额外强化**。这跟设计口径「每次升级 = 基础属性提升 + 从几个里选一个」完全对得上。

## 四、各种状态

| 状态 | 什么样 | 什么时候 |
|---|---|---|
| **常态（弹出）** | 800×400 灰面板悬在亮着的战场上，4 个按钮 | 每次升级 |
| **选完** | 面板消失，战场恢复 | 点完/按完 |
| **连升（连续弹）** | 选完一个，下一个框**立刻**顶上来 | 一次涨够好几级的经验 |
| **无遮罩** | 外面始终是亮的，能看见怪 | 一直如此 |
| **隐藏** | 不弹的时候整块不存在 | 平时 |

> **「无遮罩」是这里最影响体验的一件事**。原理：升级时世界已经停住了，怪其实不动，但玩家**看着动来动去的子弹和怪**（画面没停），会以为「我被偷袭了但我动不了」，产生紧迫感甚至愤怒。这个框应该是「安全区」，得给背景压暗。

## 五、声音 / 反馈

| 时机 | 现在 | 应该 |
|---|---|---|
| 升级（框弹出） | 无 | 「叮 — 咚」上扬两音，框从 80% 放大到 100% 弹出来（0.2 秒） |
| 鼠标划过选项 | 无（系统默认） | 按钮变亮 + 轻微放大 |
| 选中 | 无 | 一声干脆的「咔」，框往外散开消失 |
| 连升第二次弹出 | 无间隙 | 中间插 0.3 秒间歇，给玩家喘一口气 |

**给太奶奶的大白话**：这个框现在是**静悄悄冒出来**的。玩家正在紧张躲子弹，突然画面被一块灰板挡住，没有任何声音提示，很容易懵。

## 六、异常情况

| 情况 | 现在会怎样 | 玩家看到什么 | 该怎样 |
|---|---|---|---|
| 弹窗开着时按 Esc | 暂停状态和升级状态打架：按 Esc 会把状态设成「menu」，选完又设回「playing」 | 混乱，可能出现暂停字 + 升级框同时在 | 升级期间 Esc 应该无效 |
| 弹窗开着时按 Tab 开背包 | 背包（全屏遮罩）盖在升级框上面 | 升级框被背包挡住，选不了 | 升级期间应禁用背包 |
| 弹窗开着时按 C 开水晶面板 | 水晶面板盖上来，并且**它是透明的，底下的按钮还能点到** | 界面乱成一团 | 升级期间应禁用 |
| 待处理升级每帧检查 | 每帧都调一次「弹窗」，但有防重入保护（已有框就返回） | 不会闪 | ✅ 有防护 |
| 选完一轮还有一轮 | 立刻弹下一轮 | 玩家来不及反应 | 应插 0.3 秒间隔 |
| 只有 1 个候选 | 只弹 1 个按钮 | 没得选 | 池子不够时应该至少凑 2 个 |
| 玩家在框里死了（理论上不会，因为世界停住） | 不可能 | — | ✅ |

## 七、不许干的事

| ❌ | 为什么 |
|---|---|
| 选项里出现英文属性名（`atk`、`hp`、`spd`、`def`） | 太奶奶看不懂，等于没得选 |
| 弹窗没有背景遮罩 | 战斗画面透出来，玩家以为还在挨打 |
| 框弹出来的时候怪还在动 | 已经挡住了（世界停住），但要保证以后也不破坏 |
| 弹窗期间还能开背包 / 水晶面板 | 界面会叠成一团，按钮还能误点 |
| 连升几级就连弹几个框、中间没间隔 | 玩家手指都不知道往哪放 |
| 框挡住玩家的位置（人物一般在画面中下方） | 现在 800×400 从 y=160 到 560，人物在 y≈360，**被压住了**。应考虑下移或半透明 |
| 四个选项全是「+3」这种小数字 | 没有惊喜，选哪个都一样，玩家会觉得无聊 |
| 用「三选一」的名字但实际弹四个 | 说清楚就好，别让人以为少了 |

## 八、和其他文档的约定

| 项目 | 内容 |
|---|---|
| **输入** | `combat.pending_levelups`（待处理升级数）、`combat.player_lv`（当前等级）、`combat.make_levelup_offers()`（抽候选） |
| **输出** | 调 `combat.apply_levelup_choice()` 加属性，属性只加给队长 |
| **和 B002/B003 的关系** | 升级后 `Lv` 数字要变（右上），血上限要变（左上）。这两块要能同步刷新 |
| **和 B004 的关系** | 队员不加属性，技能栏没有任何反应。如果以后要做「队员跟着升级」，这个框是入口 |
| **和 B008 的关系** | 升级期间 Esc / Tab / C 应该全部无效。这条约定要写进 B008 |
| **和 006-结算 的关系** | 结算时如果还有没选完的升级，应该直接作废，不弹框 |
| **和 `cfg/levelUp.json` 的关系** | `choiceCount=4` 决定弹几个；`statPack` 是属性池；`warBuffs` 是词条池 |
| **和其他系统的关系** | 神秘房间 / 稀有战利品 / 随机事件（三种意外惊喜）**目前都不在这个框里**，是独立系统 |

## 十、太奶奶要定的事

| 问题 | 选项 |
|---|---|
| **一、升级框弹出来的时候，战场怎么办？** | (A) **背景压暗 60%**（框最清楚，战场变背景板）　(B) 背景模糊 + 稍暗（高级感，但可能费性能）　(C) 不压暗，只把框做得更实、更大（保持「战场还在」的紧张感） |
| **二、一次升了好几级，怎么弹？** | (A) **一个接一个弹**，中间隔 0.3 秒（选择多、爽，但要连点好几次）　(B) **合并成一个框**：一次给 8 个选项挑 2 个（省事，但界面会挤）　(C) 先记着，等这波怪打完再一起弹（最不打断节奏） |
| **三、框里除了加属性，要不要出「新技能」？** | (A) **只要加属性**（简单、稳）　(B) 加「解锁新技能」的选项（新鲜，但要美术做图标）　(C) 加「特殊强力词条」：比如「子弹分裂」「击杀回血」（爽，但要做实现） |
