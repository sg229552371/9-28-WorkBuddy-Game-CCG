## 一、这个功能是干什么的

**一句话**：屏幕下方一条半透明的长条，把这一局上场的三名英雄一个个摆出来——头像、名字、职业、四个技能格子。

**它本来应该干什么**：让玩家随时看清「我这队都有谁、谁是什么职业、技能好了没有、冷却还剩多少」。

**它现在实际干什么**：**只显示名字和职业**。四个技能格子是**完全空的黑方框**，下面挂着的四个 `Lv1` 是**同一个数字重复四遍**。等于一条横着的名片，没有技能功能。

**对太奶奶级玩家的意义**：三人同场是这款游戏最大的卖点。底部这条是玩家唯一能确认「三个人都还在」的地方。如果这条是空的，卖点就看不见了。

## 三、怎么变化

### 3.1 一进来怎么组出来

| 步骤 | 发生什么 | 代码 |
|---|---|---|
| ① | 读 `GameState.team_ids`（选人屏写进去的队伍） | 第 587~591 行 |
| ② | 如果是空的 → 自动补一个「主英雄」 | 第 592~594 行 |
| ③ | 拿英雄表 `cfg/heroes.json`，把 id 对上名字和职业 | 第 595~602 行 |
| ④ | 一个英雄一组，从左往右排，整条居中 | 第 621~663 行 |
| ⑤ | 一个都没对上 → 整条不要了，退回文字模式 | 第 664~668 行 |

> **关键**：这条只在**开局时建一次**，进战斗以后**再也不更新**。所以头像、名字、四个格子、`Lv` 数字，从头到尾是死的。

### 3.2 现在的数字会不会变

| 项目 | 会不会变 | 说明 |
|---|---|---|
| 名字 | ❌ 不变 | 固定 |
| 职业色 | ❌ 不变 | 固定 |
| 头像字 | ❌ 不变 | 固定 |
| 四个格子 | ❌ 永远是空的 | 没有填充逻辑 |
| 格子下的 `Lv1` | ❌ 不变 | 读的是英雄初始等级 `hero_out_level`，一局里不刷新 |

### 3.3 底板会不会变

| 情况 | 表现 |
|---|---|
| 队伍 1 人 | 底板窄（只有一个头像 + 4 格） |
| 队伍 2 人 | 自动变宽 |
| 队伍 3 人 | 最宽 |
| 英雄死了（队员阵亡） | **底板没有任何变化**，头像也不变灰 |
| 升级 | **没有任何变化** |
| 技能放出去 | **没有任何变化**（没有冷却遮罩） |

## 四、各种状态

| 状态 | 什么样 | 什么时候 |
|---|---|---|
| **常态** | 三个头像并排 + 12 个空方框 + 12 个一样的 `Lv1` | 全程 |
| **升级** | 无变化 | — |
| **技能冷却中** | 无概念（没有冷却显示） | — |
| **队员阵亡** | 无变化（头像照常亮着） | — |
| **隐藏** | 英雄表读不到时整条消失，退回文字 | 极罕见 |
| **只有一人** | 底板变窄，一个人孤零零在中间 | 单人开打 |

> **这块最要命的是「队员阵亡没反应」**。三人同场，掉了一个人，底部这条还整整齐齐三个人亮着，玩家根本不知道人少了——这跟「三人同场」的卖点是直接冲突的。

## 五、声音 / 反馈

| 时机 | 现在 | 应该 |
|---|---|---|
| 技能放出去 | 无 | 格子盖一层半透明的黑「冷却雨刷」（从满到空扫下去） |
| 技能好了 | 无 | 格子亮一圈白光 + 一声轻「叮」 |
| 队员阵亡 | 无 | 头像变灰 + 打个红叉 + 一声闷响 |
| 点头像 | 无反应 | 应该弹这个英雄的详细面板（血量、装备、技能） |
| 关卡开始 | 无 | 三个头像从左往右「咔咔咔」滑进来（0.3 秒），有队伍感 |

**给太奶奶的大白话**：底部这条现在是「一张照片」，不是「一块仪表盘」。照片贴上去以后就不动了，不告诉你谁快死了、技能好没好。

## 六、异常情况

| 情况 | 现在会怎样 | 玩家看到什么 | 该怎样 |
|---|---|---|---|
| 选了 3 人，但英雄表里只有 1 个 id 对得上 | 只画对得上的，另外两个**直接跳过** | 底部只有一个人 | 应画灰色占位，让玩家知道「这里本来该有人」 |
| 队伍 id 全部对不上 | 整条隐藏 | 底部只剩一行小字 | 应报错给玩家看「队伍数据异常」 |
| 队伍设了 3 人但 `team_ids` 是空的 | 自动补一个主英雄 | 只有一人 | 应回主城重选，而不是悄悄降级 |
| 底板太宽超出屏幕 | 没有防护 | 两侧被切掉 | 三人时实测约 3 × 250 = 750，1280 宽够放 |
| 和「自动战斗」「背包」按钮重叠 | **不重叠**：按钮在右侧 y=612/646，底板右端最多到 x≈1015 | 正常 | ✅ |
| 和左下负重重叠 | **不重叠**：负重 y=678，底板底边 y=660 | ✅ | — |
| 和 B008 操作提示重叠 | 操作提示 y=680，底板底边 660 加回退文字 y≈698，**回退文字可能压到操作提示** | 底部字挤在一起 | 需要核对，见第十节 |

## 七、不许干的事

| ❌ | 为什么 |
|---|---|
| 四个格子永远空着 | 空框比没有更糟，玩家会以为「我的技能丢了」 |
| 四个格子下面重复同一个等级 | 视觉上等于骗人，看着像 4 个技能，实际只有 1 个数字 |
| 技能栏建完就不更新 | 一块死的仪表盘毫无意义 |
| 队员阵亡不显示 | 「三人同场」是卖点，人少了必须看得见 |
| 头像能点但点了没反应 | 点不动没关系，点得动却什么也不发生最气人 |
| 三个头像用同一套色 | 职业色是三人合作的唯一视觉线索，不能省 |
| 底板挡住地图中间 | 130 高、半透明，正好压在玩家脚下那一片，所以不能更宽更实 |

## 八、和其他文档的约定

| 项目 | 内容 |
|---|---|
| **输入** | `GameState.team_ids`（队伍）、`cfg/heroes.json`（名字、职业、初始等级 `hero_out_level`）、`cfg/heroRoles.json`（职业色） |
| **输出** | 目前无。头像是个按钮，但没有接任何功能 |
| **和 B003 的关系** | 队员等级如果要显示，最自然的位置就在这里（头像下面） |
| **和 B006 的关系** | 升级只加队长的属性（`combat.apply_levelup_choice`），队员不升。技能栏如果要显示队员等级，得先定队员升不升级 |
| **和 B008 的关系** | 「自动战斗」「背包」两个按钮在底板右侧、上方，不重叠；但底板下方那行回退文字和操作提示间距很紧 |
| **和 `cfg/team.json` 的关系** | `maxSize=3` 决定最多三组；`aiSkill=true` 表示队员自己放技能，所以理论上格子该有冷却显示，现在完全没有 |

## 十、太奶奶要定的事

| 问题 | 选项 |
|---|---|
| **一、四个空格子怎么办？** 现在 4 个空框 + 4 个一样的 `Lv1`，纯占地方 | (A) **填 4 个真技能**：每格一个图标 + 快捷键 + 冷却雨刷（要美术画 12 张图标）　(B) **缩成 1 个大格子**：每个英雄只显示一个主动技能（要美术画 3 张，最省）　(C) **干脆去掉整条**，只留技能名文字（最省事，但三人卖点看不见了） |
| **二、队员要不要跟着升级？** | (A) **不升**，只有队长升（简单，队员会越来越弱）　(B) **跟着升**，队长升 1 级队员也升（感觉好，但三个人同时弹强化框会很烦）　(C) **队员按比例升**，等级永远比队长低 2 级（折中） |
| **三、点头像该干什么？** | (A) 什么都不做，头像只是装饰（去掉按钮属性，别让人觉得能点）　(B) 弹出这个英雄的小卡片：血量、装备、技能　(C) 切换操控的英雄（一局内换人玩） |
