## 一、这一屏是干什么的

**一句话**：玩家带着三名英雄跳进关卡，打满进度把 Boss 打出来、打死，然后跑到撤离点站够 8 秒，把这一局捡到的东西带回家。

**太奶奶怎么理解这一屏**：这就是「下矿」。打怪 = 挖矿，捡到的宝箱 = 挖到的矿，撤离点 = 上山的缆车。缆车没坐上之前，矿都是「背在身上的」，人一倒下就全丢了。

**四条设计底线**

| 底线 | 具体做法 | 代码依据 |
|---|---|---|
| 一眼看懂还剩多少怪 | 屏幕最上方一条金条，打满就出 Boss | 第 460~479 行 |
| 知道自己在哪、还剩多少命 | 左上 HP，右上等级和金币 | 第 513~530 行 |
| 手感要「爽快割草」 | 默认自动战斗是**开**的（配置 `autoFight` 没写 `enabled` 时按开处理），玩家可以只躲不打 | `combat.gd` 第 203~206 行 |
| 核心难点是「舍不得走」 | Boss 一死就出撤离点，读条 8 秒，读条期间一直刷怪压你 | `cfg/extract.json` `channel=8`、`waveInterval=2.5` |

**已经定死、不许再改的三条**

| 编号 | 结论 | 说明 |
|---|---|---|
| 定-1 | **打死 Boss 就算赢**，死亡丢光本局捡到的所有东西（局外等级保住） | 输赢口径 |
| 定-2 | **三人同场**，队员跟随队长，局内满级 46 级，均匀爬升 | 队伍口径 |
| 定-3 | **负重超了只是轻微变慢**，不是不能动 | 手感口径 |

## 六、和其他文档的约定

| 约定 | 内容 |
|---|---|
| 谁决定进哪一关 | `GameState.level_id`，主城选关时写进去；本屏只读（第 69~76 行） |
| 谁决定派哪三个人 | `GameState.team_ids`，选人屏写进去；缺省单人（第 587~594 行） |
| 谁是队长 | 玩家操控的那位；队员按 `cfg/team.json` `follow.depth=58`、`trailStep=5` 跟在后面 |
| 胜负怎么告诉别人 | 逻辑层 `combat.gd` 第 361~372 行发 `EventBus.run_settled`，`winner` 只有两个值：`"extract"`（撤离成功）/ `"dead"`（阵亡） |
| 本屏怎么接 | `battle.gd` 第 146~154 行 `_on_run_settled()`，**不管输赢都调 `_show_death_settlement()`** |
| 结算面板归谁 | 面板内容归 `006-结算`；本屏只负责「什么时候弹」和「按钮点完去哪」 |
| 「返回主城」去哪 | `_back_to_city()` 第 284~285 行，切到 `city.tscn` |
| 存档谁落 | `_save_on_death()` 第 221~234 行，**一局只落一次**（`_saved` 阀）。撤离成功也会落（第 153 行） |
| 开局冻结谁给 | `cfg/levelFreeze.json` `freezeTime=3`、`hint="准备战斗"`；`combat.gd` 第 198~202 行读进来 |
| 升级选几项 | `cfg/levelUp.json` `choiceCount=4`（不是三），实际弹 4 个按钮 |
| 关卡的怪量够不够 | `cfg/levels.json` 第 1 关 `progressGoal=60`、`timeLimit=180`、`monsterCap=120`；第 99 关 `progressGoal=2336`、`timeLimit=1200` |
| 一次最多上多少只怪 | 第 1 关 120 只（`monsterCap`）；第 99 关 420 只 |
| 子弹最多多少 | `cfg/boss.json` `bulletCap=260`（全屏子弹上限，防止卡死） |

## 十、太奶奶需要拍板的事

| 问题 | 选项 |
|---|---|
| **一、怎样算「赢」？** 现在两处说法打架：设计说「打死 Boss 就赢」，配置备注写「死亡时撤离点雕像消散」 | (A) 打死 Boss 就**立刻算赢**，撤离点只是演出（简单、爽）　(B) 打死 Boss 出撤离点，**站够 8 秒才算赢**，死了全丢（紧张、符合「舍不得走」）　(C) 两个都算：打死 Boss 先记一份保底，撤离成功再加一份奖励 |
| **二、负重满了怎么提醒？** 现在只有一行数字 | (A) 加一条横着的进度条，超 100% 变红（看得清楚）　(B) 只在超重时弹一行红字「太重了，走不动了」（不占地方）　(C) 两个都要 |
| **三、技能栏 4 个空框怎么办？** | (A) 填 4 个真技能图标（要美术画图）　(B) 缩成 1 个主动技能大图标（省地方）　(C) 干脆去掉整条，只留技能名 |
| **四、打开背包/水晶面板时要不要停住世界？** | (A) 停住，跟暂停一样（安全，不会被偷袭）　(B) 不停，边翻包边挨打（真实，但容易死得冤） |
