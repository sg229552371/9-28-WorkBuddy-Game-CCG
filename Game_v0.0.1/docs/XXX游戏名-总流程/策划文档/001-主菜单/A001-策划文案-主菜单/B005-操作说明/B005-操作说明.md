## 一、这个功能是干什么的

**一句话**：告诉玩家「这个游戏怎么玩」。玩家不会玩就会关掉，这是最后一道保险。

**对太奶奶级玩家尤其重要**：不认字、不熟悉键盘的玩家，全靠这一页。

## 七、界面规则

| 规则 | 内容 |
|---|---|
| 返回 | 「返回首页」按钮，回主菜单 |
| 键盘 | Esc 也回主菜单 |
| 滚动 | 内容超过一屏时垂直滚动 |
| 字号 | 正文 18 号以上（太奶奶要看得清） |
| 行距 | 行与行之间留 20 px 空隙，别挤在一起 |
