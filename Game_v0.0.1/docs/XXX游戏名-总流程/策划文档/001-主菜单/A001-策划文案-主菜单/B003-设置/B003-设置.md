# B003-设置

> 父级：`001-主菜单`　｜　版本 v1.0　｜　2026-10-26
> 对应代码：`flow_root.gd` `_build_settings()` 第 368~430 行

---

## 一、这个功能是干什么的

**一句话**：让玩家调「声音多大」「画面多精细」「能不能静音」。

**对太奶奶级玩家的意义**：声音太大吵到人、画面卡、想静音——这三件事解决不了，玩家直接不玩了。

---

## 二、界面上有哪几项

| 序号 | 项目 | 类型 | 取值范围 | 默认值 |
|---|---|---|---|---|
| 1 | 音效音量 | 滑杆 | 0 ~ 100% | 80% |
| 2 | 音乐音量 | 滑杆 | 0 ~ 100% | 70% |
| 3 | 静音 | 开关按钮 | 开 / 关 | 关 |
| 4 | 画质 | 三档按钮 | 低 / 中 / 高 | 中 |
| 5 | 全屏 | 开关按钮 | 开 / 关 | 开 |
| 6 | 返回 | 按钮 | — | — |

---

## 三、每一项的详细规则

### 3.1 音效音量滑杆

| 项目 | 规格 |
|---|---|
| 标签 | 「音效音量」 |
| 滑杆长度 | 300 px |
| 步进 | 每次移动 10%（0.1） |
| 右侧数字 | 实时显示「80%」 |
| 拖动时 | **立即生效**（拖到 30% 当下就变小） |
| 松手后 | 保存进存档 |

> **注意**：现在版本拖动滑杆**不会立即生效**，要退出重进才听到。这是个 bug，必须修。

### 3.2 音乐音量滑杆

规则同上，但控制的是背景音乐。

> 现在游戏还没有背景音乐，这个滑杆先放着，等有音乐了自动生效。

### 3.3 静音按钮

| 项目 | 规则 |
|---|---|
| 文字 | 静音时显示「已静音」，没静音时显示「静音」 |
| 点击 | 所有声音归零（音效+音乐） |
| 再点 | 恢复到静音前的音量 |
| 记忆 | 静音前音量要记住，不能恢复成默认值 |

### 3.4 画质三档

| 档位 | 效果 | 什么时候选 |
|---|---|---|
| 低 | 关掉粒子、关掉阴影、关掉光晕 | 电脑卡的时候 |
| 中 | 保留粒子，关掉阴影 | 默认 |
| 高 | 全开 | 电脑好的时候 |

**为什么要给玩家选**：老电脑跑高画质会卡，卡了玩家就怪「这游戏做得差」。

### 3.5 全屏开关

| 项目 | 规则 |
|---|---|
| 文字 | 全屏时显示「全屏」，窗口时显示「窗口化」 |
| 切换 | 立即生效 |
| 记忆 | 存进存档 |

## 五、存档规则

| 项目 | 存不存 | 存在哪 |
|---|---|---|
| 音效音量 | ✅ 存 | 存档 `settings.sfxVolume` |
| 音乐音量 | ✅ 存 | 存档 `settings.bgmVolume` |
| 静音状态 | ✅ 存 | 存档 `settings.muted` |
| 画质档位 | ✅ 存 | 存档 `settings.quality` |
| 全屏 | ✅ 存 | 存档 `settings.fullscreen` |

**规则**：改完立刻存，不需要玩家点「保存」。现在玩家不会想到要手动保存。

## 六、不许干的事

| ❌ | 为什么 |
|---|---|
| 改音量后要重启才生效 | 玩家以为坏了 |
| 音量归零后恢复成默认 80% | 应该恢复到玩家自己调过的值 |
| 设置界面弹广告或推荐 | 设置就是设置，别塞东西 |
| 忘记存 | 玩家每次开游戏都要重调，会骂人 |
