## 一、这个功能是干什么的

**一句话**：让玩家调「声音多大」「画面多精细」「操作方式舒服不舒服」。

**对太奶奶级玩家的意义**：声音太大吵到人、画面卡、想静音——这三件事解决不了，玩家直接不玩了。

## 三、每一项的详细规则

### 3.1 音效 / 音乐音量滑杆

| 项目 | 规格 |
|---|---|
| 滑杆步进 | 10%（0.1） |
| 右侧数字 | 实时显示「80%」 |
| 拖动时 | **立即生效**（拖到 30% 当下就变小） |
| 松手后 | 保存进存档 |

> **注意**：现在版本拖动滑杆**不会立即生效**，要退出重进才听到。这是个 bug，必须修。
> 音乐音量滑杆先放着，等有背景音乐了自动生效。

### 3.2 静音

| 项目 | 规则 |
|---|---|
| 点击 | 所有声音归零（音效+音乐） |
| 再点 | 恢复到静音前的音量 |
| 记忆 | 静音前音量要记住，不能恢复成默认值 |

### 3.3 画质三档（下拉）

| 档位 | 效果 | 什么时候选 |
|---|---|---|
| 低 | 关掉粒子、关掉阴影、关掉光晕 | 电脑卡的时候 |
| 中 | 保留粒子，关掉阴影 | 默认 |
| 高 | 全开 | 电脑好的时候 |

### 3.4 全屏开关

立即生效，存进存档。全屏时显示「全屏」，窗口时显示「窗口化」。

### 3.5 v3.0 新增开关（细化图已画，待实现）

| 项目 | 默认 | 为什么 |
|---|---|---|
| HUD 显示 | 开 | 玩家可关掉 HUD 看弹幕/截图（同类游戏标配） |
| 战斗震屏 | 开 | 3D 眩晕玩家需要能关 |
| 伤害数字 | 开 | 想看纯弹幕的玩家可关 |
| 字幕显示 / 字幕大小 | 开 / 小 | 无声玩家刚需 |

## 四、存档规则

| 项目 | 存不存 | 存在哪 |
|---|---|---|
| 音效音量 | ✅ 存 | 存档 `settings.sfxVolume` |
| 音乐音量 | ✅ 存 | 存档 `settings.bgmVolume` |
| 静音状态 | ✅ 存 | 存档 `settings.muted` |
| 画质档位 | ✅ 存 | 存档 `settings.quality` |
| 全屏 | ✅ 存 | 存档 `settings.fullscreen` |
| HUD / 震屏 / 伤害数字 / 字幕 | ✅ 存 | 存档 `settings.hud / shake / dmgNum / subtitle` |

**规则**：改完立刻存，不需要玩家点「保存」。

---

## 五、不许干的事

| ❌ | 为什么 |
|---|---|
| 改音量后要重启才生效 | 玩家以为坏了 |
| 音量归零后恢复成默认 80% | 应该恢复到玩家自己调过的值 |
| 设置界面弹广告或推荐 | 设置就是设置，别塞东西 |
| 忘记存 | 玩家每次开游戏都要重调，会骂人 |
| 关掉设置窗口丢改动 | 改完即存，Esc 只是关窗口，不是「取消」 |
