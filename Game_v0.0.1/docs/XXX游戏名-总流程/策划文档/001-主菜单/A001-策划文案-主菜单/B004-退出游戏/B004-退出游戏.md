## 一、这个功能是干什么的

**一句话**：玩家想关游戏，先问他一句「真要退出吗」，确认了才真的关。

**为什么要问一句**：玩家可能手滑点到。不问就关，玩家会烦。

## 三、点击后发生什么

| 玩家点 | 结果 |
|---|---|
| 「退出」 | 关掉游戏窗口，程序结束 |
| 「继续」 | 关掉这个确认框，回到主菜单 |
| 按 Esc | 等同「继续」（安全默认） |
| 按回车 | 等同「继续」（安全默认，不能默认退出） |
| 点黑幕空白处 | 等同「继续」 |

> **关键设计**：**默认动作必须是「继续」**。玩家手一抖按了回车，不能直接把游戏关了。

---

## 四、退出前要不要检查「未保存的进度」

| 情况 | 处理 |
|---|---|
| 玩家在主菜单（本次没有进行中的战斗） | 直接退出，不用多问 |
| 玩家有未保存的进度 | **目前不会出现**（主菜单不会产生进度） |

> 现在主菜单退出很安全，因为所有进度在回主城时就存好了。以后如果加了「战斗中途退出」，这里要改成「你有未保存进度，确定退出？」。

---

## 五、不许干的事

| ❌ | 为什么 |
|---|---|
| 不问就退出 | 手滑的玩家会疯 |
| 默认按钮是「退出」 | 按个回车游戏就没了，太危险 |
| 退出时清空存档 | 绝不能。存档必须留着 |
| 退出后留后台进程 | 玩家看到任务管理器里还有游戏，会以为中病毒 |
