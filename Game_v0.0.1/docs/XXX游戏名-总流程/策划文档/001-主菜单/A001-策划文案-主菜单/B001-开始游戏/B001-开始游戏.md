# B001-开始游戏

> 父级：`001-主菜单`　｜　版本 v1.0　｜　2026-10-26
> 对应代码：`flow_root.gd` 第 310~311 行（`start.pressed.connect(go_city)`）

---

## 一、这个功能是干什么的

**一句话**：主菜单上最大最亮的那个按钮，点了就进主城。

**它是全游戏唯一的入口。** 玩家每次启动游戏，90% 的情况是点这个按钮。

---

## 二、按钮长什么样

| 项目 | 规格 |
|---|---|
| 文字 | 「开始游戏」四个字 |
| 宽度 | 320 px |
| 高度 | 56 px |
| 字号 | 24 号，加粗 |
| 底色 | 金色 `#e8b33c` |
| 文字色 | 深色 `#131c2c`（深底浅字，对比强） |
| 圆角 | 6 px |
| 位置 | 水平居中，距屏幕顶部约 320 px |
| 与其他按钮的间距 | 下方留 16 px 空隙 |

**为什么它必须最亮**：太奶奶级玩家进游戏不知道该点啥，就点最亮最大的那个。这是保命设计。

---

## 三、点击后发生什么（完整流程）

```
玩家点「开始游戏」
   ↓
① 主菜单整体淡出（0.2 秒）
   ↓
② 隐藏主菜单（包括档案行、版本行）
   ↓
③ 切换到主城场景
   ↓
④ 主城淡入（0.2 秒）
   ↓
⑤ 玩家看到自己的角色站在主城中央
```

**耗时**：约 0.4 秒。超过 1 秒玩家会觉得卡。

---

## 四、点击时界面要有反应（三个状态）

按钮必须有三种样子，让玩家知道「我点到了」：

| 状态 | 什么时候 | 样子 |
|---|---|---|
| 常态 | 没碰它 | 金色底 + 深色字 |
| 悬停 | 鼠标移上去 | 金色变亮（提亮 15%）+ 按钮微微放大到 1.03 倍 |
| 按下 | 按住没松 | 金色变暗（压暗 15%）+ 缩小到 0.97 倍 |
| 禁用 | 不会出现 | 这个按钮永远可点，没有禁用状态 |

> 太奶奶注意：**「按下」那一下要有变化**。没有变化的按钮，玩家会以为没点到，会连点好几下。

---

## 五、声音

| 时机 | 声音 |
|---|---|
| 鼠标移上去 | 轻微「嗒」一声（音量 30%） |
| 点下去 | 「咚」一声（音量 60%，沉稳感） |

> 现在游戏里已经有音效系统，这两个音都在。声音很关键——比画面更能让玩家确认「点到了」。

---

## 六、异常情况怎么处理

| 情况 | 处理 | 玩家看到什么 |
|---|---|---|
| 主城场景加载失败 | 回到主菜单，不崩 | 提示条「进入主城失败，请重试」 |
| 存档损坏 | **照样进主城**，用默认数据 | 主城里档案显示「存档读取失败」 |
| 玩家连点两下 | 只认第一下，第二下忽略 | 无感，不会闪两次 |
| 键盘上按回车 | 等同点这个按钮 | 正常进主城 |

---

## 七、这个功能不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| 直接跳去选关 | 必须先经过主城，让玩家有机会看自己的角色、看 NPC。这是节奏设计 |
| 自己加载战斗 | 加载战斗是主城的事，这里越权会乱 |
| 重置玩家存档 | 绝不能。点个开始游戏就把存档清了，是灾难 |
| 弹任何确认框 | 点「开始游戏」不需要确认。确认框只用在「退出」 |

---

## 八、和其他文档的约定

| 对象 | 约定 |
|---|---|
| 输入 | 玩家点鼠标左键（或触摸屏点一下） |
| 输出 | 通知流程控制：**去主城** |
| 依赖 | 主城界面必须已经建好，否则点下去会白屏 |
| 前置 | 无（任何时候都能点） |
