## 一、这一屏是干什么的

**一句话**：玩家打开游戏看到的第一个画面，让他 3 秒知道是什么游戏，5 秒能开始玩。

**三条设计底线**（太奶奶要求：玩家不识字也能玩）

| 底线 | 具体做法 |
|---|---|
| 一眼看懂 | 主按钮「开始游戏」最大最亮，别的都小 |
| 不会迷路 | 只有一条主路：往下点「开始游戏」 |
| 有进度感 | 底部显示名字 + 称号 + 结晶数，让玩家看到攒了多少 |

## 五、这个界面能做和不能做的事

### ✅ 能做的

| 玩家动作 | 结果 |
|---|---|
| 点「开始游戏」 | 进入主城（`002-主城`） |
| 点「设置」 | 弹出**设置窗口**（960×600 弹窗，含「操作」页签 = 原操作说明，`B003`） |
| 点「图鉴」 | 打开图鉴（`B002`） |
| 点「退出游戏」 | 弹确认框（`B004`） |
| 按键盘 Esc | **无反应**（主菜单不响应 Esc） |

### ❌ 不能做的（必须挡住）

| 情况 | 处理 |
|---|---|
| 在主菜单存档 | 不需要，主菜单不改任何数据 |
| 直接跳去选关 | 不允许。必须经过主城（这是流程锁） |
| 主菜单读到损坏存档 | 不能崩。用默认值开局，并在档案行显示「存档读取失败」 |
