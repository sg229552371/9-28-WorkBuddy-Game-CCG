## 一、这个功能是干什么的

**一句话**：发现选错关了，退回去重新挑一关。

**它和「返回主城」不是一回事**：选关屏的返回是「我不打了，回城」；这里的返回是「这关我不想打，换一关」。所以它**不需要经过主城**，直接退回选关屏。

**对玩家的意义**：玩家在选关屏点了一关进来，看到敌人搭配和英雄不合适（或者纯手滑点错关），得能一步退回去。**这是「选错一关」的成本，必须是一条短线**——退一步回去，再点一关，总共两个点击。

**和整款游戏的关系**：全局已定——死了丢光本局捡到的东西。所以在真正出战之前，**任何一步都应该能免费反悔**。这个按钮就是那个反悔键，它不带任何代价：不掉东西、不清进度、不解锁也不锁关。

## 三、点击后发生什么

| 步骤 | 发生什么 | 玩家看到什么 | 耗时 |
|---|---|---|---|
| ① | 按下「返回」 | 系统默认按下效果（比较轻） | 0 |
| ② | 通知「切到选关屏」 | 画面开始变 | 立刻 |
| ③ | 检查这一步合不合法（选人 → 选关是白名单允许的，第 23 行） | — | 眨眼都不到 |
| ④ | 把选人屏藏起来、把选关屏显示出来 | **直接切过去**，没有转场动画 | 立刻 |
| ⑤ | 停留在选关屏，**关卡列表不会重建** | 关卡卡片还是原来那些，位置也没变 | 立刻 |

> 关键点：**退回去的时候不会重建关卡列表**（重建只在「从主城进门」那一步做，第 152 行）。所以退回去很快，不会卡一下。

**退回去以后，之前选的英雄会怎样？**

| 情况 | 结果 |
|---|---|
| 玩家退回去，又点同一关进来 | 队伍是**空的**（每次进选人屏都会先清空队伍，第 746 行） |
| 玩家退回去，点另一关进来 | 同样空的 |

> **太奶奶注意**：这意味着玩家退回去换一关，**刚才选的 3 个人全白选了，要重新点**。这是现在真实的行为。见第七节和第十节第 2 题。

**会不会带走了什么不该带的东西？**

| 东西 | 会不会被改 |
|---|---|
| 结晶数 | 不变 |
| 已解锁关卡数 | 不变 |
| 关卡星级记录 | 不变 |
| 队伍名单 | **会被清空**（下次进来是空的） |
| 本局关卡编号 | 不变（还是上次点的那一关，除非重新点别的） |

## 四、各种状态

| 状态 | 样子 | 能点吗 |
|---|---|---|
| 常态 | 灰蓝底、无边框、白字「返回」 | ✅ 一直能点 |
| 悬停 | 系统默认一点点变化 | — |
| 按下 | 系统默认按下效果，比较轻 | — |
| 禁用 | **不存在** | — |
| 队伍已满 3 人 | 和常态一样，因为它是退路，跟队伍状态无关 | ✅ 能点 |
| 一个人都没选 | 和常态一样 | ✅ 能点 |

> 这一屏有两个按钮：一个在没人时被禁用（出战），一个**永远不被禁用**（返回）。这是有意的——**退路不能有任何条件**。

## 六、异常情况

| 情况 | 会怎么 | 玩家看到什么 | 应该怎么处理 |
|---|---|---|---|
| 选关屏的关卡列表是空的（配置表读坏） | 照样切回去，回到一个空白选关屏 | 一片空白 | 选关屏自身应有「数据读取失败」提示（`003` 那边的事） |
| 玩家退回去，又点同一关 | 队伍清空，重新选人 | 金边全没了 | 现在就是这样。见第十节第 2 题 |
| 主城那边在玩家选人时又触发了一次传送门 | 选关/选人时守卫会挡住，不重复弹（第 150~151 行） | 没变化 | ✅ 已防住 |
| 连点两次「返回」 | 第一次已切到选关，第二次点落在选关屏上 | 可能误点到某张关卡卡片 | 建议点下后短暂禁用它 |
| 玩家在选人屏按 Esc | **没绑定** | 没反应 | 建议和按钮等效 |

## 七、不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| 在某些情况下禁用「返回」 | 它是退路。没人选、满员、配置坏了，都得能退 |
| 返回时**顺手清空玩家的关卡进度或结晶** | 玩家什么都没打，扣东西就是坑人 |
| 返回时**跳过选关直接回主城** | 玩家想的是「换一关」，不是「不打了」。回城是选关屏那个按钮的事 |
| **退回时重建 99 张关卡卡片** | 白卡一下。关卡列表在这时候不会变，没必要重建 |
| 把「返回」做成金色大按钮 | 会和「开始出战」抢主次，玩家容易点错 |
| 弹「确定要放弃这次配队吗？」 | 配队不值钱，30 秒能重配好。弹框只会烦人 |
| 按返回后自动把玩家带到「上次选的那一关」并立刻进去 | 玩家是要**重新挑**，不是要原路返回 |
| 按下完全没有反馈 | 玩家会连点，容易误触到关卡卡片上 |

## 八、和其他文档的约定

| 项目 | 内容 |
|---|---|
| **输入** | 一次点击，不带参数 |
| **输出** | 屏幕状态切回「选关」；选关屏原样显示（不重建列表） |
| **不改的东西** | 结晶、已解锁关卡数、关卡星级、本局关卡编号 |
| **会受影响的东西** | 队伍名单——下次再进选人时是空的（第 746 行清空） |
| **前置条件** | 无。任何时刻都能点 |
| **和 `003-选关` 的约定** | 选关屏负责「从哪来、能打哪几关」；退回来时它不重建、不重置滚动位置 |
| **和 `B003-出战按钮` 的约定** | 同一行、左退右进，样式分主次（返回素、出战金） |
| **和 `002-主城` 的约定** | 这条路径不经过主城，主城不参与 |
| **和 `005-战斗` 的约定** | 无关系，这里从没进过战斗 |

## 十、太奶奶要定的三件事

| 问题 | 选项 |
|---|---|
| **这个按钮上的字写什么？** | (A) 「返回」（现在这样）　(B) 「← 换个关卡」（更说明目的）　(C) 「返回选关」 |
| **退回去换一关再进来，要不要记住上次选的人？** | (A) 记住，队伍留着（省事）　(B) 清空，重新选（现在这样，每次都是干净开始）　(C) 记住，但只记前两个 |
| **按 Esc 要不要也能退回选关？** | (A) 要　(B) 不要，只认按钮　(C) 要，但只在没选人的时候生效 |
