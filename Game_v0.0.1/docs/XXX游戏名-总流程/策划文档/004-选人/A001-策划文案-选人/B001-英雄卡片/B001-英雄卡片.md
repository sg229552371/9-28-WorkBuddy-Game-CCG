## 一、这个功能是干什么的

**一句话**：一张小方块 = 一个英雄。上面画着他的头像色块、名字、难易星、练到几级。**点一下就是「带他出门」，再点一下就是「不带他」**。

**它是这一屏唯一要做决定的地方。** 12 张卡排两排，玩家扫一眼就该知道：谁是输出、谁是辅助、哪个我还没解锁、哪个我练得最熟。然后点 1~3 个，走。

**和整款游戏的关系**：全局已定——三人同场，队员跟着队长走。**第一个点的人就是队长**，所以「先点谁」不是随便的，顺序有意义。这一点现在界面上没有说明，玩家可能不知道。

**为什么最多 3 人**：配置表 `cfg/team.json` 的 `maxSize = 3`。12 个英雄里选 3 个，组合数很多，所以每次选都要掂量——这是这一屏最有趣的地方，也是玩家最容易出错的地方（选满 3 个还想换人）。

### 2.3 星级怎么算（重要，别搞错）

代码里星星的个数**取的是英雄表里的「难度」值，不是「练到几级」**。

| 英雄 | 难度 | 画几颗星 | 亮几颗 |
|---|---|---|---|
| H001 猎手 | 1 | 1 颗 | 1 颗实心 |
| H003 穿甲者 | 2 | 2 颗 | 2 颗实心 |
| H002 散弹手 | 3 | 3 颗 | 3 颗实心 |
| 未解锁的英雄 | 不管几 | 按难度画 | **全空心**（第 802 行：未解锁一律画空心） |

> **太奶奶注意**：这颗星的意思是「**这个英雄上手难不难**」，不是「练到第几级」。**1 颗星最好上手，3 颗最难**。配置表里另外有一份「推荐上手顺序」（H001 猎手最简单 → H009 守护者最难），但界面**没有用上**，所以玩家看到 H009 守护者会和 H001 一样只有 1 颗星，看似简单、其实最难。这是数据口径不一致，见第九节。

### 2.4 一张卡片长什么样

```
已解锁（能点）                         未解锁（点不动）
┌──────────────────┐  ← 150×150        ┌──────────────────┐
│    ┌──────────┐  │                   │    ┌──────────┐  │
│    │    猎    │  │ ← 48×48 职业色     │    │    守    │  │ ← 深蓝灰，糊成一片
│    └──────────┘  │   中间是名字首字    │    └──────────┘  │
│       猎手       │ ← 17 号骨白        │      守护者       │ ← 17 号暗灰
│        ★         │ ← 实心金星         │       ☆         │ ← 空心灰星
│     局外 LV1     │ ← 13 号灰蓝        │     局外 LV1     │ ← 灰蓝
└──────────────────┘                   └──────────────────┘

被选中（带他出门）
┌──────────────────┐
│  ╔══════════════╗│ ← 外面多一圈 2px 金边
│  ║  …同上…      ║│
│  ╚══════════════╝│
└──────────────────┘
```

> **太奶奶注意**：右边那张「未解锁」的卡片，只靠「颜色变灰」区分。**它点了不会有任何反应，也没说怎么才能解锁**。玩家会盯着这张灰卡片发呆，或者干脆不玩了。

## 三、点击后发生什么

### 3.1 点一个「还没选」的英雄（队伍没满）

| 步骤 | 发生什么 | 玩家看到什么 | 耗时 |
|---|---|---|---|
| ① | 按下卡片上那层透明按钮 | 没有按下效果（透明按钮没有样式） | 0 |
| ② | 检查队伍人数，还没满 3 | 没变化 | 眨眼都不到 |
| ③ | 把这个英雄加进队伍名单 | — | 同上 |
| ④ | 给这张卡片套上 2 像素金边 | **金边亮起** | 立刻 |
| ⑤ | 在下方详情面板里画这个英雄的全部信息 | **下方面板内容整体换掉** | 立刻，肉眼几乎无感 |
| ⑥ | 右下角按钮文字变成「开始出战 (1/3)」 | **数字变了** | 立刻 |

### 3.2 点一个「已经选了」的英雄（取消）

| 步骤 | 发生什么 | 玩家看到什么 | 耗时 |
|---|---|---|---|
| ① | 按下卡片 | 无按下效果 | 0 |
| ② | 发现他已经在名单里 → 从名单删掉 | — | 立刻 |
| ③ | 把卡片样式还原（去掉金边） | **金边消失** | 立刻 |
| ④ | **又在详情面板里画了一遍这个人**（第 871 行照常执行） | **下面还是显示他**，玩家可能困惑 | 立刻 |
| ⑤ | 按钮文字变「开始出战 (0/3)」 | 数字变了，如果 0 人按钮变灰 | 立刻 |

> **这就是「行为不一致」的那处**：取消选择时，卡片明明已经变了，下面详情却仍然是他。玩家取消了一个人，看到下方面板还写着他，会怀疑「到底取消了没」。这是缺陷，见第九节。

### 3.3 点一个「还没选」的英雄（队伍已满 3 人）

| 步骤 | 发生什么 | 玩家看到什么 | 耗时 |
|---|---|---|---|
| ① | 按下卡片 | 无 | 0 |
| ② | 检查队伍人数，已满 3 | — | 立刻 |
| ③ | 程序内部打一句警告，**直接结束** | **屏幕上什么都没有** | 立刻 |

> **这就是「满员静默失败」**（第 860~863 行）。玩家点了第 4 个英雄，卡片没亮、详情没变、按钮没变、没有声音、没有提示。玩家的第一反应是「点坏了」或者「这个游戏卡了」。这是这一屏最要紧的缺陷。

### 3.4 点一个「未解锁」的英雄

| 步骤 | 发生什么 | 玩家看到什么 |
|---|---|---|
| ① | 按下去 | 无 |
| ② | **什么都没接到**（未解锁卡片根本没加按钮，第 841 行） | **什么都没发生**，连气泡都还在 |

## 四、各种状态

| 状态 | 条件 | 样子 | 能不能点 |
|---|---|---|---|
| 已解锁·未选中 | 有这个英雄、没进队伍 | 职业色头像 + 骨白名字 + 实心金星 + 无边框 | ✅ 能，点一下选中 |
| 已解锁·已选中 | 已进队伍 | 同上 + **2 像素金边** | ✅ 能，点一下取消 |
| 已解锁·鼠标悬停 | 鼠标在卡上 | 弹名字小气泡 | — |
| 已解锁·按下 | 正按着 | **没有变化** | — |
| 未解锁 | 存档里没这个英雄 | 深蓝灰头像 + 暗灰名字 + **空心星** + 无边框 | ❌ 完全点不动，也没有任何说明 |
| 队伍已满时点别人 | 已有 3 人 | 外表完全不变（因为点不进去） | 应答：弹「最多 3 人」 |
| 卡片禁用 | **不存在** | 未解锁就是「点不动」，但看起来不像「禁用」，看起来像「坏的」 | — |

> **四态缺了按压**：卡片按下去完全没有变化，玩家感受不到「我点中了」。建议加一点「按下缩到 97%」的效果。

## 五、声音/反馈

| 时机 | 现在 | 应该 |
|---|---|---|
| 选中一个英雄 | ❌ 无声 | ✅ 一声清脆「叮」，金边亮起 |
| 取消选中 | ❌ 无声 | ✅ 一声低一点的「嗒」 |
| 队伍已满时点别人 | ❌ 无声也无画面 | ✅ 一声闷「咚」+ 卡片轻抖 + 一行字「最多 3 人」 |
| 点了未解锁英雄 | ❌ 无声无画面 | ✅ 一声闷「咚」+ 一句「还没解锁」 |
| 鼠标滑过卡片 | ❌ 只有气泡 | 🟡 卡片轻微变亮（可选） |

> 这一屏**目前完全没有音效**。但注意：光加音效不够，玩家可能静音——**满员和未解锁这两种情况必须有看得见的提示**。

## 六、异常情况

| 情况 | 会怎么 | 玩家看到什么 | 应该怎么处理 |
|---|---|---|---|
| 英雄配置表读不到 | 打一句警告，一张卡都不建 | 网格空白 | 显示「英雄数据读取失败」+ 建议「返回」 |
| 12 个英雄里有条目格式坏 | 跳过那一条 | 少一个英雄 | 少一个不致命，但要在日志里记下来 |
| 存档里英雄记录缺失 | 按「未解锁」处理 | 一张灰卡 | 合理 |
| **队伍已满点第 4 个** | 静默失败 | **什么都没有** | 弹「最多 3 人」（待办 T1） |
| 点了未解锁英雄 | 静默 | 什么都没有 | 弹「还没解锁」+ 写清怎么解锁（待办 T3） |
| 选了一个人后不选第二个人就出战 | 允许（1 人也行） | 按钮写「开始出战 (1/3)」 | 这是设计，不是错 |
| 攒了 3 个人，其中一个英雄的配置在中途被删 | 重建网格时这个英雄消失 | 队伍里凭空少一个 | 重建时校验名单，把不存在的去掉 |
| 连点同一个英雄两次 | 选中又取消 | 金边闪一下 | 正常，但建议加一点防抖（0.1 秒内不响应第二下） |

## 七、不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| **满员时点了完全没反应** | 这是现在的真实毛病。玩家分不清「满了」还是「坏了」 |
| 未解锁卡片和已解锁卡片只差「字变灰」 | 低亮度屏上几乎看不出。未解锁必须有锁的形象或解锁说明 |
| 未解锁卡片也能点进队伍 | 那等于没解锁，破坏成长线 |
| 取消选择后，下方详情还留在被取消的人身上 | 玩家会怀疑「到底取消了没」 |
| 星级用「难度」画，却让人以为是「养成等级」 | 数据口径不一致。要么统一口径，要么在界面上说清这颗星代表什么 |
| 卡片按下去没有任何反馈 | 玩家会连点，容易误选 |
| 一次把 12 张卡全建一遍（每张带一个透明按钮） | 12 张不算多，但每次进选人都重建，可以缓存 |
| 同一英雄能被选两次 | 第 853~854 行已防（点了就是取消），别改坏 |
| 卡片上写一堆属性数字 | 属性在详情面板里看。卡片只放「认人」用的一眼信息 |

## 八、和其他文档的约定

| 项目 | 内容 |
|---|---|
| **输入** | 英雄配置表 `cfg/heroes.json` 的 12 条（名字、职业、难度、各属性）；存档里的「是否解锁」「局外等级」 |
| **输出** | 队伍名单（按点击顺序，**第一个是队长**）；卡片选中/取消；通知队友按钮刷新数字 |
| **依赖** | `B002-英雄详情` 负责下方面板；`B003-出战按钮` 负责人数显示；`cfg/team.json` 的 3 人上限 |
| **前置** | 必须有「本局关卡编号」（选关屏已经写好），否则进不了这一屏 |
| **和 `004-选人` 总纲的约定** | 卡片只管「选没选」，不管「打赢没打赢」 |
| **和 `005-战斗` 的约定** | 战斗按名单顺序放人，第一个当队长，其余跟随 |
| **和 `001-主菜单` 图鉴的约定** | 头像色块和英雄名首字的画法，跟图鉴里的卡片是同一套「没图用色块」的思路 |
| **和 `A002-UI层-SVG文档-选人` 的约定** | 卡片 150×150、头像 48×48、金边 2 像素，改了几何图要重画 |

## 十、太奶奶要定的三件事

| 问题 | 选项 |
|---|---|
| **卡片上那颗星代表什么？** | (A) 上手难度（1 星最好学）——现在的数据，但要说清楚　(B) 练到第几级（跟着「局外 LV」走）　(C) 干脆去掉星，只留「局外 LV1」 |
| **未解锁的英雄要不要显示名字？** | (A) 显示真名字 + 解锁条件（现在显示名字，缺条件）　(B) 显示「???」，保持神秘　(C) 显示名字，但卡片整体打一个灰叉 |
| **「第一个选的是队长」要不要写在界面上？** | (A) 要，卡片上加个「队长」小标　(B) 只在按钮旁边写一句「先选的是队长」　(C) 不写，玩家自己会摸出来 |
