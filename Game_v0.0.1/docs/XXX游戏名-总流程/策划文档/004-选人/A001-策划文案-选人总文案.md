## 一、这一屏是干什么的

**一句话**：从 12 个英雄里挑 1~3 个，组成这一趟下矿的队伍。

**三件事这一屏必须让玩家看懂**

| 要懂的事 | 靠什么让人懂 |
|---|---|
| 我有哪些英雄能用 | 卡片是亮的（彩色），能点 |
| 我这个英雄擅长什么、怕什么 | 点卡片，下方面板立刻出详情（生命、攻击、优点、缺点） |
| 三个人怎么搭 | 三个职业：输出、防御、辅助。挑的时候能同时看到自己已经选了谁 |

**设计底线**（太奶奶要求：玩家不识字也能玩）

| 底线 | 具体做法 |
|---|---|
| 选了谁一眼看见 | 选中的卡片**加一圈金边** |
| 现在几个人一眼看见 | 右下角按钮直接写「开始出战 (1/3)」 |
| 选错了能改 | 再点一次同一张卡 = 取消选择 |
| 不能白点一下 | 点下去要么变了、要么有提示，不许静默 |

**和整款游戏的关系**：全局已定——三人同场、队员跟随队长、满级 46 级、装备存背包不自动穿。这一屏只管「哪三个」，不管「他们带什么装备」（那是战斗里的事）。所以这一屏的决心越简单越好：**挑人，走**。

**为什么最多 3 人**：配置表里队伍上限就是 3（`cfg/team.json` 的 `maxSize`）。这一屏所有「3」都是从那儿读的，不是写死的。

## 五、这一屏能做和不能做的事

### ✅ 能做的

| 玩家动作 | 结果 |
|---|---|
| 点一张**已解锁**的英雄卡 | 金边亮起 + 下面详情面板换成这个英雄 + 按钮数字 +1 |
| 再点一次**同一个**已选英雄 | 取消选择，金边消失 + 详情面板**仍然显示这个英雄**（不是清空）+ 按钮数字 -1 |
| 点第三个人以外的第四个人（已满 3 人） | **现在：什么都没发生**（缺陷）；**应该：** 弹一句「最多 3 人，先点掉一个」 |
| 点一张**未解锁**的英雄卡 | **什么都没发生**，没有按钮、没有提示（缺陷） |
| 上下滑详情面板 | 内容比 190 高时能滚 |
| 点「返回」 | 回到选关屏（队伍清空） |
| 点「开始出战」 | 带着选好的 1~3 人进战斗 |

### ❌ 不能做的（必须挡住）

| 情况 | 处理 | 现在做到了吗 |
|---|---|---|
| 一个人都不选就出战 | 不许。没人时按钮是灰的、点不动（第 1005 行），函数里也再挡一次（第 1009~1011 行） | ✅ 挡住了 |
| 选 4 个人 | 不许。到 3 人就拒绝（第 861~863 行） | 🟡 挡住了，但玩家看不到拒绝原因 |
| 点未解锁英雄直接出战 | 不许。未解锁卡片连按钮都不加（第 841 行） | ✅ 挡住了，但也没提示 |
| 从选人直接跳主城/主菜单 | 不许。只能去选关或战斗（第 23 行） | ✅ 挡住了 |
| 不带关卡直接进战斗 | 不许。关卡是在选关屏记下的，这一屏不改它 | ✅ 结构上保证 |
| 同名英雄重复选两次 | 不许。已经在队伍里再点就是取消（第 853~854 行） | ✅ 挡住了 |

| 队伍上限从哪来 | `cfg/team.json` 的 `maxSize = 3` |
| 结晶数从哪来 | 存档里的结晶数，**只在进这一屏时读一次** |
| 我告诉了谁「选了哪三个」 | 全局状态里的「队伍名单」（按点击顺序）+ 「队长」＝名单第一个；同时广播「队伍已确认」 |
| 和 `005-战斗` 的约定 | 战斗会把**名单第一个当队长**，其余跟着队长走。所以「第一个点的人」就是队长，顺序有意义 |
| 缺什么数据 | 羁绊数据（配置表没有这个字段，永远显示「待配置」）；英雄解锁条件（配置表没写，所以灰卡说不出怎么解锁） |
