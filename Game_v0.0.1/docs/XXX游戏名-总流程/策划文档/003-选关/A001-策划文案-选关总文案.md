## 一、这一屏是干什么的

**一句话**：把 99 个关卡像一条楼梯一样摆在玩家面前，让他看见「我走到第几级了」，然后挑一级往下走。

**它卡在什么位置**：主城 →（进门 2 秒）→ **选关** →（点一关）→ 选人 →（点出战）→ 打。也就是说，玩家**一场游戏要打哪一关，是在这一屏决定的**。选错关，后面选人、打斗全白搭。

**三条设计底线**（太奶奶要求：玩家不识字也能玩）

| 底线 | 具体做法 |
|---|---|
| 一眼看出「我能打哪几关」 | 能打的关卡名字是**金色**、有**金边框**；不能打的是灰的。不看字也知道 |
| 一眼看出「有多少关没打」 | 往下滑就是没打的，一共 99 关，滑到底还有东西 |
| 不会卡死 | 不管点错、连点、来回切，都能退出去（至少「返回主城」这条退路必须永远看得见） |

**和整款游戏的关系**：全局已定——打死 Boss 算赢，死了丢光本局捡到的东西（局外等级保住）。所以这一屏对玩家的意义是「这一趟要爬多高」。关卡越往后，目标进度越高、时限越长、怪越硬。选关就是选难度，而选难度的前提是**玩家得看得懂这张卡片在说什么**。

## 五、这一屏能做和不能做的事

### ✅ 能做的

| 玩家动作 | 结果 |
|---|---|
| 点一张**已解锁**的关卡卡片 | 记住这关 → 立刻换到选人屏 |
| 点一张**未解锁**的关卡卡片 | **现在：完全没反应**（这是缺陷，见第七节）；**应该：** 弹一句「先打过第 X 关才能来」 |
| 上下滑滚动区 | 看到更多关卡，一共 99 关 |
| 拖右侧滚动条 | 快速跳到最后几关 |
| 点「返回主城」 | 退出选关，回到主城 |
| 在主城传送门里连点/重复进门 | **不会**重复弹选关屏（第 148~151 行有防重入守卫） |

### ❌ 不能做的（必须挡住）

| 情况 | 处理 | 现在做到了吗 |
|---|---|---|
| 未解锁的关卡被点进去 | 不许。只有 `index < max(1, 已解锁数)` 的关卡可以进（第 160~161 行） | ✅ 进不去，但几乎没提示 |
| 从选关直接跳到战斗 | 不许。必须经过选人（第 22 行白名单） | ✅ 挡住了 |
| 从选关直接跳去主菜单/设置/图鉴 | 不许。选关只能去「选人」或「主城」（第 22 行） | ✅ 挡住了 |
| 选关时带着上一次选好的队伍 | 不许。每次进选关都**清空已选队伍**（第 153 行） | ✅ 已清空 |
| 画面卡顿到点不动 | 不许。但 99 张卡 + 99 个按钮一次全建出来，低配机器有风险 | ❌ 有风险，见 T3 |
