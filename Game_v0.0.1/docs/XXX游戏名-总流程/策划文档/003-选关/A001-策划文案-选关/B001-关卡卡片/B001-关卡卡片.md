## 一、这个功能是干什么的

**一句话**：一张小卡片 = 一个关卡。上面写着「这关叫什么、要打多少怪、限多久」，点它就去打这一关。

**对太奶奶的玩家来说，这张卡片是这一屏唯一要动脑子的地方。** 玩家进门后眼睛会一张一张扫过去，扫到一个金边的（能打），点它，走人。整个过程不超过 3 秒。所以卡片只要做错一点，玩家就卡在这里不动了。

**和整款游戏的关系**：打死 Boss 算赢，死了丢光本局东西。卡片上写的「目标进度」就是这个要求——打够这个数才算过关。如果卡片把这个数写错或者看不清，玩家会以为自己过关了却没过，或者反过来被吓退。

**这一关有 99 张卡片，每张都长这样。** 其中第 1 关叫「荒地哨站」，第 2 关「腐朽林地」，第 3 关「深渊回廊」，最后一关第 99 关叫「神罚之眼 9」。

## 二、界面长什么样

### 2.1 卡片整体

| 项目 | 规格 | 出处 |
|---|---|---|
| 尺寸 | **200 宽 × 96 高**（最小尺寸，内容多了可以被撑高） | 第 662 行 |
| 底色 | 中灰蓝 `#252a34` | 第 634 行 |
| 圆角 | 8 | 第 635 行 |
| 内边距 | 左右各 10、上下各 8 | 第 636~639 行 |
| 边框（已解锁） | 2 像素金色 `#e8b33c` | 第 640~642 行 |
| 边框（未解锁） | **没有边框**（跟底色混在一起） | 第 640 行，只有解锁时才加边 |
| 鼠标停在上面 | 显示一个灰黑小气泡，内容是关卡全名 | 第 663 行 |

### 2.2 卡片里面的三行字（从上往下）

| 第几行 | 内容 | 字号 | 颜色 | 出处 |
|---|---|---|---|---|
| 第一行 | 关卡名，例如「第 1 关 · 荒地哨站」 | 20 号 | 已解锁金色 `#e8b33c`；未解锁暗灰 `#5a6572` | 第 647~650 行 |
| 第二行 | 「目标进度 60 · 时限 180s」 | 15 号 | 灰蓝 `#8a93a5`（解锁与否都一样） | 第 652~656 行 |
| 第三行 | 「✦奖励 0」 | 14 号 | 已解锁金色；未解锁暗灰 | 第 657~661 行 |

> **口诀**：名字大（20）、进度中（15）、奖励小（14）。玩家扫一眼先看见名字，再看数字，最后才看奖励。

### 2.3 关名前缀的特殊规则（这是修过的老 bug，别改回去）

代码里有个判断：**如果配置表里的关名不是以「第」字开头，才自动补「第 X 关 · 」前缀**（第 626~629 行）。

| 配置表里的名字 | 屏幕上显示 | 为什么 |
|---|---|---|
| 「第 1 关 · 荒地哨站」 | 第 1 关 · 荒地哨站 | 名字已带「第」，**不再叠一遍** |
| 「荒地哨站」（假设） | 第 1 关 · 荒地哨站 | 名字不带「第」，自动补 |

> 以前没这个判断的时候，屏幕上会出现「第 1 关 · 第 1 关 · 荒地哨站」这种重复。现在 99 关的名字**全都已经带「第」**了，所以前缀判断实际上不会触发，但这个保护要留着。

### 2.4 一张卡片的示意图

```
已解锁（能打）                        未解锁（锁着）
┌──────────────────────┐             ┌──────────────────────┐
│ 第 1 关 · 荒地哨站    │ ← 20 号金   │ 第 47 关 · 名字灰灰的 │ ← 20 号暗灰
│ 目标进度 60 · 时限 180s│ ← 15 号灰  │ 目标进度 900 · 时限 600s│
│ ✦奖励 0              │ ← 14 号金   │ ✦奖励 0              │ ← 暗灰
└──────────────────────┘             └──────────────────────┘
   ↑ 外面一圈 2px 金边                   ↑ 没有边框，整张糊成一团
```

> **太奶奶注意**：右边那张「未解锁」的卡片，跟左边只差两件事：字变灰、没金边。**这点差别在低亮度屏幕上几乎看不出来**，而且它点了完全没反应。所以现在玩家分不清「锁住」和「坏了」。这是这一屏最要紧的毛病（见第九节）。

## 三、点击后发生什么（以点「第 1 关」为例）

| 步骤 | 发生什么 | 玩家看到什么 | 耗时 |
|---|---|---|---|
| ① | 玩家的手指/鼠标按下卡片上那层透明按钮 | 卡片没有「凹陷」效果（透明按钮没有按下样式） | 0 |
| ② | 抬起手指，按钮算「点成功」 | 没变化 | 0 |
| ③ | 系统记下「这局打第 1 关」，同时把这关编号写进全局状态 | 没变化 | 眨眼都不到（1/60 秒） |
| ④ | 广播一条「关卡已选」的通知 | 没变化 | 同上 |
| ⑤ | 开始重建英雄网格（12 张英雄卡全新建一遍） | 画面顿一下（肉眼基本看不出） | 很短，可忽略 |
| ⑥ | 整个画面切到选人屏 | 看到「角色选择」标题 | 立刻，**没有任何转场动画** |

> **整个过程没有任何「确认」步骤**。点了就进，没有二次确认框。

**点「未解锁」的卡片会怎样**：什么都不发生。**一行字都不弹、一点声音都没有。** 因为代码在「没解锁」时直接返回，连按钮都没加（第 664~665 行），所以你这一下点击根本没被任何东西接到。这是缺陷，见第九节和第十节。

**为什么不做「二次确认」**：因为退回很容易——选人屏左下角就有「返回」按钮，一步就回选关。所以不值得为它加一个确认框挡住玩家。

## 四、各种状态

### 4.1 已解锁卡片（能打）

| 状态 | 样子 |
|---|---|
| 常态 | 中灰蓝底 + 2 像素金边 + 金色关名 + 金色奖励数字 |
| 鼠标停在上面 | 弹出灰黑小气泡，写着关卡全名（和卡片上第一行一样） |
| 按下/点击 | **没有任何视觉变化**（透明按钮，没有按下效果、没有缩放） |
| 禁用 | 不存在这个状态。能打就是能打 |

### 4.2 未解锁卡片（锁着）

| 状态 | 样子 |
|---|---|
| 常态 | 中灰蓝底、无边框、关名暗灰、奖励暗灰 |
| 鼠标停在上面 | 弹出小气泡，写着关卡全名（跟已解锁一样，**说明它自己被当成「可看但不可点」**） |
| 按下/点击 | **什么都没发生**，连气泡都不会消失得快一点 |
| 「锁」的提示 | **没有**，一个锁头图标都没有 |

> 也就是说，未解锁卡片四态里其实只有一种态，剩下三态都是「没反应」。这不符合「一个功能要有四态」的基本要求。

## 五、声音/反馈

| 时机 | 现在有吗 | 应该有吗 |
|---|---|---|
| 点已解锁卡片 | ❌ 没有声音 | ✅ 应该有一声轻快的「咔」，让人知道点中了 |
| 点未解锁卡片 | ❌ 没有声音、没有画面提示 | ✅ 应该有一声闷的「咚」+ 卡片轻轻抖一下 + 弹一句「先打过第 X 关」 |
| 鼠标滑过卡片 | ❌ 只有系统气泡 | 🟡 可以加一点点变亮（可选） |

> 目前这一屏**完全没有音效**。声音部分留给后续统一做，但「点未解锁要有反应」这件事不能只靠声音，因为玩家可能静音——**必须有看得见的提示**。

## 六、异常情况

| 情况 | 会怎么 | 玩家看到什么 | 该怎么办 |
|---|---|---|---|
| 关卡配置表缺失或格式不对 | 代码打一句警告，直接不建卡片 | 一个关卡都不显示，空白一片 | 屏幕上应有一行「关卡数据读取失败」，别让玩家对着空白猜 |
| 关卡条目不完整（比如少了名字） | 关名显示成「第 X 关 · 」（后面空） | 一个怪名字 | 名字为空时显示「未命名关卡」 |
| 关卡没有目标进度 / 时限 | 该数字显示 0 | 「目标进度 0 · 时限 0s」 | 应显示「待配置」 |
| 关卡没有奖励字段 | 显示「✦奖励 0」 | 每关都写 0 | 见第十节第 1 题 |
| 已解锁数超过 99 | 全部解锁（`index < 已解锁数` 永远成立） | 99 张卡全是金边 | 无问题 |
| 已解锁数是 0 或负数 | 代码会把它当 1 处理（`max(1, 已解锁数)`，第 160~161 行） | 第 1 关永远能打 | 这是故意的：至少保证玩家能玩第一关 |
| 快速连点同一张卡两次 | 第一次已切屏，第二次点击落在新屏上，没反应 | 没反应，但也没出问题 | 无问题 |

## 七、不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| 未解锁的卡片点了**完全没反应** | 玩家分不清「锁住」还是「游戏坏了」。这是现在的真实毛病 |
| 未解锁卡片和已解锁卡片**只差字色和一圈边** | 低亮度屏幕上看不出差别，等于没标 |
| 关名重复显示「第 1 关 · 第 1 关 · 荒地哨站」 | 老 bug，代码已防（第 626~629 行），以后改配置表别破坏这个判断 |
| 卡片显示「✦奖励 0」却假装是真奖励 | 玩家会以为打关不给东西，直接不打了。要么补数据，要么删掉这行 |
| 卡片上写「星级」但没画星级 | 副标题承诺了星级，卡片上没有，玩家会觉得少东西 |
| 一次把 99 张卡全建出来（包括 99 个透明按钮） | 关卡只会越来越多，低配机器和手机会卡 |
| 点卡片弹二次确认框 | 退回只要一步（选人屏的「返回」），多余确认只会烦人 |
| 在选关卡片上做「花里胡哨的动画」 | 这一屏要的是快，玩家要快速选关出征，不是看动画 |

## 八、和其他文档的约定

| 项目 | 内容 |
|---|---|
| **输入** | 关卡配置表 `cfg/levels.json` 的每一条（关名、目标进度、时限）；存档里的「已解锁关卡数」 |
| **输出** | 点击成功后：写下「本局关卡编号」→ 广播「关卡已选」→ 切到选人屏 |
| **依赖** | `B002-进度与解锁` 决定这张卡片是金边还是灰的；选人屏依赖这里写下的关卡编号 |
| **不依赖** | 队伍、英雄、结晶，这一屏一概不管 |
| **和 `004-选人` 的约定** | 「本局关卡编号」必须在这一屏就写好，选人屏不重新选关 |
| **和 `002-主城` 的约定** | 主城只管把我叫出来，不传任何关卡信息 |
| **和 `005-战斗` 的约定** | 战斗读的是这里写下的关卡编号去加载地图和 Boss，卡片上写错数不影响战斗（战斗自己读配置表） |

| 奖励数字 | ❌ 假的 | 配置表没有奖励字段，永远显示「✦奖励 0」（第 630~631 行注释已承认） |

**要补的**：① 未解锁卡片加灰锁头 + 点一下弹「先打过第 X 关」；② 奖励行要么补数据要么删；③ 卡片补星级（已过关显示几颗星）；④ 点击给一点按下反馈（卡片轻轻缩一下）；⑤ 99 张卡改成分批建或只建可见范围。

## 十、太奶奶要定的三件事

| 问题 | 选项 |
|---|---|
| **未解锁的卡片，点下去应该怎么回应？** | (A) 弹一句「先打过第 X 关才能来」（推荐）　(B) 只让卡片抖一下，不弹字　(C) 什么都不做，只把卡片画成灰锁样子 |
| **卡片上那条「✦奖励」怎么处理？** | (A) 直接删掉，只留名字和进度时限　(B) 补每关奖励数据，显示真实数字　(C) 改成「首通奖励」，只在没打过的关上显示 |
| **能打的关卡要不要标「我打过没、几颗星」？** | (A) 要，卡片右上角画星星　(B) 要，但只标「已通关」三个字　(C) 不要，选关屏只管选 |
