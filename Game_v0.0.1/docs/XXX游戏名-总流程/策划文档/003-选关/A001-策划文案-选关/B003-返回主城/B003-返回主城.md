## 一、这个功能是干什么的

**一句话**：不打了，回去。这是**选关屏唯一一条退路**。

**为什么它必须排在 B003（而不是随手塞进总纲）**：因为它是「保命按钮」。玩家进错屏、看错关、临时改主意、或者根本不想打，全靠这一个按钮往回走。这一屏里如果它出问题，玩家就被关在选关屏里出不去——那只能强退游戏。

**对玩家的意义**：它不是「功能」，是**安全感**。玩家知道右下角永远有个「返回主城」，才敢随便点随便看。

**和整款游戏的关系**：点它 = 放弃这次出征。放弃不扣任何东西（不扣结晶、不掉级、不解锁），因为玩家根本还没出门。真正扣东西是「出战之后死了」才算。所以这个按钮没有任何代价，**必须让人敢点**。

## 二、界面长什么样

| 项目 | 规格 | 出处 |
|---|---|---|
| 文字 | 「返回主城」 | 第 589 行 |
| 尺寸 | **180 宽 × 48 高** | 第 590 行 |
| 位置 | 面板**最底一行、靠右**（左边放一段空白把按钮顶到右边） | 第 585~593 行 |
| 底色 | 中灰蓝 `#252a34` | 第 259 行（普通按钮样式） |
| 圆角 | 8 | 第 260 行 |
| 边框 | **没有边框**（这是「次要按钮」，只有金按钮才有框） | 第 261~263 行 |
| 文字颜色 | 骨白 `#e2e6ee` | 第 257 行（非金色按钮） |
| 字号 | 20 号 | 第 256 行 |
| 默认大小 | 通用按钮默认 320×52，这里被改成 180×48 | 第 255 行 + 第 590 行 |

```
面板最底一行（宽度 680，内边距左右 24）
┌──────────────────────────────────────────────────────────┐
│                                          ┌────────────┐  │
│                                          │ 返回主城    │  │ ← 180×48，右对齐
│                                          └────────────┘  │
└──────────────────────────────────────────────────────────┘
  ↑ 左边这一大片是空白占位，专门用来把按钮顶到右边
```

> **为什么靠右不靠左**：「下一关」类的动作通常在右边，但这里右边是退路……其实这一屏只有这一个按钮，靠右是为了把左边留空，让玩家的眼睛先扫卡片、最后才看到退路。**不要因为「退路应该显眼」就把它换成金色大按钮**——金色在这一屏是「能打的关卡」的专用色，按钮也用金色会跟卡片抢注意力。

> **⚠ 太奶奶注意**：这个按钮在**面板最底下**，而面板现在是 760 高、屏幕只有 720 高（第 596 行）。所以这个按钮很可能**大半截在屏幕外**。这是本屏最要紧的缺陷，见第七节和第九节。

## 三、点击后发生什么

| 步骤 | 发生什么 | 玩家看到什么 | 耗时 |
|---|---|---|---|
| ① | 玩家点下「返回主城」 | 按钮没有明显的按下凹陷（通用按钮样式比较素） | 0 |
| ② | 调用「去主城」 | 没变化 | 0 |
| ③ | 整个界面立刻隐藏 | 画面开始变 | 立刻 |
| ④ | 切到主城场景 | 主城画面加载出来 | 加载时间取决于主城场景，正常一两秒内 |
| ⑤ | 屏幕状态被记成「主菜单」（这是给下一步回来用的） | 玩家在主城里 | — |

**回到主城后，会不会马上又被弹回选关？**

| 情况 | 会不会弹回 |
|---|---|
| 玩家退出传送门圈，站远处 | 不会，只有「进圈站满 2 秒」才触发 |
| 玩家按钮点下去那一瞬间**还站在圈里** | 传送门有「同一个圈只触发一次」的规则（`002-主城` B001 有写），且选关屏自己也有防重入（第 150~151 行） |

> 也就是说，正常操作不会被立刻弹回来。但**如果玩家回主城后立刻又走进传送门**，2 秒后会正常再弹一次选关——这是预期行为，不是毛病。

## 四、各种状态

| 状态 | 样子 | 说明 |
|---|---|---|
| 常态 | 灰蓝底 + 白字「返回主城」 | 一直可点 |
| 鼠标停在上面 | 系统默认有一点点变亮（没有专门做样式） | 能看出可以点 |
| 按下 | 系统默认的按下效果，很轻 | 反馈偏弱 |
| 禁用 | **不存在这个状态** | 退路在任何时候都必须是通的 |
| 被挤出屏幕 | 玩家**看不见**按钮 | 现在的真实风险，见第七节 |

> **「禁用」这一态在这里必须是空的**：不管玩家有没有选关、有没有解锁、配置表有没有读错，返回键永远可用。宁可让玩家退出，也不能把他关在里面。

## 六、异常情况

| 情况 | 会怎么 | 玩家看到什么 | 应该怎么处理 |
|---|---|---|---|
| **按钮被挤出屏幕（现在的真问题）** | 玩家点不到 | 屏幕右下角什么都没有，或只露一条边 | 面板高度改成不超过屏幕高（待办 T1） |
| 主城场景加载失败 | 界面已隐藏、场景没出来，玩家对着一片空 | 黑屏/空屏 | 加载失败要能回到主菜单，并显示「主城加载失败」 |
| 点一次没反应，玩家连点 | 第一次已切场景，后续点击落在别处 | 可能误点到主城的别的东西 | 点下后按钮应立刻变灰，防止二连 |
| 配置表读错导致选关屏空白 | 按钮如果还在，仍然能退出 | 空白 + 一个返回按钮 | 这时候返回按钮**必须保留可见**，它是唯一的活路 |
| 按键 Esc | **没有绑定** | 按 Esc 没反应 | 建议和按钮等效（见第十节） |

## 七、不许干的事

| ❌ 不许 | 为什么 |
|---|---|
| 返回按钮被挤出屏幕却不管 | 玩家被关在选关屏里出不去，等于游戏坏了 |
| 在某些情况下禁用返回按钮 | 退路永远要通。没有例外 |
| 把它做成金色大按钮 | 金色在这一屏代表「能打的关卡」，混用会让玩家分不清该点哪个 |
| 把它放到左上角、跟标题挤在一起 | 会和标题抢注意力，而且这一屏没有「返回箭头」的视觉习惯 |
| 点了弹「确定要放弃出征吗？」 | 玩家根本还没出征，没东西可放弃。多一句确认纯属添堵 |
| 返回时清空玩家的进度或结晶 | 什么都没打，扣东西会让玩家骂人 |
| 返回后再自动弹回选关 | 玩家刚明确表示「我要回去」，再弹回去就是打脸 |
| 按下没有任何反馈 | 玩家会连点好几次，容易误触主城别的东西 |

## 八、和其他文档的约定

| 项目 | 内容 |
|---|---|
| **输入** | 一次点击，不带任何参数 |
| **输出** | 隐藏本屏 + 切到主城场景 + 屏幕状态记为「主菜单」 |
| **依赖** | 主城场景文件必须存在 |
| **前置** | 无。任何时刻都能点 |
| **和 `002-主城` 的约定** | 主城负责在玩家走进传送门后再把我叫回来；我不负责通知主城「我来了」 |
| **和 `004-选人` 的约定** | 选人屏有它自己的「返回」（回到选关，不是回主城），两回事，别混 |
| **和 `005-战斗` 的约定** | 无关系。这里从来没进过战斗 |
| **白名单依据** | 选关屏允许去的地方里就有主城（第 22 行），所以这条退路是流程允许的正路，不是后门 |

## 十、太奶奶要定的三件事

| 问题 | 选项 |
|---|---|
| **返回按钮放哪儿？** | (A) 现在这样，面板右下角　(B) 屏幕左上角做一个「← 返回主城」　(C) 底部正中一个宽按钮 |
| **按键盘 Esc 要不要也能回主城？** | (A) 要，和点按钮一样　(B) 不要，只能点按钮（避免玩家误按退出）　(C) 要，但先弹一句「按 Esc 回主城？」 |
| **回主城后，要不要记住玩家停在选关的哪个位置？** | (A) 记住，下次进来还在那　(B) 不记，每次都跳到当前能打的关　(C) 不记，每次都从第 1 关开始 |
