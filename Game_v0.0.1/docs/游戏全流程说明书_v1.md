# 游戏全流程说明书 v1（给太奶奶看的版本）

> 这份文档只用大白话。不讲代码，不讲术语。
> 目的：让你一眼看懂「玩家从打开游戏到关掉游戏，中间每一步都在干什么」，以及「哪里还缺东西」。
> 对应版本：v0.6 · 主城 → 串行关卡 → 边界
> 最后更新：2026-10-26

---

## 一、一句话说清这游戏是什么

**你带三个人下地牢，打怪捡东西，能全身而退就把东西带回家；死了就丢一半。**

「下地牢」= 一局战斗，大约 3 分钟。
「带回家」= 撤离成功，东西变成永久资产（结晶、金币、经验）。
「死了」= 东西大部分丢掉，但角色等级还在。

一句话：**贪心就会有代价，这是这游戏的核心乐趣。**

## 二、完整流程图（玩家看到的顺序）

```
① 打开游戏
     ↓
② 主菜单 ──→ 帮助 / 设置 / 图鉴 / 退出
     ↓ 点「开始游戏」
③ 主城（大本营）  ←──────────────┐
     ↓ 走到「出征传送门」站着不动读条   │
④ 选关（99 个关卡，从第 1 关往后解锁）  │
     ↓ 点一张关卡卡                    │
⑤ 选人（12 个英雄，最多选 3 个）        │
     ↓ 点「开始出战」                  │
⑥ 战斗（打怪 3 分钟 → 打 Boss → 撤离点出现）│
     ↓ 两个出口                         │
     ├─ 站到撤离点读条 → 撤离成功 ───────┤
     └─ 血被打光 → 阵亡 ────────────────┤
⑦ 结算（看战绩 + 拿收益）               │
     ↓                                  │
     └──────────────────────────────────┘
     ↓ 也可以选「回主菜单」
⑧ 主菜单（新一轮）
```

## 三、每一步详细说明

### ① 打开游戏

- **玩家看到**：游戏窗口打开，第一个画面是主菜单。
- **游戏在后台做什么**：读取你的存档（上次的结晶、解锁了哪些英雄、哪些关卡通过、赛季等级），加载所有配置表（关卡、怪物、装备、技能等 95 张表）。
- **要点**：存档读不到时不能崩，要有默认值。这条现在已做。

---

### ② 主菜单

**玩家看到的东西（从上到下）：**

| 位置 | 内容 | 现在状态 |
|---|---|---|
| 大标题 | 游戏名 | ✅ 有 |
| 副标题 | 「组队下矿 · 撤离拿结晶 · 局外养成」 | ✅ 有 |
| 主按钮 | 开始游戏 → 进主城 | ✅ 有 |
| 其他按钮 | 帮助 / 设置 / 图鉴 / 退出 | ✅ 有 |
| 底部档案行 | 「无名旅者 · 初出茅庐 · ✦结晶数」 | ✅ 有（结晶是真的，称号是假的） |
| 最底版本行 | 「v0.6 · 主城 → 串行关卡 → 边界」 | ✅ 有 |

**这一屏要补的：**
1. 称号「初出茅庐」现在是**写死的假数据**，真正应该由玩家进度决定（比如通关数、累计击杀）。→ 需要一张「称号表」。
2. 档案行没有头像。→ 需要头像图。
3. 没有「继续上次」的快捷入口。→ 可加，玩家省一步。

---

### ③ 主城（大本营）

**玩家在这里能做什么：**

| 位置 | 叫什么 | 干什么 | 现在状态 |
|---|---|---|---|
| 中央 | 出征传送门 | 站进去读条 → 进选关 | ✅ 能进 |
| 左上 | 强化导师 | 提升英雄局外等级 | 🟡 界面有，功能待接 |
| 左中 | 武器匠 | 武器 / 技能重铸 | 🟡 界面有，功能待接 |
| 右下 | 形象师 | 改名字、换头像、换称号 | 🟡 界面有，改名已能存 |
| 右下 | 图鉴学者 | 看收集进度 | 🟡 界面有，内容待填 |
| 右上 | 神秘商人 | 买秘密商品 | 🟡 界面有，商品表待填 |
| 右上 | 赛季使者 | 看赛季进度 | 🟡 界面有 |
| 下方 | 深渊之门 | 进无尽模式（一直打到底） | ✅ 能触发 |

**左上角档案卡**：显示名字 + 称号 + 结晶数。✅ 已做

**这一屏要补的：**
1. **六个 NPC 里只有传送门是真能用的**，其他五个点开是空壳。这是目前**最大的缺口**。
2. 主城没有「存档已保存」的提示。玩家不知道进度保住了，会不安。→ 建议每次回城左上角闪一下「已保存」。
3. 没有「今天该干什么」的引导。太奶奶级别的玩家会呆站着不知道去哪。→ 建议：第一次进主城时，传送门上画一个跳动箭头。

---

### ④ 选关

**玩家看到**：99 个关卡排成三列。前面的亮着能点，后面的灰着带锁。

**当前关卡数据示例**（来自 `cfg/levels.json`）：

| 关卡 | 名字 | 要打多少怪 | 最长多久 |
|---|---|---|---|
| 第 1 关 | 荒地哨站 | 60 只 | 180 秒 |
| 第 2 关 | 腐朽林地 | 72 只 | 200 秒 |
| 第 3 关 | 深渊回廊 | 85 只 | 220 秒 |

**规则**：必须按顺序打，第 1 关过了才解锁第 2 关。

**这一屏要补的：**
1. **卡片上的「✦奖励 0」**——关卡表里还没有奖励字段，所以全是 0。→ 必须补：每关给多少结晶、多少金币。
2. **没有星级显示**。代码里是有「星级」概念的，但卡片上没画出来。→ 打完一关给几颗星，是让人有动力重打的关键。
3. **没有「推荐等级」**。玩家不知道自己该不该打这关，进去被秒杀会很难受。→ 建议每关标一个推荐战力。
4. 99 关全在一个列表里太长。→ 建议按章节分页（每章 10 关），不然滑到吐。

---

### ⑤ 选人

**玩家看到**：12 张英雄卡（6 列两行），点一张，下面就显示这张卡的详细资料。

**卡片上有**：职业色头像 + 名字 + ★星级 + 局外等级。✅ 已做
**详情面板有**：名字 / 职业 / HP / 攻击 / 移速等属性 + 绿底优点 + 红底缺点 + 羁绊 + 进化结晶。✅ 已做

**底部按钮**：「返回」（回选关）+「开始出战 (n/3)」（组队满了才能点）。✅ 已做

**这一屏要补的：**
1. **一次最多选 3 个，但没说清楚「为什么是这 3 个」**。→ 需要提示：比如「需要 1 个坦克 + 2 个输出」。
2. **没有「上次用的队伍」记忆**。每局都要重选，很烦。→ 建议自动记住上次阵容。
3. **英雄属性怎么算的，玩家看不懂**。→ 需要一个「这个英雄适合打什么」的一句话标签。
4. 没有水晶/装备预览。→ 选人时看不到自己攒的家底，容易选错。

### ⑥ 战斗（核心）

**玩家看到的界面**：

| 位置 | 显示什么 |
|---|---|
| 顶部中间 | 金色进度条 +「击败精英 X / 60 (剩余 Zs)」 |
| 左上 | HP / 等级 / 经验 |
| 左上（开场 3 秒） | 绿色 READY 徽章，表示「现在冻结，先熟悉一下」 |
| 右上 | Lv 大字 + ✦金币 + ✦经验 + 宝箱数 + 波次 |
| 左下 | 负重 X / 100 |
| 底部中间 | 英雄技能栏（头像 + 4 个技能槽 + 等级） |
| 右下 | 「自动战斗」按钮 + 「背包(Tab)」按钮 + 操作提示 |

**玩家怎么操作**：WASD 走，鼠标瞄准，左键或 J 射击。

**一局的完整节奏（这是最关键的，必须丝滑）：**

```
开场冻结 3 秒（让玩家看清地形和怪）
   ↓
第 1 波怪刷出来 → 打
   ↓
打死 60 只（或时间到 180 秒）
   ↓
Boss 出场（血条出现在它头顶）
   ↓
打死 Boss → 地图中央亮起金色撤离圈
   ↓
玩家跑进撤离圈，站着不动读条（约 3~5 秒，负重越高读条越慢）
   ↓
读条满 → 撤离成功 → 进入结算
```

**三个中途可用的东西：**

| 按键 | 干什么 | 什么情况下用 |
|---|---|---|
| Tab | 开背包，穿装备 | 捡到好装备想马上变强 |
| C | 开水晶面板，装水晶 | 攒了水晶想强化技能 |
| R | 开裂隙任务 | 想要额外奖励的挑战 |
| F | 开无尽模式 | 想一直打下去拼排名 |

**这一屏要补的（重要）：**
1. **玩家不知道撤离点在哪**。现在只有地图上亮个圈，没有箭头指路。→ 必须加：屏幕边缘一个箭头，或者一条光柱。
2. **Boss 出场没有演出**。突然就出现了，没有「大怪来了」的紧张感。→ 建议加：屏幕震动 + 红色警报 + 名字弹出。
3. **负重高会拖慢撤离读条，但玩家不知道**。→ 需要在负重条上写明白「负重越高，跑得越慢，撤离越难」。
4. **死了没有任何提示就直接结算**。→ 建议加一个「你倒下了」的 1 秒慢动作。
5. **没有暂停菜单**。Esc 只是暂停，不能退出、不能看帮助。→ 需要个正常暂停菜单。

### ⑦ 结算

**玩家看到**：一页纸，写着这局打成什么样。

| 区域 | 内容 | 现在状态 |
|---|---|---|
| 大标题 | 「撤离成功」或「你倒下了」 | ✅ 有 |
| 战绩 | 击杀数 / 波次 / 金币 / 经验 / 暴击 | ✅ 有 |
| 收益 | 这局赚到多少结晶 | ✅ 有 |
| 战利品 | 捡到了什么 | ✅ 有（内容还比较空） |
| 按钮 | 「返回主城」/「回主菜单」 | ✅ 有 |

**这一屏要补的：**
1. **没有「新纪录」高亮**。破了自己的击杀记录应该闪一下金字，这是最便宜的正反馈。
2. **没有经验条动画**。经验加了多少，应该有个条从旧值涨到新值，看着爽。
3. **撤退和阵亡的收益差多少，没写清楚**。→ 建议直接对比：「撤离：+120 结晶 / 阵亡：+40 结晶（损失 80）」。
4. **战利品区域看不出拿了什么好东西**。→ 需要金色描边标出稀有物品。

---

### ⑧ 回到主菜单 / 退出

- 结算页选「回主菜单」→ 回主菜单，可以再开一局。
- 主菜单选「退出」→ 弹确认页 → 真的关掉。
- ✅ 这条链路现在通了。

**要补的**：退出前如果还有未保存的进度，要提示。

| 编号 | 缺什么 | 为什么必须有 | 大概要做什么 |

## 五、给太奶奶的「先做哪个」建议

不要一次全做，会乱。按这个顺序，每做完一批你都能亲手试：

### 第一批：让游戏「能完整玩一局」（约 1 天）
- A1 暂停菜单
- A2 新手引导
- A3 撤离点指引
- A4 存档提示
- A5 战败原因说明

> 做完这批，一个完全没玩过的人能自己从主菜单玩到结算再回主城，不会卡住。

### 第二批：让游戏「值得多玩几局」（约 1~2 天）
- B2 关卡奖励数值（把「奖励 0」变成真数）
- B1 星级评分
- B6 撤离/阵亡收益对比
- B7 破纪录高亮
- B4 队伍记忆

> 做完这批，玩家会有「再来一局」的动力。

### 第三批：让游戏「像个完整游戏」（约 3~5 天）
- B3 主城五个 NPC 的真实功能
- B5 推荐战力
- B8 章节分页
- C1 Boss 演出
- C2 阵亡慢动作
- C3 经验条动画

> 做完这批，游戏就有模有样了。

### 第四批：美术与手感（长期）
- 换成 2.5D 的 3D 场景 + 2D 人物（你上次问的那个）
- C5 背景音乐
- UI 换皮（主题表 + 中文字体 + SVG 设计稿落地）
