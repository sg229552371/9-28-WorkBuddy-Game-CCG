# 积木覆盖率压测模板（v0.4，2026-10-18 第四轮）

> **性质**：空模板 + 2 行示范。**不改主书稿**。
> **用途**：拿到 **12 角色技能清单**后逐行填写，检验「**当前积木注册表** + 两事件 + 三载体 + 三权限」能否拼出每个技能；拼不出的行即新积木候选来源。
> **口径变更（2026-10-18 第四轮，用户指正）**：**积木数量不固定**。四类是参考实现，不是上限——压测中若需 5、6 块甚至更多，属预期，不属失败。**暴露部位**（单个技能开放给玩家的自定义点）默认 4 个，同样可变。
> **填写前提**：先逐技能写一份 24.4 设计卡草稿，再把结论回填本表；本表只做覆盖率统计，不替代设计卡。

## 6　填写规则（给填表者）

1. 一个技能一行；一个技能含多形态时**写在同一行内分句列出**，不拆多行。
2. 积木拼法按注册表逐项写；确实不用的写“不涉及”，不留空。
3. **不得为了凑四类而硬塞**：现有积木表达不了就填“需新积木”，写明为何拼不出——新增积木是正常演进，不是失败。
4. 暴露部位数按技能实际填写，**不要求等于 4**；与积木数量无关。
5. 凡写“需新规则/需新积木”，必须引用主书稿章节或决策号，说明哪条规则不够用。
6. 不得为了拼出而新增第三个事件、绕过已确认规则（D-01…D-09、D-90…D-92、D-104/D-105）。
