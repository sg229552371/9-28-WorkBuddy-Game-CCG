## 六、评审裁决 C04-01（本次最重要的一处把关）

### 冲突

需求文档 2.4/2.5 写四类载体为 `independent / instant / attached / none`；主书稿第 8 章与附录 B 写 `none / self / independent / attached`。**差异是 `instant` ↔ `self`，二者不是同义词。**

### 证据

主书稿附录 B（3893 行）以机器可读 YAML 写死：

```yaml
carriers: [none, self, independent, attached]  # 〔2026-10-18 终审修正〕
```

且主书稿 8.2 定义 `none` = 寿命 0 的瞬时实例——"瞬时"语义**已由 `none` 承担**，不需要第二个 `instant`；而 `self`（位移状态 + 跟随判定体）在需求文档的四值中**无处安放**，冲刺/跳跃类积木将没有合法载体。

### 裁决

**以主书稿为准：`none` / `self` / `independent` / `attached`。需求文档该处为摘要转述笔误。**

- `instant` 降级为**描述词**（可描述"瞬时实例"），**不得作为 `carrier` 字段取值**
- 已定正：冻结约定枚举、第 4 章位移候选卡（`carrier` 归 `self`）、第 6 章载体名称表述、第 9 章 `trail.carrier` 取值范围
- 裁决记录见 `_shared/11_评审裁决_C04-01.md`

### 值得记录的一点

这个冲突是**执笔方（Claude CLI）在第 4 章主动发现并挂起**的——它没有自行猜测或静默统一，而是登记为阻塞项、把位移卡标为候选并禁止导出，写明"评审必须先统一枚举才能解除"。这正是双 AI 相互监督设计想要的效果。同时另有 3 个包（第 1/5/13 章）也各自独立发现了同一冲突。

### R6 核心取舍（写清理由，不是凑格式）

**回放 = 重新演算，不是录像。** 只存「版本三元组 + 逻辑种子 + 固定时间轴 + 固化开局条件 + 有序输入」，不存渲染帧／中间状态／每 tick 全量快照。

- **版本三元组**（`schema_version` / `rules_version` / `config_digest`）三者都要：Schema 变则字段语义变、规则版本变则同配置结果变、配置摘要变则内容变。
- **表现 RNG 不进回放**（对齐 D-09 的逻辑／表现分离）。
- **校验和只覆盖逻辑状态**，且按稳定标识排序后再哈希——否则同状态不同遍历顺序会算出不同校验和。
- 版本不匹配**禁止静默重放**，须显式报告"规则已变更，结果不可比"，不得把回放失败当 bug。
