# 第24章　技能设计卡模板

> **一句话结论**：一页设计卡写完一个技能，八栏齐全，每栏都有"最小可用默认值"，新手只改关键字段就能跑；新技能先过"积木优先判断流程"，拼不出才允许新增积木，且须登记决策编号。

## 24.1 首要原则与积木优先判断流程

首要原则：**高模块化、高自定义、能拼出所有技能、简单易上手**。四件事互相支撑：积木少而通用 → 才能拼出所有技能；每块积木都有默认值 → 才好上手；字段暴露给修饰器 → 才能高自定义。

**积木注册表（当前 4 类，可扩展）**：施法者闭环、效果体、修饰器、被动触发层。

两条必须分清的事（2026-10-18 第四轮）：

1. **积木 = 系统级的能力单元**，数量不固定。四类只是当前注册表；压测中发现拼不出时，允许注册第 5、6 类（按下方第 5 步与补充约束办理），**不要求硬塞进四类**。
2. **暴露部位 = 单个技能开放给玩家的自定义点**，默认 4 个（伤害、冷却、范围、数量），也可以 3 个或 6 个。设计卡"修饰器接口"栏声明暴露哪些字段，数量取决于技能本身，不与积木数量绑定。

两者都遵循"默认值可跑、扩展需登记"的同一条原则。

积木优先判断流程〔D-69.5 推荐默认〕：

| 步 | 问题 | 是 → | 否 → |
|---|---|---|---|
| 1 | 这个技能的"施放过程"能否用 索敌→前摇→出手→冷却 描述？ | 用施法者闭环，只填参数 | 先检查是否其实是被动（转步4）或召唤物（独立闭环，D-07） |
| 2 | 产物能否用"一个或几个效果体"描述（载体 none/self/independent/attached + 寿命 + 运动）？ | 用效果体，只填参数 | 转步5 |
| 3 | 额外需求能否用已有 hit/vanish 派生（原因码过滤）表达？ | 用派生 | 转步4 |
| 4 | 额外需求是"某结算后触发"或"改数字/加行为"吗？ | 前者用被动触发层，后者用修饰器 | 转步5 |
| 5 | 以上都不行 | **允许新增积木**：必须写明"为何前4步拼不出"，并登记决策编号（D-xx）经主编/用户确认 | — |

补充约束：

1. 新增积木不得引入第三个技能事件（事件只有 `hit`、`vanish`）。
2. 新增积木必须声明：暴露字段、默认值、能否被修饰器改。
3. 设计卡末尾"待登记积木"栏（见 24.4）不空即视为草案，不得进入实现。

## 24.2 八栏结构与最小可用默认值

> 下列默认值标"示例"处仅为示意，最终数值不在本书给出。

| 栏 | 关键字段 | 最小可用默认值 | 新手可改的关键字段 |
|---|---|---|---|
| 1 基础信息 | 名称、意图、攻击对象、标签、状态 | 状态=推荐默认 | 名称、意图 |
| 2 施法者闭环 | 索敌、前摇、出手次数 X、冷却 | 索敌=最近目标；前摇=无；X=1；冷却=1 秒（示例）；冷却起点=出手后 | 索敌、冷却 |
| 3 效果体 | 载体、寿命、运动、判定形状 | 载体=independent；寿命=由终止条件决定；运动=直线；形状=圆（示例） | 载体、运动 |
| 4 命中与伤害份 | hit_policy、伤害份数、类型 | per_target_limit=1；伤害份=1；类型=物理（示例）；无 rehit_interval | 伤害份数、类型 |
| 5 派生 | hit 派生、vanish 派生 | 均为"无" | 按需添加 |
| 6 终止原因 | 允许哪些 reason | 抛射体：`hit_end`＋`range_end`；瞬时：`instant_end` | 通常不改 |
| 7 修饰器接口 | 暴露字段声明 | 暴露：伤害、冷却、射程、数量；其余不暴露 | 增减暴露字段 |
| 8 被动触发挂点 | 可订阅的结算记录 | 无；默认**不**挂被动 | 按需添加 |
| 玩家文字 | 三句 | 见 23.2 | 三句 |

"新手只改关键字段"含义：保持其余栏为默认值，改"名称、意图、索敌、冷却、运动、伤害份、类型"七项即可得到一个能跑的新技能。〔D-69.6 推荐默认〕

## 24.3 各栏填写规则

### 栏2　施法者闭环

```text
索敌：目标 / 方向 / 地面落点 / 无目标        （默认：目标=最近）
前摇：无 / 有；覆盖 整轮 / 动作组 / 单次出手   （默认：无；多次出手的候选见 26.2）
出手：X 次；出手间隔                          （默认：X=1）
冷却：限制哪一级；起算点                       （默认：出手后；多次出手时见 26.2）
占用与打断：位移状态期间不能施放其他技能〔D-06 已确认〕
```

不得把飞行、命中写进闭环；闭环到"出手"为止，之后是效果体的事。

### 栏3　效果体

对每一种实例各写一行：

| 字段 | 取值 | 备注 |
|---|---|---|
| 实例名 | 自定 | 如"炮弹""火区" |
| 载体 | `none` / `self` / `independent` / `attached` | none=瞬时实例（寿命0，同 tick 内 hit+vanish，原因码 `instant_end`）；self=位移状态＋跟随判定体 |
| 生成条件 | 出手 / hit 派生 / vanish 派生 | |
| 数量 | 整数或公式 | |
| 寿命 | ticks 或"由终止条件决定" | 瞬时=0 |
| 运动/等待 | 直线 / 抛射 / 环绕 / 滞留 / 波前 | 计时、波前到位属内部状态，不是事件 |
| 判定形状 | 圆 / 扇 / 线 / 矩形 | |

### 栏4　命中与伤害份

| 字段 | 默认 | 说明 |
|---|---|---|
| per_target_limit | 1 | 每实例每目标命中次数上限 |
| rehit_interval_ticks | 无 | 火区/环绕须显式声明 |
| max_hits | 无 | 穿透额度等 |
| 伤害份 | 1 | 每份独立判闪避、独立算减免 |
| 全部闪避 | 无 hit | 〔D-05 已确认〕无敌=伤害份视为闪避（非伤害份见 11.4/D-104） |
| 部分闪避 | 一条 hit | 未闪避但减免到 0 仍是 hit |

### 栏5　派生（注明原因码）

| 触发 | 原因码过滤 | 生成什么 | 数量 | 代数提示 |
|---|---|---|---|---|
| hit | （不适用） | | | 派生体第 N+1 代 |
| vanish | 例：`landed` / `expired` / `hit_end` | | | |
| vanish | `range_end` / `interrupted` | 默认不派生；要派生须显式声明 | | |

- `purge` 不发 vanish、不派生〔D-01 已确认〕，卡上不写 purge 派生。
- 每条 hit 只执行一次派生规则，不按伤害份数复制〔见第11章〕。

### 栏6　终止原因

列出本技能每种实例**可能**出现的原因码，并标"是否有 vanish 派生"。表里没有的原因码即"不会发生"。

| 原因码 | 本技能可能出现？ | 有 vanish 派生？ |
|---|---|---|
| `hit_end` / `range_end` / `landed` / `expired` / `returned` / `interrupted` / `instant_end` | 勾选 | 勾选 |

### 栏7　修饰器接口（字段暴露声明）

| 字段名 | 类型 | 暴露给 | 可被 mutate_number | 可被 add_behavior | 可被 mutate_live_instance |
|---|---|---|---|---|---|
| damage | 数字 | tagged / own_skill | 是 | — | 按 26.8 |
| cooldown | 数字 | own_skill | 是 | — | 否 |

规则：未列入暴露字段的内容，修饰器**不得**修改；新增字段需先登记。三档权限与细则见第17章。

### 栏8　被动触发挂点

| 可订阅记录 | 本技能是否允许被订阅 | 备注 |
|---|---|---|
| `cast_started` | 是/否 | |
| `hit_settled`（含 killed） | 是/否 | |
| `evaded_all` | 是/否 | |
| `damage_taken` | 是/否 | |

被动触发层只能"生成效果体"或"挂修饰器"，不能直接造成伤害（见第21章）。

## 24.5 填好的最简飞弹卡（示例）

````text
══ 技能设计卡：魔法飞弹（示例）══
【1 基础信息】
名称：魔法飞弹   意图：最基础的远程单体攻击

【7 修饰器接口】
````

# 第22章　非伤害效果模板

> 一句话结论：**治疗、护盾、增益、召唤、击退、控制都是效果体**，各用一张"效果体模板卡"写清载体、寿命、命中语义、闪避/免疫如何适用、可被哪些修饰、与伤害 hit 的关系；召唤物是独立施法者闭环，有 `owner_id` 与上限。〔D-02、D-07 已确认〕

## 22.1 模板卡字段

| 字段 | 含义 |
|---|---|
| 载体 | `none` / `self` / `independent` / `attached`（8.5A）〔2026-10-18 终审修正〕 |
| 寿命 | `lifetime_ticks`，0 = 瞬时实例 |
| 命中语义 | 谁算被命中；`hit_policy` |
| 闪避/免疫 | 见 22.10 |
| 可被哪些修饰 | 暴露字段与权限（第17章） |
| 与伤害 hit 的关系 | 是否带伤害份；是否进入 `hit_settled` |
| 阵营过滤 | 见 22.9 |

## 22.2 统一约定

1. 非伤害效果同样是效果体，事件同样只有 `hit` 与 `vanish`。〔D-01 已确认〕
2. 接触到合法目标且至少一份未被闪避时发 `hit`；`parts[]` 中各份的 `type` 标明为非伤害类型（`heal`、`shield`、`buff`、`debuff`、`knockback`、`control` 等，示例命名），`final_amount` 为实际量。〔D-58 推荐默认〕
3. 非伤害 `hit` 同样写入 `hit_settled`；被动触发的 `condition` 应按份 `type` 过滤，避免"治疗触发击杀类遗物"。
4. 实例带 `origin`，受代数与 `cast_budget` 约束（第20章）。
5. 状态型派生体（载体 `attached`）：D-71“创建 tick 不判定”不阻止状态在创建 tick 挂载；空实例由 `lifetime` 自然回收（2026-10-18 第二轮，U-4/D-98 推荐默认，见 20.2 注）。

## 22.3 治疗

| 项 | 内容 |
|---|---|
| 载体 | 无载体瞬时实例（单次治疗）或独立载体（持续治疗区） |
| 寿命 | 瞬时 = 0；区域有限，到期 `expired` |
| 命中语义 | 命中合法友方目标，份 `type=heal`；`killed` 恒为 false |
| 闪避/免疫 | 按 22.10 推荐不判闪避；无敌目标照常受治疗（2026-10-18 第二轮，D-90 已确认，无敌只使伤害份视为闪避，见 11.4）；"免疫治疗"类状态=该份减免为 0（D-05） |
| 可被修饰 | 治疗量、半径、持续时间（须在设计卡暴露） |
| 与伤害 hit | 独立 `hit`；不触发"造成伤害时"类被动 |
| 溢出 | 超出上限部分不计入 `final_amount` |

## 22.4 护盾

| 项 | 内容 |
|---|---|
| 载体 | `attached`（给目标挂护盾状态，8.5A；有寿命，无空间运动）或自身载体（跟随判定体）〔2026-10-18 终审修正〕 |
| 寿命 | 到期发 `vanish(expired)`；额度被打光发 `vanish(hit_end)`（额度用尽视同命中额度用尽） |
| 命中语义 | 给施法者/友方施加护盾，份 `type=shield` |
| 闪避/免疫 | 有益不判闪避（22.10）；无敌目标照常获得护盾（D-90，见 11.4），无敌持有者的既有护盾保留、不消耗（D-97，推荐默认）；对来袭伤害的吸收发生在伤害份减免之后、扣血之前，作为结算链的一步（2026-10-18 第二轮，D-96 推荐默认；与 11.5 同口径） |
| 可被修饰 | 护盾值、持续时间、叠加规则（`restack_rule`，默认刷新单例，第19章） |
| 与伤害 hit | 被吸收的伤害仍使对应伤害 hit 成立；护盾吸收属于结算后行为，**不使** `final_amount` 变为 0，因此吸收到 0 **不**置位 `any_reduced_to_zero`（该字段仅反映 11.2 的减免后为 0）；`hit_settled.total` 为吸收前，`damage_taken.total` 为吸收后实际扣血（2026-10-18 第二轮，U-2/U-11，D-96） |

## 22.5 增益/减益

| 项 | 内容 |
|---|---|
| 载体 | `attached`（状态挂在目标上，8.5A）或独立载体（光环区）〔2026-10-18 终审修正〕 |
| 寿命 | 有限；到期 `vanish(expired)` |
| 命中语义 | 施加状态，份 `type=buff` / `debuff`，`final_amount` 可表示层数 |
| 闪避/免疫 | 增益不判，无敌目标照常获得增益与有益修饰器（2026-10-18 第二轮，D-90 已确认，见 11.4）；减益按 22.10 判闪避 |
| 可被修饰 | 持续时间、层数上限、强度（须暴露） |
| 叠加 | 默认有限叠层（19.3） |
| 与伤害 hit | 本身不造成伤害；其数值作用于后续伤害份时，按"命中时目标侧状态"取值（18.1） |

## 22.6 召唤〔D-07 已确认〕

D-07 已确认：召唤物有独立施法者闭环，受召唤上限约束。以下为细则。

| 项 | 内容 |
|---|---|
| 载体 | 独立载体（长期存在的效果体，内含自己的施法者闭环） |
| 归属 | 必须携带 `owner_id`（召唤者）；召唤物自己的施放以其自身为 `caster_id`〔D-59 推荐默认〕 |
| 上限 | 每个召唤者对每类召唤物的同时存活数上限 `summon_cap`（示例：3）；超限时丢弃最旧（旧者按清场处理，不发 vanish）〔D-59 推荐默认〕 |
| 寿命 | 有限或直到被击杀；自然终止发 `vanish`（带原因码），清场不发 |
| 命中语义 | 召唤动作作用于目标点/空位；召唤物之后的攻击走它自己的闭环与 hit |
| 闪避/免疫 | 召唤动作不适用闪避；召唤物作为单位受击时按常规伤害规则 |
| 可被修饰 | `summon_cap`、寿命、召唤物属性（须暴露）；召唤物是否继承召唤者的修饰器按 `inheritable`，默认不继承 |
| 预算 | 召唤物自己的施放有自己的 `origin_cast_id` 与 `cast_budget`；其 `origin_skill` 沿用召唤技能；同时受全局实例预算约束（第15章）〔D-59 推荐默认〕 |
| 召唤者阵亡 | 召唤体模板字段 `bind_owner`，默认 `true`：随召唤者阵亡以 `purge` 终止（不发 vanish、不派生）；设为 `false` 则留存。召唤物自己已生成的独立实例继续存在〔D-59 推荐默认〕 |

## 22.7 击退

| 项 | 内容 |
|---|---|
| 载体 | 无载体瞬时实例（一次击退）或独立载体（推力区） |
| 命中语义 | 命中即对目标施加位移，份 `type=knockback`，`final_amount` 为实际位移量 |
| 与伤害 hit | 可与伤害份同属一条 hit（各份独立判闪避/减免），也可单独成 hit |
| 闪避/免疫 | 伤害份被闪避而击退份未被闪避 → hit 仍成立；无敌=伤害份视为闪避（D-05/D-90）；无敌不隐含击退/控制/减益免疫：有害非伤害份照常生效，除非目标带对应免疫标记（D-104，2026-10-18 第三轮，见 11.4）；免疫击退=该份减免为 0，hit 仍成立（D-05） |
| 可被修饰 | 位移距离、速度 |
| 与位移状态 | 被击退者若处于位移状态：默认被打断，位移状态以 `vanish(interrupted)` 终止（规则见第7–8章）；设计卡可声明"位移中免疫击退" |

## 22.8 控制（眩晕、定身、沉默等）

| 项 | 内容 |
|---|---|
| 载体 | 无载体（直接施加状态）或独立载体（控制区/弹） |
| 命中语义 | 施加控制状态，份 `type=control`，`final_amount` 为时长 |
| 闪避/免疫 | 按 22.10 判闪避；免疫某类控制=该份减免为 0，hit 仍成立（D-05） |
| 与闭环的关系 | 眩晕令目标的施法者闭环暂停（保留已排队的出手点语义），与“打断”（作废未出手的出手点）分属两种机制：眩晕结束恢复闭环，其间不触发打断流程；眩晕中被打断则按打断处理（2026-10-18 第二轮，U-6）；沉默只阻止"施放"，不影响已在场上的实例；定身只阻止位移 |
| 与位移状态 | 位移状态期间不能施放其他技能〔D-06 已确认〕；被控制打断位移状态按 `interrupted` |
| 叠加 | 同类控制默认刷新单例，**刷新=重置为满寿命（D-46）**；若设计需要“取剩余与新值较大者”，在设计卡以 `restack_rule: keep_longer` 显式声明，默认不启用（2026-10-18 第二轮，U-5/D-101 推荐默认）；"控制递减"（连续被控时长衰减）是否引入——**待用户确认** |
| 可被修饰 | 控制时长、范围 |

**控制是否打断施法：`interrupts_cast` 字段表（D-107）**〔2026-10-18 终审修正〕

| 控制类型 | `interrupts_cast` | 默认语义 |
|---|---|---|
| 眩晕 `stun` | `false` | 闭环暂停，出手点语义保留，结束恢复 |
| 冻结 `freeze` | `false` | 同眩晕 |
| 沉默 `silence` | `false` | 只关 `cast` 门，不打断在办前摇（已在前摇的继续） |
| 定身 `root` | `false` | 只关 `move` 门 |
| 击退 `knockback` | `true` | 打断：前摇终止、未出手作废、零出手不耗冷却 |
| 强制位移 `displace` | `true` | 同击退 |

| 编号 | 规则 | 状态 |
|---|---|---|
| 22.8-x | **每种控制类型必须在 CFG 注册 `interrupts_cast`**；未注册的控制类型不得上线（同 D-104 的注册强制口径） | 〔D-107 推荐默认〕〔2026-10-18 终审修正〕 |
| 22.8-y | 眩晕期间若**另有** `interrupts_cast=true` 的效果命中，以该效果为准（即"眩晕中被打断"）；两者并存时打断优先结算 | 〔D-107〕〔2026-10-18 终审修正〕 |

## 22.9 阵营过滤规则

| 效果类型 | 合法目标 | 默认过滤 |
|---|---|---|
| 伤害 | 敌方 | 不命中友方；是否伤及己方由设计卡声明 `friendly_fire`，默认 false |
| 治疗/护盾/增益 | 友方 | 默认不命中敌方；是否含施法者自身由 `include_self` 声明 |
| 减益/控制 | 敌方 | 同伤害 |
| 击退 | 与来源阵营一致的敌方 | 与伤害同规则 |
| 召唤 | 目标点/空位 | 无目标过滤 |

- 阵营由 `caster_id` 所属阵营推导；召唤物阵营继承 `owner_id`。〔D-58 推荐默认〕
- 过滤发生在接触检测之后、伤害份判定之前；被过滤的目标不产生任何 hit 载荷。

## 22.10 闪避对非伤害效果的处理

| 候选 | 规则 | 体验 | 优点 | 代价 | 典型案例 | 与已确认规则兼容性 |
|---|---|---|---|---|---|---|
| A 非伤害一律不判闪避 | 治疗、护盾、增益、减益、控制、击退都不判 | 简单 | 规则最短；友方增益不会被"闪掉" | 闪避对控制/击退没有价值 | 简化原型 | 兼容 D-05 |
| B 有益不判、有害判 | 治疗/护盾/增益不判；减益/控制/击退判闪避 | 与"闪避=躲开攻击"直觉一致 | 保留闪避价值；有益效果稳定 | 每份需标有益/有害 | 本书推荐 | 兼容 D-05 |
| C 按份声明 | 设计卡逐份写"可闪避/不可闪避" | 灵活 | 精确 | 书写量大，易不一致 | 特殊技能 | 兼容；作为 B 的覆盖 |

推荐：**B 为默认，C 作为显式覆盖**。〔D-58 推荐默认〕

同一 hit 内治疗份与伤害份并存（如吸血）：治疗份不判闪避，伤害份判；只要至少一份未被闪避，hit 成立。无敌（D-05）时**伤害份**视为闪避；治疗份、增益不受影响，照常生效（2026-10-18 第二轮，D-90 已确认；此句取代原“无敌时全部份视为闪避、治疗份亦不生效”的写法，D-05 原文不变）。若无敌目标身上只有伤害份，则该份全部被闪避、无 hit。〔2026-10-18 终审修正〕

## 22.11 常见误写→正确写法

| 常见误写 | 正确写法 |
|---|---|
| "治疗是直接加血，不是效果体" | 治疗也是效果体（可为瞬时实例），发 `hit`，份 `type=heal` |
| "召唤物只是普通飞弹" | 召唤物是独立载体，内含独立施法者闭环，有 `owner_id` 与 `summon_cap` |
| 召唤物无限召唤 | 声明 `summon_cap` 与超限处理，同时受全局实例预算约束 |
| "无敌时治疗照样生效" | 正确（2026-10-18 第二轮，D-90 已确认）：无敌只使伤害份视为闪避；治疗与增益对无敌目标照常生效；阻止指向性效果的是独立标记“不可选取”（D-05 原文不变） |
| "免疫击退=整条 hit 不成立" | 免疫某类型=该份减免为 0，hit 仍成立 |
| 友方增益命中敌方 | 有益效果默认只命中友方（22.9） |
| 击退取消冲刺却不写原因码 | 位移状态被打断用 `vanish(interrupted)` |
