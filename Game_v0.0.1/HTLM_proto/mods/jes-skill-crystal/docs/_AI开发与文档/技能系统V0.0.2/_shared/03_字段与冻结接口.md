## 5.4 instance 字段表

下表字段即契约词表，不得另造字段名。示例数值仅为说明。

| 字段 | 取值／类型 | 确定时机 | 含义 | 运行中是否可变 |
|---|---|---|---|---|
| `instance_id` | 唯一标识 | 生成 | 实例唯一编号 | 否 |
| `seq` | 创建序号 | 生成 | 全局创建先后；同 tick 内排队与 FIFO 的依据（第14章） | 否 |
| `skill_id` | 技能编号 | 生成 | 所属技能 | 否 |
| `carrier` | `none` ／ `self` ／ `independent` ／ `attached` | 生成 | 载体类型；`none` 即瞬时实例（第8章）；`attached` 见 8.5A〔2026-10-18 终审修正〕 | 否 |
| `caster_id` | 施法者编号 | 生成 | 谁施放（召唤物独立闭环，其 `caster_id` 为召唤物自身，见第22章） | 否 |
| `generation` | 整数，根为 0 | 生成 | 派生代数 | 否 |
| `parent_ref` | 实例引用或空 | 生成 | 指向父实例；根实例为空 | 否 |
| `origin` | 来源链标记 | 生成 | 含 `origin_skill`、`origin_cast_id`、`chain_depth`、`proc_mask`；细则第20章 | 否（派生时按第20章规则继承） |
| `spawn_tick` | tick 编号 | 生成 | 生成发生的 tick | 否 |
| `lifetime_ticks` | 整数 | 生成 | 预定寿命；**瞬时实例为 0**；无限期实例用技能声明的上限（见第15章预算） | 默认否；修改走第18章 |
| `snapshot` | 属性快照 | 出手瞬间 | 出手时施法者属性的快照；语义细则第18章 | 否 |
| `params` | 参数集 | 生成 | 生成时确定的实例级参数（半径、速度、数量等；示例） | 视权限；第17、18章 |
| `hit_policy` | 见下 | 生成 | 重复命中规则 | 默认否 |
| `state` | `live` ／ `terminating` ／ `gone` | 随生命周期 | 当前状态 | 由系统转换 |

`hit_policy` 子字段：`per_target_limit`（默认 1）、`rehit_interval_ticks`（可选）、`max_hits`（可选）。默认每实例每目标 1 次，火区、环绕、穿透必须显式声明。（计次按候选接触，细则见第14章；此处只引用冻结词表）

补充规则：

1. 位移状态本身不是实例；它的**跟随判定体**才是实例（`carrier = self`）。位移状态是施法者的运动状态，不占 `instance_id`。〔D-18 推荐默认〕
2. `generation` 只数派生（根为 0）。`chain_depth` 另见第20章：每次派生与被动触发各 +1，故 `chain_depth ≥ generation`。〔D-17a 推荐默认〕

## 36.3 原因码（冻结）

| 码 | 含义 | 发 vanish | 允许 vanish 派生 |
|---|---|---|---|
| `hit_end` | 命中次数/穿透额度用尽；分裂时母体亦用此码 | 是 | 是 |
| `range_end` | 飞行距离/路径耗尽，位移按距离定义抵达终点；`on_target_lost: terminate` | 是 | 默认否，显式声明才可 |
| `landed` | 落到目标点/地面（仅限抛射） | 是 | 是 |
| `expired` | 持续时间到期；位移按固定时长结束 | 是 | 是（到期不额外跳伤） |
| `returned` | 回旋体回到施法者 | 是 | 是 |
| `interrupted` | 被打断或被拦截（含位移状态被打断） | 是 | 默认否，显式声明才可 |
| `instant_end` | 瞬时实例在其 tick 内结束 | 是 | 是 |
| （purge） | 清场、场景卸载、阵亡清理、预算丢弃 | **否** | **否** |

## 36.4 字段词表与载荷（冻结）

**instance：**`instance_id` `seq` `skill_id` `carrier`(`none`|`self`|`independent`|`attached`) `caster_id` `generation` `parent_ref` `origin` `spawn_tick` `lifetime_ticks` `snapshot` `params` `hit_policy` `state`(`live`|`terminating`|`gone`)

**origin：**`origin_skill` `origin_cast_id` `chain_depth` `proc_mask`。`generation` 只数派生；`chain_depth` 数派生与被动触发，`chain_depth ≥ generation`。

**hit_policy：**`per_target_limit`（默认 1，按候选接触计）`rehit_interval_ticks`（可选）`max_hits`（可选，只计成立的 hit）。

**候选接触：**实例与目标由不重叠变重叠，或 `rehit_interval_ticks` 到点；每次只判定一次逐份闪避。

**hit 载荷：**`source_instance` `target_id` `parts[]{part_index, evaded, type, final_amount}` `any_reduced_to_zero` `killed` `tick` `seq`

**设计卡附加字段：**`shotgun_allowed`（默认 false）`on_target_lost`(`continue`|`terminate`，默认 `continue`) `attach_to_caster` `bind_owner`（召唤体，默认 true）`summon_cap` `internal_cooldown_ticks` `max_chain_depth` `allow_self_chain`（默认 false）`trigger_id`。

## 36.6 修饰器接口（冻结）

`modifier_id` `permission`(`mutate_number`|`add_behavior`|`mutate_live_instance`) `scope`(`own_skill` 默认|`tagged`) `inheritable`(默认 false) `targets[]` `stack_rule`。数值应用顺序 `set → add → mul → clamp`（`mul` 合并口径见第26章候选）。

## 36.7 运行时顺序（冻结，示意）

```text
每个 tick：
  1. 推进计时（受时间缩放）
  2. 闭环推进：索敌 / 前摇 / 出手 → 创建实例（**出手**创建的瞬时实例当 tick 阶段③参与接触；**派生**创建的实例见 14.4-2，`spawn_tick+1` 起参与）〔2026-10-18 终审修正〕
  3. 实例按 seq 升序：运动 → 候选接触 → 逐份闪避 → hit 入 FIFO
  4. FIFO 逐个处理 hit：结算 → 写结算记录 → 派生
  5. 终止判定 → vanish 入 FIFO → 派生
  6. 被动触发层读结算记录 → 生成效果体（chain_depth+1）
  7. 回收；预算检查（超限按优先级 purge）
```

细节与边界以第14、15章为准。
