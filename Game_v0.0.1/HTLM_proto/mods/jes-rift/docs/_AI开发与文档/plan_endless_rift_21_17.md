# 21.17 深渊副本改版：大秘境模式（时间驱动 + 推进量 BOSS + 最终撤离点）

> 拍板：2026-10-08。参考《暗黑破坏神 3》大秘境。用户已确认全部选项，本方案为执行文档。

## 零、改版动机

21.15 的深渊是**清空推进 + 死亡即结算**模式，与用户设想不符。本轮按 D3 大秘境重构：
- 改成 **时间驱动刷怪**（到点就刷，不看场上）→ 逼玩家向前推，不能磨
- 改成 **总时限 10 分钟** → 时间压力
- 改成 **打到最终 BOSS 才拿到逃生权** → 「见好就收 vs 继续贪」的赌注
- **屏蔽空间裂隙雕像** → 深渊是纯粹冲关，不引入分支玩法

## 一、用户拍板结论（不再讨论）

| 项 | 结论 |
|---|---|
| 怪物生成 | **到点就刷，不看场上剩余**（上限仍封顶）|
| 撤离点 | **仅最终 BOSS 掉落**；打到才拿到逃生权 |
| 总时限 | **10 分钟**（CFG 可调）；超时 = **失败结算（保留 30%）** |
| BOSS 触发 | **累计推进量 = 击杀数 + 时间加权** |
| 空间裂隙雕像 | **屏蔽**（深渊不刷 RIFT）|
| 页面加载优化 | **本轮不做**（用户明确）|
| 逃生逻辑 | 时限内击杀最终 BOSS → 掉撤离点 → 玩家走过去读条即撤离（带全收益）；超时/死亡 → 失败结算（保留 30%）|

## 二、玩法规则（定稿）

### 2.1 核心循环（时间驱动）
```
进入深渊 → 计时开始（10:00 倒计时）
  ↓
每 spawnInterval 秒刷一波怪（间隔随波次递减，下限封顶）
  ↓ 场上怪不清也会继续刷（上限 capFor(wave) 封顶）
  ↓
推进量 progress = kills + timeSec * timeWeight 累积
  ↓ progress 到阈值 → 刷 BOSS（周期递增：第1个早、后续渐远）
  ↓
击杀最终 BOSS → 掉落撤离点 → 玩家走过去读条 → 撤离成功（全收益）
  ↓
超时（10:00 到）或死亡 → 失败结算（保留 30%）
```

### 2.2 关键数值（全部进 `CFG.endless`）

| 字段 | 值 | 说明 |
|---|---|---|
| `timeLimit` | 600 | 总时限（秒）= 10 分钟 |
| `spawnInterval` | 开始 4.0s | 刷怪间隔基准 |
| `spawnIntervalMin` | 1.5s | 间隔下限（波次越高越密）|
| `spawnIntervalDecay` | 0.12s/波 | 每波递减量 |
| `capBase` / `capPerWave` / `capMax` | 40 / 12 / 300 | 同屏上限（沿用 21.15）|
| `bossProgressBase` | 300 | 首个 BOSS 的推进量阈值 |
| `bossProgressStep` | 260 | 后续每个 BOSS 阈值增量 |
| `timeWeight` | 1.0 | 时间加权（每秒折算 1 点推进量）|
| `finalBossIndex` | 3 | 第 N 个 BOSS = 最终 BOSS（掉撤离点）|
| `hpMulPerWave` / `dmgMulPerWave` | 0.18 / 0.06 | 强度曲线（沿用）|
| `reward.base` / `reward.exp` | 8 / 1.15 | 每波结晶（沿用）|
| `extractChannel` | 3.0 | 撤离读条时长（对齐主线 exitBeacon）|

### 2.3 BOSS 机制
- **非最终 BOSS**（第 1、2 个）：精英强化的普通 BOSS，击杀给大额结晶奖励，不掉撤离点
- **最终 BOSS**（第 `finalBossIndex` 个）：击杀后**在玩家附近掉落撤离点**（复用主线 `exitBeacon` 视觉 + `judgeChannel` 判定）
- BOSS 从 `CFG.monsters` 的 boss 池抽取，强度按当波曲线放大

### 2.4 屏蔽空间裂隙
- 深渊世界的祭坛随机池**排除 `RIFT`**（`js/config.js` 的 `CFG.altars.RIFT`）
- 实现：Endless.makeWorld 后设置世界级白名单/排除项，或在祭坛抽取处按世界 kind 过滤
- ⚠️ **不改 CFG.altars 本身**（主线仍要 RIFT），只在深渊世界生效
