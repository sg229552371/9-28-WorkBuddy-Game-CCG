# UI 图标资源需求规格 v1（交付给生图模型用）

> 建立日期：2026-10-13 ｜ 对应代码版本：`APP_VERSION 20261057`
> 用途：本项目当前**全部 UI 图标均为程序化文字/符号占位**（`assets/sprites/` 为空目录），
> 本文件把「游戏里实际需要、目前拿符号顶着」的每一个图标逐条列出，可直接投喂生图模型批量出图。
> **交付形式 = 2048×2048 图集（Sprite Sheet）**：一张大图按网格装多个图标、纯蓝 `#0000FF` 底色、无透明、对齐可切，
> 详见 §0.2 / §0.2.1；每张图集须附「图集清单」（§0.3）。
> 真源：`index.html`、`js/config.js`、`js/ui.js`、`js/ui-panels.js`、`js/ui-screens.js`、
> `js/hud_endless.js`、`js/render.js`、`js/endless-arena.js`、`css/style.css`。

## 0. 交付与通用规格（所有图标一律遵守）

### 0.1 全局禁止项（**重要，逐条硬约束**）

1. **不加任何特效**：不画发光、不画光晕、不画外发光、不画粒子、不画星光、不画闪电光弧、不画镜头光斑、不画动态拖尾、不画能量波纹。
2. **不加图标背景**：每个图标**自身不带**底图、底板、圆形/方形实心底衬、外框底衬、网格、纸纹、云雾。
   （**区分清楚**：整张图集会铺一层**纯蓝 `#0000FF`** 作为**技术抠图底色**，见 §0.2 —— 那是切图用的底色，**不是**图标背景。不要把蓝色当作设计元素画进图标里，也不要在图标内部使用蓝色来「呼应底色」。）
3. **不加文字**：不写中文、不写英文、不写数字、不写字母、不画水印、不画签名。
4. **不加装饰**：不画边框花纹、不画角花、不画丝带、不画额外的点线装饰、不画阴影投影。
5. **不加人物**：除明确要求「雕像/人物」的条目外，图标内不出现人脸、不出现角色。
6. **单格单物**：每个图标**只占一格**、**每格只画一个**图标（在该格内居中）；**不要**一图一文件、**不要**在同一格里拼多个物件、**不要**输出四格/九格备选。

> 说明：以上只约束「不要画什么」。画画的对象、造型语言、配色做法**不限定**，由出图方自行决定，但同一批图标必须自洽（同一套线条粗细、同一套圆角、同一套正视角）。

### 0.2 图集与出图技术参数（**所有批次一律遵守**）

| 项 | 要求 |
|---|---|
| **交付形式** | **图集（Sprite Sheet）**：一张大图内含**多个**图标，按**网格**整齐排列成一张成图（不要一图一文件） |
| **图集尺寸** | **固定 2048 × 2048 px**（2K 方图），任何一批都按这个尺寸出，不得改大改小 |
| **画质** | **最高品质**：无压缩伪影、无锯齿糊边、无涂抹涂抹感；不要把图集存成低质量 JPEG 再转 PNG |
| **背景** | **整张图集铺满纯蓝 `#0000FF`**（RGB = 0,0,255）——**纯色、均匀、无渐变、无噪点、无纹理**，用于后期一键抠图 |
| **透明通道** | **关闭 alpha / 无透明**：整图**每个像素都不透明**，不得出现任何半透明区域或羽化残留 |
| **边缘** | 图标与蓝底之间为**硬边**：不羽化、不外发光、不投影、不做半透明渐变过渡；**不得出现与蓝底混色的半透明过渡带**（蓝天之间不要有「蓝图标色混合的中间带」） |
| **网格** | **严格行列对齐**（见 §0.2.1），便于等分切图 |
| **单格尺寸** | 标准图集 = **256 × 256 px / 格**；大格图集 = **512 × 512 px / 格**（见 §0.4 尺寸档） |
| **构图** | 每个图标**在自己那一格内居中**，主体占单格约 **80%**，四周各留约 10% 蓝底边（不贴格边、不切格边） |
| **可读性** | 缩到 **32×32 像素时仍能辨认**（剪影必须独特，不能两个图标缩下去像同一个） |
| **线宽** | 同一批内线条粗细一致；最细线在 32×32 下不得消失 |

### 0.2.1 网格与切图对齐规则（**决定好不好切图，务必照做**）

1. **网格规格**（两种，按图集类型二选一）：
   - **标准图集**：**8 列 × 8 行 = 64 格**，单格 **256×256**（2048 = 8 × 256，整除）
   - **大格图集**：**4 列 × 4 行 = 16 格**，单格 **512×512**（2048 = 4 × 512，整除）
2. **无外边距、无格间距**：图像从左上角 (0,0) 起，格子**紧邻拼接**，**不要**在格子间加分隔线、间距、留白或编号。
3. **每图标只占一格**：图标必须**完整落在自己那一格内**，**不得越格、不得跨格、不得压线**，也不得旋转/倾斜（保持正视角，横平竖直）。
4. **居中**：每个图标的几何中心对准**格子的几何中心**（水平居中 + 垂直居中），不要偏到格角。
5. **切图坐标**：第 `r` 行第 `c` 列（均从 0 开始）= 裁切区域 `x = c × 单格边长, y = r × 单格边长, w = h = 单格边长`。
   例：标准图集第 3 行第 5 列的图标 → 裁 `x=4×256=1024, y=2×256=512, w=256, h=256`。
6. **空位处理**：某一批图标数量不足（末格不足 64 / 16）时，**空位保持纯蓝**，**不要把后面的图标前移补位**，也不要画占位符号。
7. **不要输出网格线/坐标/编号**：切图靠我方按固定尺寸等分，图上**不要**画任何网格线、行列号、文字标签。

### 0.3 命名、投放与「图集清单」（**必须随图交付**）

- 图标键名 = 下方每条给出的**键名**（全小写 snake_case，`ui_` 前缀）。例：`ui_op_back`、`ui_stat_atk`。
- 键名一经采用不可更改（渲染侧按名字查表）。
- **图集文件名**：`atlas_ui_<组>_<两位序号>.png`，例：`atlas_ui_op_01.png`、`atlas_ui_stat_02.png`。
- **必须随每张图集附一份「图集清单」**（文本 / CSV 均可），标明**每个格子对应哪个键名**。格式示例：

  ```
  atlas_ui_stat_01.png  (标准图集 8×8 / 256px)
  行0: ui_stat_hp | ui_stat_hp_max | ui_stat_def | ui_stat_atk | ui_stat_spd | ui_stat_cd | ui_stat_radius | ui_stat_lifesteal
  行1: ui_stat_summon | ui_stat_trap | ui_stat_str | ui_stat_agi | ui_stat_int | ui_stat_crit | ui_stat_pierce | ui_stat_range
  ...（依次列到行7；空位写 -）
  ```

  我方按此清单**自动切图并归档**到 `assets/sprites/ui/<组>/<键名>.png`。

### 0.4 尺寸档位与单格规格

条目标注的档（S / M / L）决定它进哪种图集、占多大单格：

| 档 | 目标显示尺寸（我方缩放到） | 单格尺寸 | 图集网格 | 每张图集装 | 用于 |
|---|---|---|---|---|---|
| **S** | 64×64 | **256×256** | 8×8（64 格） | 64 个 | HUD 小角标、列表行内、属性标签 |
| **M** | 128×128 | **256×256** | 8×8（64 格） | 64 个 | 按钮、槽位、卡片角标、物品格 |
| **L** | 256×256 | **512×512** | 4×4（16 格） | 16 个 | 祭坛/雕像实体、面板主视觉、货币大图、摇杆 |

- **S 与 M 共用同一种图集**（都是 256 单格，混排即可，我方按目标尺寸分别缩放）。
- **L 单独用大格图集**（512 单格）。标注「M/L」的条目按 **L** 处理，进大格图集。
- 单格 256 已是 S（64）的 4 倍、M（128）的 2 倍，缩放绰绰有余；大格 512 保证 L 档 256 显示时清晰。

### 17.2 图集装箱估算（**一张 2048 图集装多个图标**）

> **不要**一图一文件、不要做成四格/九格备选。**一张图集按 §0.2.1 的网格装多个图标**，格子数固定。

| 类型 | 单格尺寸 | 网格 | 每张容量 | 适用条目数（约） | 需要张数 |

## 附：可直接投喂给生图模型的一段话（**图集通用前缀**）

> 请画一张游戏 UI 图标**图集（sprite sheet）**，尺寸固定 **2048×2048 像素**，**最高画质**。
